遥感 CV 转型 · 24 个月「教-学-做」带教手册 —— 网站版
================================================================

怎么打开
----------------
1. 把这个压缩包完整解压出来（不要只解压单个文件）。
2. 双击 index.html，用浏览器打开。就这样，不需要联网、不需要装任何东西。

推荐用 Chrome / Edge / Firefox / Safari。手机上也能看：把整个文件夹传到手机，
用支持本地文件的浏览器打开 index.html 即可。

glossary.html     术语表。M0 原有的 + 补充的常用词，标了首次用到的周次。
buffer.html       缓冲周（W28 / W44）怎么用。
errata.html       校订说明：做成网站时改了什么、没改什么。
guide.html        原始 README 阅读说明。
log.html          手册的编写接力记录（普通使用可跳过）。
source-md/        原始 Markdown 文件，原样保留；另加 4 份补充稿（补充00–03）。

进度和笔记存在哪
----------------
勾选（每个时段的方框）和每天的笔记，都存在**你当前这台电脑的这个浏览器**里，
不会上传到任何地方。

注意两件事：
- 换电脑、换浏览器、清理浏览器数据，进度会没。
- 首页底部有「导出进度 / 导入进度」，会存成一个 JSON 文件。
  建议每隔一两个月导出一次备份。


快捷键
----------------
/            跳到搜索框
← →          上一周 / 下一周
点击某天标题  折叠 / 展开那一天


怎么用这套手册
----------------
1. 先读 start/ 里的 M0 两篇（零遥感基础必读）。
2. 然后从 week/w1.html 开始，按周号顺着做，不要跳。
3. 每个时段照着六块走：先垫概念 → 手把手带做 → 合格样例 → 常踩的坑 →
   卡住自救 → 今天学会了什么。
4. 做完一个时段就点一下方框。进度可慢不可断。
