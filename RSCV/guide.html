《遥感 CV 转型 · 24 个月》「教-学-做」带教手册 —— 阅读说明 & 完整内容总览

这是原始 README 的原文　其中"730 天""106 个 .md"是文件包口径；站内统一按 728 天 / 2142 个时段计。差异见校订说明。

🎉 本手册已全部完工：M0 入门 2 份 + M1–M24 全 102 个周文件 + 本说明 + 接力说明 = 106 个 .md，覆盖完整的 104 周 / 24 个月 / 730 天。

一、这份手册是什么

把你的《遥感 CV 转型 24 个月终极整合执行计划 v5.0》逐日重写成「边做边教」的带教脚本。

  • 不改动原计划的日历、任务和编号；
  • 只把每天从“日程表”重写成“牵着你一步步做”的带教单元；
  • 从零遥感基础起步，全程目标导向（空天院 offer + 博士毕业），自带基础、不依赖外部 MOOC。

一句话：这是你那份 v5.0 计划的“可执行版 + 教练版”。 你不需要再去想“今天具体怎么做”，跟着每天的脚本做就行。

二、怎么读（阅读顺序）

0️⃣ 先读两份基础入门（M0，零遥感 / 零深度学习基础者必读）

  • M0-遥感基础知识入门_教学做版.md —— 从零讲遥感：电磁波/波段、被动 vs 主动、数据类型、四种分辨率、几何/辐射校正、数据格式、遥感 vs 通用 CV 十大差异、SAR 专题、遥感里的 CV 任务、术语表。全程用“和通用 CV 对比”的方式讲。
  • M0-必备前置知识_教学做版.md —— CV / 深度学习 / 数学 / 工具的最小够用底子：训练五步、CNN 与 backbone/neck/head、检测/分割/变化检测范式、各类指标何时用、PyTorch 最小够用、够用数学、常用库，并标注“它在计划哪天出现”。

这两份把基础集中、自带地垫一遍。两份读完，再正式从 M1-W1 开始。

1️⃣ 然后顺着月份/周次往下做

从 M1-W1_教学做版.md 开始，按文件名里的周号（W1 → W104）一路顺着做即可。每周一个文件，每天三个时段。正文每天的“①先垫概念”仍会在用到时讲对应概念（伴随式），M0 是提前集中垫一遍。

三、每周文件长什么样（统一结构）

每个周文件 = 满深度正文 + 加厚补充包，约 26–44K 字。

正文：7 天 × 每天 3 时段（上午段 / 中午段 / 晚上段）= 21 个时段单元。每个时段单元固定 六块：

  1. 先垫概念 —— 用类比讲清“为什么现在做这个”“它和通用 CV 有什么不同”；
  2. 手把手带做 —— 具体命令 / 代码 / 操作；
  3. 合格样例 —— 做对了长什么样；
  4. 常踩的坑 —— 容易出错的地方 + 怎么避开；
  5. 卡住自救（决策树） —— 卡住了照着这个判断往下走；
  6. 今天你同时学会了什么 —— 做了 / 学了 / 会了，偶附“技能卡”小结。

每天还有：开头的「预期管理」（今天要做什么、提醒）+ 结尾的「今日交付」（今天产出了什么）。

加厚补充包（每周文件末尾）四样：① 合格范例（照着填就能用）；② 完整可运行代码 + 预期输出；③ 每日自测；④ 报错 / 坑速查表。

四、贯穿全程的“战略定位 / 诚实校准”（最重要）

这是整份手册的灵魂，每一周都在落实：

  • 战略定位（核心）：你是零遥感基础 + 单张 RTX 4090 + 导师不支持 + 目标空天院。所以不在“更大基础模型”主轴上和 RingMoE / 空天·灵眸硬拼；发力点 = 下游特化 / 高效适配（LoRA）/ 评测 / 鲁棒性 / 跨域泛化 / 小样本 / SAR 难题 / 通用 CV 嫁接。单张 4090 写进论文当亮点（高效、可复现）。
  • 两条线并行不混：博士毕业靠博士论文（原方向），转型求职靠遥感成果——这是两条线，精力清醒分配、并行推进、绝不混为一谈。
  • 对外连接 / 运营定位为“强作品的自然放大”（副线、控时），核心始终是研究产出。
  • 事实订正（散落各周）：RingMo 归属空天院孙显组（非自动化所）；SARCLIP 替换为王超组 2025 TACMT；天智杯非空天院主办（练手可以、不作破冰理由）等。

五、📚 完整内容总览（四个阶段 · M1–M24）

整个 24 个月分四个阶段，一条主线：从零基础 → 第一/二/三篇论文 + 竞赛 + 开源 → 联系空天院 + 访问/合作 → 求职拿 offer + 博士毕业 + 入职。

🟦 阶段一 · 奠基期（M1–M4 · W1–W16 · D1–D112）

入门 → 6+ baseline → 选方向读穿 → Gap 分析 → Proposal → 方法 v1/v2/v3 → 论文骨架 → 收尾。

  • M1（W1–W4） 入门与环境：装环境、第一批论文精读（“5 段式”读法）、跑通第一个 baseline、建立每日节奏。
  • M2（W5–W8） baseline 铺开：跑通 6+ 个 baseline、横向对比、方向调研、文献地图。
  • M3（W9–W12） 选方向读穿：锁定细分方向、把方向读穿、Gap 分析、写出 Proposal。
  • M4（W13–W16） 方法成形：方法 v1 → v2（一次只改一处）→ v3 + 跨数据集验证、论文骨架（Intro/RW/Method）、pipeline 复现性、阶段一收尾。

🟩 阶段二 · 产出期（M5–M12 · W17–W48 · D113–D336）

第一篇论文完稿投稿 + 竞赛 + 第二/三课题 + GitHub 开源运营 + 首批冷邮件。

  • M5（W17–W20） 主实验全面铺开：实验矩阵 + wandb、三数据集多 seed、跨数据集 + 迁移、8 类消融、Method+Experiment 章定稿。
  • M6（W21–W24） 论文 v1 完整草稿 + 竞赛启动：Abstract/图表/整合、mock review + rebuttal、竞赛多 trick、选刊 + Cover Letter → “可投稿”。
  • M7（W25–W27） 论文打磨 + 正式投稿 + 竞赛冲刺：数字审计、投稿系统、点 Submit + arXiv、MAE/SAHI/ensemble、竞赛复盘。
  • M8（W29–W32） 竞赛收口 + 第二课题立项 + GitHub 公开运营：技术报告/开源、从 Limitation 挖第二课题、双语 README/Colab demo/引流。
  • M9（W33–W36） 第二篇推进：第二课题实验、方法迭代、结果积累。
  • M10（W37–W40） 第二篇完稿：实验补全、论文成形。
  • M11（W41–W43） 第二篇投稿 + 第三课题启动。
  • M12（W45–W48） 阶段二收尾：开源运营、首批冷邮件、阶段二总结。

🟨 阶段三 · 深化期（M13–M18 · W49–W74 · D337–D518）

联系空天院（破冰冷邮件）+ 访问 / 远程合作 + 成果积累 + 第三篇。

  • M13（W49–W52） 空天院破冰：精准定位目标老师（孙显/付琨/王超组）、写破冰冷邮件、建立初步联系。
  • M14（W53–W56） 联系深化：跟进、展示成果、为访问/合作铺垫。
  • M15（W57–W60） 访问 / 远程合作：暑期访问或远程合作落地、融入课题。
  • M16（W61–W65） 合作成果推进：合作课题实验、成果积累。
  • M17（W66–W69） 成果深化：第三篇推进、与空天院老师的实质联系。
  • M18（W70–W74） 阶段三收尾：成果整合、推荐信铺垫、阶段三总结。

🟥 阶段四 · 冲刺期（M19–M24 · W75–W104 · D519–D730）

求职拿 offer + 博士论文定稿/答辩/毕业 + 入职 + 收尾 + 24 个月终极复盘 + 计划终点。 —— 双线收口。

  • M19（W75–W78） 求职启动：简历/作品集打磨、岗位调研、内推铺垫。
  • M20（W79–W82） 投递 + 面试准备：投递空天院及备选、面试题准备、模拟面试。
  • M21（W83–W87） 面试 + offer：技术面/综合面、谈 offer、空天院 offer 落定。
  • M22（W88–W91） offer 落定 + 博士论文推进：接 offer、博士论文写作推进（博士线提速）。
  • M23（W92–W95） 博士论文定稿 / 送审：导师反馈 → 修改 → 定稿 → 送外审、模拟答辩、M23 月复盘。
  • M24（W96–W104） 收官月：外审意见修改 → 答辩准备 → 🎓 博士答辩通过 = 博士毕业 → 入职手续 → 搬家 → 社交收尾 → 知识归档 → 24 个月终极复盘（≥6000 字） → 🎉 W104 计划正式完结（计划终点）。
