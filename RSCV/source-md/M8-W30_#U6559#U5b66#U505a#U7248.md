# D197 周一 · 从第一篇 Limitation 挖第二课题候选

> 上午回顾第一篇的 Limitation & Future Work、整理候选来源清单;中午挑 3 个最有潜力的方向;晚上每个写 1 段 mini-proposal。
>
> **预期管理**:M8 第二课题立项周开始。今天从第一篇 Limitation 挖第二课题候选。提醒:**最自然的来源=第一篇做不完的事**(你写的 Limitation + mock reviewer 指出的不足),挖出来形成"系列"展示持续深耕;★校准——优先选**能复用第一篇资产的、小而硬的延伸**(如光学旋转检测→SAR旋转检测,用上你的SAR技能),别跳到全新大方向(浪费积累、超单卡);挑3个候选,每个写200字mini-proposal说清"接第一篇哪个口子、为什么小而硬"。

## 上午段 · 回顾第一篇 Limitation & Future Work,整理候选来源

**① 先垫概念(第二课题最自然的来源:第一篇的"没做完")**:
- **第二课题最自然、最稳的来源,就是第一篇做不完的事**。你第一篇论文的 Limitation(局限性)和 Future Work(未来工作)——既有你自己写的,也有 mock reviewer 指出的不足——**就是第二课题的金矿**。
- **为什么从 Limitation 挖第二课题(三重好处)**:① **自然延续**——Limitation 是你的工作"还差什么",顺着它做就是自然的下一步;② **形成系列**——第一篇解决 X、第二篇解决 X 的某个局限或延伸到新场景,两篇形成连贯的"系列",展示你在一个方向的持续深耕;③ **复用积累**——延伸第一篇,你的代码框架、领域知识、实验经验都能复用,做得又快又稳。**这是高产研究者的常用打法**:不是每篇都从零开始找全新方向,而是顺着已有工作不断延伸、深挖。
- **"系列工作"对你的战略价值(对接空天院)**:想象你将来联系空天院——"我在遥感旋转检测/SAR 这个方向做了两篇连续的工作(第一篇做光学旋转检测,第二篇延伸到 SAR 跨模态)"——这传递的是"我在这个领域有持续的积累和产出能力"。**一个连贯的研究故事(系列),远胜于一堆不相关的零散尝试**——它塑造的是你在特定方向的学术身份和深度,正是顶尖机构看重的。所以第二课题选"第一篇的自然延伸",不只是为了快,更是在构建你的长期定位。
- **候选来源清单怎么整理**:把第一篇所有的"没做完/做不好/可延伸"的点列出来——① 你写的 Limitation(方法在什么情况下还不够好);② Future Work(你提到的未来方向);③ mock reviewer 指出的不足(他们说"你没做 X""你在 Y 上不够好");④ 你做实验时发现但没深入的现象。**穷举这些,就是第二课题的候选来源池**。

**② 手把手带做**:
1. 回顾第一篇的 Limitation & Future Work(你写的 + mock reviewer 指出的)。
2. 整理成"第二课题候选来源"清单(穷举所有可延伸的点)。
3. 标注每个候选接第一篇的哪个口子。

**③ 合格样例**:一份"第二课题候选来源"清单,穷举了第一篇可延伸的点(Limitation/Future Work/reviewer 意见/未深入的现象)。

**④ 常踩的坑(★校准)**:
- **跳到一个全新的大方向(如"做个基础模型")** → 浪费第一篇积累的框架/知识,且可能超单卡。优先选能复用第一篇资产的、小而硬的延伸。
- **候选来源没穷举,凭印象想一两个** → 系统回顾 Limitation/Future Work/reviewer 意见,穷举候选池。

**⑤ 卡住自救(决策树)**:Limitation 里挖不出好候选?→ 重点看 mock reviewer 提的"你没做的""你做不好的"那些点(外部视角往往指向真实的可延伸方向);第一篇 Limitation 写得太简略?→ 回想实验中发现的、方法表现差的场景/数据,那些就是可延伸的口子。

**⑥ 今天(这一步)你同时学会了什么**:你学会**从第一篇 Limitation 系统挖掘第二课题候选**。**做了**(回顾 Limitation + 整理候选来源清单)、**学了**(第二课题从第一篇延伸最自然、形成系列、复用积累)、**会了**(从已有工作中识别可延伸的研究方向)。

## 中午段 · 从清单中挑 3 个最有潜力的方向

**① 先垫概念**:候选来源池里可能有不少点,**挑出 3 个最有潜力的**——按"① 延伸性(接第一篇)② 可行性(数据/代码可复用、单卡可做)③ 价值/兴趣"初步筛选。**先挑 3 个(而非 1 个),给决策留余地**(D198 详细评估再从 3 个里选 1 个)。
- **为什么挑 3 个(而非直接定 1 个)**:选题是关键决策,不该凭第一感觉定。**先挑 3 个最有潜力的候选,D198 详细调研评估后再从中选 1 个**——给决策留比较的空间,避免冲动选了个其实不可行的。3 个是个好数字:够比较,又不至于评估不过来。
- **挑选的三个维度**:① **延伸性**——是第一篇的自然延伸吗(形成系列、复用积累);② **可行性**——数据拿得到吗?代码能复用吗?单卡 4090 跑得动吗?(避免选做不动的);③ **价值/兴趣**——有研究价值吗?你感兴趣能坚持吗?**初步用这三维从候选池筛出 3 个**。

**② 手把手带做**:
1. 从候选来源清单里,按延伸性/可行性/价值初步筛。
2. 挑出 3 个最有潜力的方向。
3. 确认这 3 个都是"小而硬、能复用第一篇资产"的。

**③ 合格样例**:从候选池挑出 3 个最有潜力的方向(都小而硬、能复用第一篇资产)。

**④ 常踩的坑**:挑的候选复用度低(和第一篇差异大)→ 优先选能复用框架的(否则失去"快"的优势);只挑 1 个没留比较余地 → 挑 3 个,D198 评估后再选。

**⑤ 卡住自救**:候选太多难取舍?→ 优先"第一篇自然延伸 + 代码可复用 + 单卡可做"的;不确定哪个有潜力?→ 都先留着进 3 个候选,D198 详细评估。

**⑥ 今天(这一步)你同时学会了什么**:你**初步筛出了 3 个候选方向**。**做了**(从候选池挑 3 个)、**学了**(挑 3 个留决策余地、三维度初筛)、**会了**(从候选中识别最有潜力的方向)。

## 晚上段 · 每个候选写 1 段 mini-proposal(200字)

**① 先垫概念**:给 3 个候选各写一段 ~200 字的 **mini-proposal**——简述这个方向"做什么、接第一篇的哪个口子、为什么是小而硬的、怎么复用第一篇资产"。**mini-proposal 是候选的"快速画像"**,帮你(和 D198 的评估)看清每个候选的轮廓。
- **mini-proposal 写什么(200字够说清)**:① **做什么**——这个课题要解决什么问题;② **接第一篇哪个口子**——它对应第一篇的哪个 Limitation/延伸;③ **为什么小而硬**——为什么它是个聚焦、可做、有价值的课题(而非宽泛或做不动的);④ **怎么复用第一篇资产**——能复用哪些代码/知识/经验。**200 字精炼地说清这四点,就是一个候选的清晰画像**。
- **为什么要写 mini-proposal(而非只在脑子里想)**:写下来,能逼你把每个候选想清楚(模糊的想法写成文字时,漏洞和优势都会显现);也方便 D198 评估时比较 3 个候选。**写 mini-proposal 是"快速验证想法清晰度"的方式**——写得出清晰 mini-proposal 的候选,说明你想透了;写不出的,说明还模糊(可能不够成熟)。

**② 手把手带做**:
1. 给 3 个候选各写一段 ~200 字 mini-proposal(做什么/接哪个口子/为什么小而硬/怎么复用)。
2. 写清楚每个候选的轮廓。
3. 写不出清晰 mini-proposal 的候选,标记(可能还不成熟)。

**③ 合格样例**:3 段 mini-proposal,每个能说清"它接第一篇的哪个口子、为什么是小而硬、怎么复用第一篇资产"。

**④ 常踩的坑**:mini-proposal 写得空泛(没说清接哪个口子)→ 明确对应第一篇的哪个 Limitation;只写"做什么"不写"为什么小而硬/怎么复用" → 四点都要写清。

**⑤ 卡住自救**:某候选写不出清晰 mini-proposal?→ 说明它还模糊/不够成熟,要么再想清楚、要么换一个更清晰的候选;不知怎么写?→ 套"做什么+接哪个口子+为什么小而硬+怎么复用"四点。

**⑥ 今天(这一步)你同时学会了什么**:你**给候选写了 mini-proposal**。**做了**(3 段 mini-proposal)、**学了**(mini-proposal 是候选快速画像、写下来验证清晰度)、**会了**(精炼地刻画一个研究方向)。

> **技能卡｜从 Limitation 挖第二课题**:最自然来源=第一篇做不完的事(你的Limitation+reviewer指出的不足)。延伸成"系列"(持续深耕,对接空天院有说服力)+复用积累(快)。★校准:优先小而硬、单卡可做、能复用第一篇资产的延伸(如光学→SAR跨模态),别跳全新大方向。

> **技能卡｜mini-proposal**:给每个候选写~200字快速画像:做什么+接第一篇哪个口子+为什么小而硬+怎么复用第一篇资产。写下来逼自己想清楚,写不出清晰mini-proposal的候选=还不成熟。给决策(D198)提供比较依据。

> **今日交付**:✅ 3 个候选方向 ✅ mini-proposal ×3。

# D198 周二 · 候选调研 + 评分矩阵选定第二课题

> 上午调研 3 个候选的文献(每个搜 5 篇泛读摘要);中午评估可行性(数据/代码复用/时间);晚上用评分矩阵决策选定第二课题。
>
> **预期管理**:今天调研3候选+评分矩阵决策选定第二课题。提醒:每个候选搜5篇相关论文泛读摘要(看这方向有没有人做、做到什么程度、有没有空间);评估可行性时**把"复用度/算力"作为重要权重**(复用度低的候选会失去第二课题"快"的优势,本该4个月做完);用评分矩阵(复用M3那张:创新/可行/匹配/算力/9月内完成)给3候选打分,选最优——决策要客观(评分),别凭一时偏好。

## 上午段 · 调研 3 个候选的文献(每个 5 篇泛读)

**① 先垫概念(候选调研:看方向的"竞争态势")**:
- 对 3 个候选,各搜 5 篇相关论文、**快速泛读摘要**——目的是了解这个方向的"竞争态势":有没有人做?做到什么程度?还有没有你的空间(尤其单卡能做的空间)?
- **为什么调研(避免选错方向)**:① **看有没有空间**——如果某方向已经被做烂了(大量论文、SOTA 很高很卷),你单卡难有空间;如果是个较新、较少人做的口子,机会更大;② **看可行性**——看别人怎么做的(用什么数据、什么方法),判断你能不能复用第一篇资产做;③ **避免重复造轮子**——确认你的想法没被完全做过(否则白做)。**调研是选题前的"侦察",避免选个没空间或做不动的方向**。
- **泛读摘要即可(快速侦察)**:这一步不用精读(精读是定方向后 D202 的事),**每个候选搜 5 篇、快速泛读摘要**,把握"这方向有人做吗、做到什么程度、有没有空间"即可。3 个候选 × 5 篇 = 15 篇摘要,快速过一遍。

**② 手把手带做**:
1. 对 3 个候选各搜 5 篇相关论文。
2. 快速泛读摘要(看方向的竞争态势:有人做吗、做到什么程度、有空间吗)。
3. 记录每个候选的调研发现(空间大小、可行性线索)。

**③ 合格样例**:3 个候选各完成 5 篇文献泛读,了解了每个方向的竞争态势和你的空间。

**④ 常踩的坑**:调研时精读每篇(太慢)→ 这一步泛读摘要即可,快速侦察;只看有没有人做不看有没有空间 → 重点判断"单卡还有没有你的空间"。

**⑤ 卡住自救**:某方向论文太多太卷?→ 可能空间小,优先选较新、较少人做的口子;某方向几乎没人做?→ 确认是"有价值但少人做"(机会)还是"没价值所以没人做"(陷阱)。

**⑥ 今天(这一步)你同时学会了什么**:你学会**调研候选方向的竞争态势**。**做了**(3 候选各 5 篇泛读 + 记录发现)、**学了**(调研是选题侦察、看空间和可行性、泛读快速)、**会了**(评估一个研究方向的机会和可行性)。

## 中午段 · 评估可行性(数据 / 代码复用度 / 时间成本)

**① 先垫概念**:对 3 个候选,具体评估**可行性**——① 数据集拿得到吗?② 代码复用度多高(能复用第一篇多少)?③ 时间成本(单卡多久能做完)?**复用度和算力是关键权重**——第二课题的优势就是"快"(复用第一篇),如果选个复用度低的,就失去了这个优势。
- **为什么"复用度"是第二课题的核心考量**:第二课题预期 4 个月做完(远快于第一篇 8 个月),靠的就是复用第一篇的代码框架、领域知识、实验经验。**如果某候选和第一篇差异太大(代码要大改、领域要重学),就失去了"快"的优势,变回"几乎从零"**——那不如不选它。所以评估时,**把"代码复用度"作为重要权重**:优先选能大量复用第一篇资产的候选。
- **算力可行性(单卡约束)**:评估每个候选在你单张 4090 上做得动吗——数据量多大?模型多大?训练要多久?**确认单卡能在合理时间内做完**(别选个需要多卡/超大算力的)。这呼应你一贯的"小而硬、单卡可做"原则。

**② 手把手带做**:
1. 对 3 个候选评估:数据可得性、代码复用度、时间成本、算力可行性。
2. 重点看复用度和算力(第二课题要"快且单卡可做")。
3. 记录评估结果。

**③ 合格样例**:3 个候选的可行性评估完成(数据/复用度/时间/算力),复用度和算力作为重点。

**④ 常踩的坑**:只看创新不看可行性 → 复用度/算力是第二课题的关键;选了复用度低的候选 → 失去第二课题"快"的优势(本该 4 个月做完变回从零)。

**⑤ 卡住自救**:不确定复用度?→ 想"用第一篇的代码做这个候选,要改多少"(改得少=复用度高);不确定算力?→ 估算数据量和模型大小,对比第一篇(类似规模=单卡可做)。

**⑥ 今天(这一步)你同时学会了什么**:你学会**评估候选的可行性(重点复用度/算力)**。**做了**(3 候选可行性评估)、**学了**(复用度是第二课题核心、算力可行性、第二课题要快且单卡)、**会了**(从可行性角度评估候选)。

## 二、实用工具 — 候选评分 + 复用框架 toy
```python
# ① 候选评分（复用度/算力高权重，选第二课题）
def score_candidate(c, w={"data":0.15,"reuse":0.25,"time":0.15,"compute":0.25,"novelty":0.20}):
    # reuse=代码复用度, compute=单卡可行性，权重最高（第二篇更快+可持续）
    return sum(c[k]*w[k] for k in w)
cands = {
    "光学→SAR旋转检测": {"data":4,"reuse":5,"time":4,"compute":4,"novelty":4},
    "小样本旋转检测":   {"data":3,"reuse":4,"time":3,"compute":4,"novelty":4},
}
best = max(cands, key=lambda c: score_candidate(cands[c]))
for c,v in cands.items(): print(f"{c}: {score_candidate(v):.2f}")
print(f"→ 选定第二课题: {best}（复用度+单卡可行性权重最高）")
```
