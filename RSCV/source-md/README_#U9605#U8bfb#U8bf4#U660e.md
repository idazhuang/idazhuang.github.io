## 三、每周文件长什么样（统一结构）

每个周文件 = **满深度正文 + 加厚补充包**，约 26–44K 字。

**正文**：7 天 × 每天 3 时段（上午段 / 中午段 / 晚上段）= **21 个时段单元**。每个时段单元固定 **六块**：
1. **先垫概念** —— 用类比讲清"为什么现在做这个""它和通用 CV 有什么不同"；
2. **手把手带做** —— 具体命令 / 代码 / 操作；
3. **合格样例** —— 做对了长什么样；
4. **常踩的坑** —— 容易出错的地方 + 怎么避开；
5. **卡住自救（决策树）** —— 卡住了照着这个判断往下走；
6. **今天你同时学会了什么** —— 做了 / 学了 / 会了，偶附"**技能卡**"小结。

每天还有：开头的**「预期管理」**（今天要做什么、提醒）+ 结尾的**「今日交付」**（今天产出了什么）。

**加厚补充包**（每周文件末尾）四样：① 合格范例（照着填就能用）；② 完整可运行代码 + 预期输出；③ 每日自测；④ 报错 / 坑速查表。

## 四、贯穿全程的"战略定位 / 诚实校准"（最重要）

这是整份手册的灵魂，每一周都在落实：

- **战略定位（核心）**：你是零遥感基础 + 单张 RTX 4090 + 导师不支持 + 目标空天院。所以**不在"更大基础模型"主轴上和 RingMoE / 空天·灵眸硬拼**；发力点 = **下游特化 / 高效适配（LoRA）/ 评测 / 鲁棒性 / 跨域泛化 / 小样本 / SAR 难题 / 通用 CV 嫁接**。**单张 4090 写进论文当亮点**（高效、可复现）。
- **两条线并行不混**：**博士毕业靠博士论文（原方向）**，**转型求职靠遥感成果**——这是两条线，精力清醒分配、并行推进、绝不混为一谈。
- **对外连接 / 运营**定位为"强作品的自然放大"（副线、控时），核心始终是**研究产出**。
- **事实订正**（散落各周）：RingMo 归属空天院孙显组（非自动化所）；SARCLIP 替换为王超组 2025 TACMT；天智杯非空天院主办（练手可以、不作破冰理由）等。

## 五、📚 完整内容总览（四个阶段 · M1–M24）

整个 24 个月分四个阶段，一条主线：**从零基础 → 第一/二/三篇论文 + 竞赛 + 开源 → 联系空天院 + 访问/合作 → 求职拿 offer + 博士毕业 + 入职**。

**入门 → 6+ baseline → 选方向读穿 → Gap 分析 → Proposal → 方法 v1/v2/v3 → 论文骨架 → 收尾。**
- **M1（W1–W4）** 入门与环境：装环境、第一批论文精读（"5 段式"读法）、跑通第一个 baseline、建立每日节奏。
