## 晚上段 · 第三课题 baseline 全面推进启动（数据集 1 的 baseline）

**① 先垫概念（baseline 全面推进是什么）**
- 第三课题立项后（W50），进入**正式实验的第一步：baseline 全面推进**——目标是在 **2 个数据集上跑 5 个 baseline + your method v1**。为什么要跑多个 baseline：① **对比的基础**（你的方法要和多个有代表性的 baseline 比，才有说服力）；② **2 个数据集**（验证泛化性，不是只在一个数据集上有效）。今晚先在**数据集 1** 上铺开 baseline（基于 W50 搭好的框架）。
- **baseline 选什么**：选该方向有代表性的、公认的方法（如经典方法 + 近期 SOTA + 你方法的直接对比对象），5 个左右，覆盖不同思路。

**② 手把手带做**：① 确定 5 个 baseline（有代表性的、公认的方法，含你方法的直接对比对象）；② 在数据集 1 上启动这些 baseline 的训练（基于 W50 框架）；③ 用实验管理工具追踪（多个实验并行）；④ 确保每个 baseline 配置合理、可复现；⑤ 今晚启动数据集 1 的 baseline（跑起来，明后天出结果）。
**③ 这一步合格的样子**：数据集 1 的 5 个 baseline 启动（配置合理、可复现、用实验管理追踪），第三课题正式实验铺开。
**④ 最常踩的坑**
- baseline 选太少/不代表性 → 5 个左右、有代表性（经典+SOTA+直接对比）。
- baseline 配置不一致（不公平）→ 统一的训练配置（公平对比）。
- 不用实验管理（实验乱）→ 用工具追踪（多实验并行）。

**⑤ 卡住怎么自救（决策树）**：选哪 5 个 baseline？→ 该方向经典方法 + 近期 SOTA + 你方法的直接对比对象；单卡跑不动多个？→ 串行跑/控制规模/用预训练。
**⑥ 今天（这一步）你同时学会了什么**：你**启动了第三课题的 baseline 全面推进**。**做了**（确定 5 个 baseline + 数据集 1 启动 + 实验管理追踪 + 配置合理可复现）、**学了**（baseline 全面推进=2 数据集×5 baseline、多 baseline 是对比基础、统一配置公平、实验管理）、**会了**（为新课题铺开严谨的 baseline 实验）。

> **技能卡｜baseline 全面推进**：第三课题立项后正式实验第一步——在 **2 个数据集上跑 5 个 baseline + your method v1**。多 baseline（经典+近期 SOTA+你方法的直接对比对象，覆盖不同思路）=对比的说服力基础；2 数据集=验证泛化（不只一个数据集有效）。要点:统一训练配置（公平对比）、可复现、用实验管理工具追踪多个并行实验。基于已搭好的框架（复用前两课题）推进。

## 二、完整可运行代码 · baseline 实验矩阵追踪器（+ 预期输出）

> 这个脚本追踪第三课题的 baseline 实验矩阵（2 数据集 × 5 baseline + your method v1），显示完成进度、并算出 your method v1 相比最强 baseline 的提升。集中实验日跑一下，一眼看清进度和效果。

```python
#!/usr/bin/env python3
# baseline_matrix.py —— 第三课题 baseline 实验矩阵追踪器
# 指标越高越好（如 mAP/Acc）；None 表示还没跑完
matrix = {
    "Baseline-A":       {"数据集1": 72.1, "数据集2": 68.3},
    "Baseline-B":       {"数据集1": 73.5, "数据集2": 69.0},
    "Baseline-C(SOTA)": {"数据集1": 75.2, "数据集2": 70.8},
    "Baseline-D":       {"数据集1": 74.0, "数据集2": 69.5},
    "Baseline-E":       {"数据集1": 74.8, "数据集2": 70.1},
    "Your method v1":   {"数据集1": 76.5, "数据集2": 72.0},
}

def track(matrix):
    datasets = ["数据集1", "数据集2"]
    done = sum(1 for m in matrix.values() for d in datasets if m.get(d) is not None)
    total = len(matrix) * len(datasets)
    print(f"=== baseline 实验矩阵（完成 {done}/{total}）===\n")
    header = "方法".ljust(20) + "".join(d.ljust(10) for d in datasets)
    print(header); print("-" * len(header))
    for name, m in matrix.items():
        row = name.ljust(20) + "".join((f"{m[d]:.1f}" if m.get(d) is not None else "—").ljust(10) for d in datasets)
        print(row)
    # your method vs 最强 baseline
    ym = matrix.get("Your method v1", {})
    baselines = {k: v for k, v in matrix.items() if k != "Your method v1"}
    print("\n--- Your method v1 相比最强 baseline 的提升 ---")
    for d in datasets:
        best_bl = max((v[d] for v in baselines.values() if v.get(d) is not None), default=None)
        if ym.get(d) is not None and best_bl is not None:
            delta = ym[d] - best_bl
            sig = "✅ 有提升" if delta > 0 else "⚠️ 无提升,需迭代"
            print(f"  {d}: v1={ym[d]:.1f} vs 最强baseline={best_bl:.1f} → +{delta:.1f} {sig}")

if __name__ == "__main__":
    track(matrix)
```

**预期输出**：
```
=== baseline 实验矩阵（完成 12/12）===

方法                数据集1     数据集2     
-----------------------------------------
Baseline-A          72.1      68.3      
Baseline-B          73.5      69.0      
Baseline-C(SOTA)    75.2      70.8      
Baseline-D          74.0      69.5      
Baseline-E          74.8      70.1      
Your method v1      76.5      72.0      

--- Your method v1 相比最强 baseline 的提升 ---
  数据集1: v1=76.5 vs 最强baseline=75.2 → +1.3 ✅ 有提升
  数据集2: v1=72.0 vs 最强baseline=70.8 → +1.2 ✅ 有提升
```
> 解读：把你的 baseline + your method v1 在 2 个数据集上的指标填进 matrix，脚本显示完成进度、并算出 your method v1 相比最强 baseline 的提升。2 个数据集都有提升（+1.3/+1.2）说明 idea 有效且泛化好；若某数据集无提升，提示需迭代。注意 v1 是初版，有提升就是好信号、后续迭代优化；没提升也别灰心，分析原因迭代 v2。
