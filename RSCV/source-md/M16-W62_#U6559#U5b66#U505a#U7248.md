## 上午段 · ★ 第一次参加组会 + 做 5min 自我介绍

**① 先垫概念（组会自我介绍怎么做）**
- ★ **第一次参加组会，做 5min 自我介绍**——这是让全组人认识你的关键一刻。用你 W60/W61 准备的 5min PPT：① **你是谁**（姓名 + 学校 + 博士在读）；② **来自哪里 + 研究方向**（下游特化/高效适配/SAR 等）；③ **已有成果**（三篇论文 + 开源，展示研究能力）；④ **访问期间计划**（基于 1v1 目标，你想做什么、可能的合作方向）；⑤ **期待**（虚心学习、希望合作）。★ **专业而谦逊**——讲清你能带来什么（嵌单卡高效的差异化定位），但姿态谦逊（来学习、来合作）。同时**观察团队怎么开组会**（流程、节奏、谁汇报什么——熟悉团队的工作方式）。
- ★★ **远程模式**：线上组会做自我介绍（视频 + PPT 共享），同样讲清这 5 部分。

**② 手把手带做**：① 第一次参加组会（准时、带 PPT）；② 做 5min 自我介绍（你是谁/方向/成果/访问计划/期待）；③ 专业谦逊（嵌差异化定位 + 谦逊姿态）；④ 观察团队组会方式（流程/节奏）；⑤ 让全组人记住你。
**③ 这一步合格的样子**：第一次组会 + 自我介绍完成——5min 讲清了你是谁/方向/成果/访问计划、专业谦逊，全组人认识了你，也熟悉了组会方式。
**④ 最常踩的坑**

- 只讲成果不提访问计划（没针对性）→ 讲来这想做什么、合作方向。

**⑤ 卡住怎么自救（决策树）**：紧张？→ 你 W60/W61 练过,记要点自然讲;讲多久？→ 控 5min,重点突出;观察什么？→ 组会流程/谁汇报什么/团队节奏。

## 中午段 · 核心实验——团队数据预处理

**① 先垫概念（团队数据预处理）**
- 中午开始**核心实验**——第一步是**团队数据预处理**：① **了解团队数据**（空天院的数据：什么任务、什么格式、有什么特点——可能是内部数据或团队自采数据）；② **数据清洗/格式化**（把团队数据处理成你的方法能用的格式）；③ ★ **理解数据特性**（团队数据可能和公开数据不同——分辨率、传感器、标注方式等，理解差异）；④ **复用你的数据处理经验**（你处理过很多遥感数据）。**数据预处理是在团队数据上跑你方法的第一步——理解数据、处理好格式。**
- ★★ **远程模式**：远程访问团队数据（如团队提供数据访问），同样预处理。

**② 手把手带做**：① 了解团队数据（任务/格式/特点）；② 数据清洗/格式化（处理成你方法能用的格式）；③ ★ 理解数据特性（和公开数据的差异）；④ 复用你的数据处理经验；⑤ 数据预处理就绪。
**③ 这一步合格的样子**：团队数据预处理完成——了解了数据、清洗格式化好、理解了数据特性，数据就绪可用于实验。
**④ 坑**：① 不了解数据就处理（出错）→ 先了解任务/格式/特点；② 忽略数据特性差异（方法不适配）→ ★ 理解和公开数据的差异；③ 格式不对（方法跑不动）→ 处理成你方法能用的格式。
**⑤ 自救**：数据看不懂？→ 虚心问师兄数据的来源/格式/标注;特性差异？→ 看分辨率/传感器/标注方式和公开数据的不同。
**⑥ 今天（这一步）你同时学会了什么**：你**预处理了团队数据**。**做了**（了解数据 + 清洗格式化 + 理解特性 + 复用经验）、**学了**（团队数据预处理理解差异、处理好格式、复用经验）、**会了**（把团队数据处理成实验可用的格式）。

## 上午段 · 与师兄讨论实验方案

**① 先垫概念（怎么和师兄讨论实验方案）**
- 上午**与师兄讨论实验方案**——① **请教团队的经验**（团队在这个数据/问题上有什么经验、踩过什么坑、有什么建议——虚心学习）；② **讨论你的方法怎么适配**（你的方法[第三课题/你的方法]怎么用在团队数据上、需要怎么调整）；③ ★ **贡献你的想法**（你有通用 CV 的强能力 + 三篇遥感论文的经验，也能给团队带来视角——平等交流、互相启发）；④ **达成方案共识**（讨论出一个清晰的实验方案）。**和师兄讨论既是学习团队经验、也是贡献你的想法——融入团队工作、深化合作。**
- ★★ **远程模式**：视频/线上讨论，同样。

**② 手把手带做**：① 请教团队在这数据/问题上的经验（虚心）；② 讨论你的方法怎么适配（调整方向）；③ ★ 贡献你的想法（你的能力和视角）；④ 达成实验方案共识；⑤ 记录讨论结果。
**③ 这一步合格的样子**：与师兄讨论了实验方案——请教了团队经验、讨论了方法适配、贡献了想法，达成了清晰的实验方案。
**④ 最常踩的坑**
- 只请教不贡献想法（显被动）→ ★ 平等交流、贡献你的视角。
- 不虚心（显自大）→ 请教团队经验、谦逊。
- 讨论无共识（方案模糊）→ 讨论出清晰方案。

**⑤ 卡住怎么自救（决策树）**：讨论什么？→ 团队经验 + 你的方法怎么适配 + 你的想法;不好意思贡献想法？→ 你有真本事(通用 CV + 三篇论文),平等交流互相启发。
**⑥ 今天（这一步）你同时学会了什么**：你**和师兄讨论了实验方案**。**做了**（请教经验 + 讨论适配 + 贡献想法 + 达成共识 + 记录）、**学了**（讨论既学习团队经验也贡献想法、平等交流、达成方案）、**会了**（通过讨论融入团队工作、确定实验方案）。

## 中午段 · 核心实验——方法适配

**① 先垫概念（方法适配）**
- 中午**方法适配**——把你的方法适配到团队数据上：① **据讨论的方案适配**（按上午和师兄讨论的方案，把你的方法调整到能用于团队数据）；② **代码适配**（修改代码以处理团队数据的格式/特性，★ 大量复用你已有的代码）；③ **小规模验证**（先在小数据上验证适配后的方法能跑通）；④ **排查问题**（适配中的报错/不匹配，排查解决）。**方法适配是把"你的方法"用到"团队数据"上的关键一步。**
- ★★ **远程模式**：在团队服务器或你的 4090 上适配，同样。

## 二、完整可运行代码 · 访问周进展追踪器（+ 预期输出）

> 这个脚本追踪访问一周的核心进展（核心实验各阶段 + 团队协作 + 博士维护），并据"本周完成/下周计划/困难"自动生成周报草稿——把访问的周进展和周报系统化。

```python
#!/usr/bin/env python3
# visit_week_tracker.py —— 访问周进展追踪器 + 周报草稿生成
experiment = {  # 核心实验各阶段
    "数据预处理": True, "方法适配": True, "训练启动": True,
    "看初步结果": True, "深化/调整": True, "第一份结果整理": True,
}
collaboration = {"组会自我介绍": True, "与师兄讨论方案": True, "读团队草稿给反馈": True}
phd_daily_1h = [True, True, True, True, True, True, True]  # 每天博士维护1h

# 周报三要素
report = {
    "本周完成": "数据预处理+方法适配,团队数据上跑出第一份初步结果",
    "下周计划": "深化实验+做消融,推进合作点",
    "遇到困难": "你的方法在团队数据上某setting效果还不理想,想请教建议",
}

def track():
    def rate(d): 
        done = sum(1 for v in d.values() if v); return done, len(d), round(done/len(d)*100)
    e_done, e_tot, e_pct = rate(experiment)
    c_done, c_tot, c_pct = rate(collaboration)
    phd_days = sum(1 for v in phd_daily_1h if v)
    print("=== 访问周(W62)进展 ===\n")
    print(f"核心实验: {e_done}/{e_tot} = {e_pct}%")
    for k, v in experiment.items():
        print(f"   {'✅' if v else '□'} {k}")
    print(f"\n团队协作: {c_done}/{c_tot} = {c_pct}%")
    for k, v in collaboration.items():
        print(f"   {'✅' if v else '□'} {k}")
    print(f"\n★博士课题维护: {phd_days}/7 天 (每天1h)")
    print("\n" + "="*40)
    print("📧 周报草稿:")
    print(f"   本周完成了{report['本周完成']},")
    print(f"   下周计划{report['下周计划']}。")
    print(f"   目前{report['遇到困难']},想请教您是否有建议?")
    if e_pct == 100 and c_pct == 100 and phd_days == 7:
        print("\n🎉 本周融入+产出+博士维护全到位!发周报、计划W63。")
    else:
        print("\n→ 补齐未完成项,再发周报。")

if __name__ == "__main__":
    track()
```
