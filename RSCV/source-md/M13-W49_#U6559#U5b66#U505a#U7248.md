## 晚上段 · 第三课题文献检索（搜 10–15 篇 + A/B/C 分级）

**① 先垫概念（文献检索 + A/B/C 分级）**
- 确定候选方向后，**检索该方向的文献并分级**——在 Google Scholar 搜 10–15 篇相关论文，按相关度/重要性分 A/B/C 级：**A = 最相关、最核心（必精读）**；**B = 相关（泛读了解）**；**C = 背景/边缘（知道即可）**。分级让你**高效聚焦**——把精读精力放在 A 级（少而精），不被海量文献淹没。

**② 手把手带做**：① 针对候选方向，在 Scholar 搜 10–15 篇相关论文（关键词组合、看引用、看目标组的相关工作）；② 快速浏览每篇（标题/摘要/图），按相关度分 A/B/C 级（A 必精读、B 泛读、C 背景）；③ 标注每篇的"为什么这个级别"；④ 形成分级清单（A 级 3 篇左右，作明后天精读对象）；⑤ 优先把目标组的相关论文纳入（对接合作）。
**③ 这一步合格的样子**：检索了 10–15 篇第三课题文献、完成 A/B/C 分级，A 级约 3 篇（明后天精读），清单清晰。
**④ 坑**：① 搜一堆不分级（淹没）→ A/B/C 分级聚焦核心；② A 级标太多（精读不过来）→ A 级控制在 3 篇左右（少而精）；③ 漏了目标组的相关工作 → 优先纳入（对接合作方向）。
**⑤ 自救**：搜不到相关论文？→ 换关键词、看综述的引用、看目标组近作的参考文献；分不清级别？→ A=和你方向最直接相关的核心方法、B=相关、C=背景。
**⑥ 今天（这一步）你同时学会了什么**：你**高效检索并分级了第三课题文献**。**做了**（搜 10-15 篇 + A/B/C 分级 + A 级约 3 篇 + 优先纳入目标组工作）、**学了**（A/B/C 分级高效聚焦、复用 M3 方法论、A 级少而精、纳入目标组工作）、**会了**（快速锁定新课题方向的核心文献）。

## 二、完整可运行代码 · 候选 idea 评分器（+ 预期输出）

> 这个脚本帮你从 3 个候选 idea 中选优——给每个 idea 在四个维度（Gap 清晰度/单卡可行性/目标组关系/创新性）打分，加权算总分排序。下周 W50 选题时用，把"选哪个 idea"从拍脑袋变成有依据的对比。

```python
#!/usr/bin/env python3
# idea_scorer.py —— 第三课题候选 idea 评分器
# 维度与权重（可调）：Gap清晰度/单卡可行性/目标组关系/创新性
WEIGHTS = {"gap清晰": 0.25, "单卡可行": 0.30, "目标组关系": 0.25, "创新性": 0.20}

ideas = {
    "idea1 (speckle-aware跨模态)": {"gap清晰": 8, "单卡可行": 9, "目标组关系": 9, "创新性": 7},
    "idea2 (旋转检测few-shot)":    {"gap清晰": 7, "单卡可行": 8, "目标组关系": 6, "创新性": 8},
    "idea3 (跨域泛化新范式)":      {"gap清晰": 6, "单卡可行": 6, "目标组关系": 7, "创新性": 9},
}

def score(ideas, weights):
    print("=== 候选 idea 评分（满分 10）===\n")
    results = []
    for name, dims in ideas.items():
        total = sum(dims[k] * weights[k] for k in weights)
        results.append((name, total, dims))
    results.sort(key=lambda x: -x[1])
    for rank, (name, total, dims) in enumerate(results, 1):
        detail = " | ".join(f"{k}:{dims[k]}" for k in WEIGHTS)
        print(f"{rank}. {name}  → 加权总分 {total:.2f}")
        print(f"   {detail}")
    print(f"\n🏆 推荐选题：{results[0][0]}（总分 {results[0][1]:.2f}）")
    print("   注：评分是辅助，最终结合你的兴趣、把握和 toy 实验结果定。")

if __name__ == "__main__":
    score(ideas, WEIGHTS)
```

**预期输出**：
```
=== 候选 idea 评分（满分 10）===

1. idea1 (speckle-aware跨模态)  → 加权总分 8.40
   gap清晰:8 | 单卡可行:9 | 目标组关系:9 | 创新性:7
2. idea2 (旋转检测few-shot)  → 加权总分 7.30
   gap清晰:7 | 单卡可行:8 | 目标组关系:6 | 创新性:8
3. idea3 (跨域泛化新范式)  → 加权总分 6.85
   gap清晰:6 | 单卡可行:6 | 目标组关系:7 | 创新性:9
```
> 解读：把你的 3 个候选 idea 和各维度打分填进 ideas，脚本加权算分排序、推荐选题。注意权重里"单卡可行"和"目标组关系"占比高——这呼应你的两个核心约束（单卡 4090 + 第三课题要能对接目标组）。评分是辅助决策，最终结合你的兴趣、把握和下周 toy 实验的结果定。
