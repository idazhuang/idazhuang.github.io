## 上午段 · 精读 Zhu 2021《SAR Image Classification Using Deep Learning: A Survey》(第 1–3 遍)
**① 先垫概念(SAR 入门,务必先懂)**
- **SAR(Synthetic Aperture Radar,合成孔径雷达)**:卫星**自己发射微波、再接收地物反射的回波**来成像。和光学最根本的两点不同:① **主动成像**(不靠太阳光),所以**全天时全天候**——黑夜、阴天、云雾照拍;② 成的是"**雷达回波强度图**",和你眼睛看到的世界长得**完全不一样**(满屏颗粒、金属物超亮)。
- **"合成孔径"**:雷达天线很小,分辨率本该很差;但卫星一边飞一边连续测量,用算法把一路上的回波"拼"成一个**等效的超大天线(合成孔径)**,从而得到高分辨率。这就是名字的由来。
- **为什么 SAR 在国防/海洋监视里不可替代**:光学卫星一遇云、一到夜里就"瞎了",而 SAR 全天候全天时穿云透雾——对舰船监视、灾害应急、军事侦察这些"等不起天气"的场景,SAR 是刚需。**这也是空天院(原中科院电子所)长期深耕 SAR、且你把 SAR 当重要发力点的原因**——国家需求 + 强组 + 难题多。
- **SAR 特有的成像几何畸变(先有概念)**:因为是侧视、按"距离"成像,SAR 有光学没有的几何畸变——**叠掩**(高处目标"倒"向雷达,山顶比山脚先成像)、**阴影**(被遮挡处无回波,纯黑)、**透视收缩**(朝向雷达的坡面被压缩)。这些畸变让 SAR 解译更难,但也是 SAR 信息的一部分。
- **空天院(原中科院电子所)在 SAR 领域是国内最强团队之一**——这也是你瞄准它、且 SAR 是你重要发力点的原因。

## 晚上段 · Zhu 2021 第 4–5 遍 + 记牢"SAR 三大特有挑战"
**① 先垫概念(三个你将反复用到的 SAR 关键词)**
- **speckle(相干斑噪声)**:SAR 图满屏的"颗粒/麻点"。它是**相干成像的固有产物**,而且是**乘性噪声**(下一节细讲)——这是 SAR 去噪/解译的头号难题。
- **极化(polarization)**:雷达波有偏振方向(HH/HV/VH/VV)。多极化提供额外信息(不同地物对不同极化响应不同),是 SAR 特有的"多通道",但**和光学的多光谱完全是两码事**。
- **方位角敏感(azimuth sensitivity)**:同一目标,雷达从不同方位照射,回波差异巨大——同一艘船换个角度"长相"就变,这让 SAR 目标识别比光学难。
**② 带做**:读 Section 3–4(传统方法+深度学习方法)与 Conclusion,补完笔记;在笔记里专门列"**SAR 三大特有挑战**"(speckle/极化/方位角),每条一句话。
**③ 合格样例**:笔记有"SAR 三大特有挑战"清单 + 完整 5 段。
**④ 坑**:把 SAR 多极化当成光学多光谱来理解——机理不同,务必分开记。
**⑤ 卡住**:极化/方位角太抽象 → 现在只需记住"它们是 SAR 独有、且都很难"的方向标,具体含义随后续论文加深。
**⑥ 今天(这一步)你同时学会了什么**:你掌握了**SAR 的三大特有难题**——这三条**就是你"SAR 小而硬选题"的候选清单**(speckle 鲁棒、极化利用、方位角不变性都是个人可做的硬题)。**做了**(SAR 综述完整笔记)、**学了**(SAR 成像 + speckle/极化/方位角)、**会了**(把"领域难题"读成"我的选题候选")。这三大难题的共同点是:**它们都源于 SAR 的物理本质、且都还没被"大模型时代"很好解决**——这意味着,即便你没有海量算力,只要在这些 SAR 特有难题上做出针对性的巧思(而非和大模型拼规模),就能做出有价值、能发表的工作。把这三条抄进你的"选题候选池",M2/M3 收敛方向时会反复回来看它们。

## 中午段 · 理解"SAR 数据的几种形态"(复数/幅度/强度)
**① 先垫概念**:
- SAR 原始数据常是**复数(complex)**:每个像素有实部+虚部(含幅度和相位信息)。
- **幅度(amplitude)** = 复数的模;**强度(intensity)** = 幅度的平方。**相位**含干涉信息(InSAR 用,王超组方向之一)。
- 做图像分类/检测时,常用**幅度/强度图**;但要知道复数和相位里还有更多信息(这是 SAR 特有、可挖的)。
- **相位信息为什么是"宝藏"**:光学图像没有相位这个概念,但 SAR 的相位记录了回波的精确路径长度信息。**两次成像的相位差**能测出地表毫米级的形变(InSAR/干涉测量),用于监测地震、沉降、滑坡——这是 SAR 独有的、价值极高的能力,也是王超组等深耕的方向。你现在做分类/检测只用幅度图就够,但要**知道"相位里还有一整个维度的信息没用上"**,这本身就是未来可挖的空间(如何在检测/识别中利用相位/复数信息)。
- **数据形态决定你怎么处理**:拿到复数 SLC,你要先取幅度再 log;拿到的已是幅度 PNG,直接 log 归一化即可。**搞清形态是 SAR 处理的第一步**,所以今天要确认并记进 README。
**② 带做**:确认你下载的 SAR 数据是什么形态(复数 SLC?幅度图?),记进数据集 README。

## 晚上段 · 写 SAR 预处理脚本(幅度 → log 变换 → 归一化 → PNG)
**① 先垫概念(为什么 SAR 必须 log 变换,务必懂)**
- SAR 图像**动态范围极大**:强散射体(金属船、建筑)的像素值可能是弱散射体(平静水面)的**上万倍**。直接线性显示 → 几个亮点占满,其余全黑,看不出细节。
- **log 变换**(`20*log10(amplitude+1)`,即转成"分贝/dB")**压缩动态范围**,让强弱都可见。这是 SAR 处理的**第一步基础操作**,几乎每篇 SAR 工程都做。
- **不只是为了"好看",更是为了"训得动"**:神经网络对输入数值范围敏感。如果直接喂动态范围跨好几个数量级的原始 SAR 幅度,绝大多数像素挤在很小的数值区间、少数极亮点拉爆,网络很难学到有效特征(梯度被极值主导)。log 变换把数值压到合理范围,**让网络能正常学习**——所以 log 既是可视化的需要,更是入网预处理的需要。
- **log 之后还要归一化**:log(dB) 之后通常再归一化到 0–255 或 0–1,并配合 1%/99% 分位裁剪去掉极端亮点,进一步稳定数值。**这套"取幅度→log→分位裁剪→归一化"的预处理链,是你做任何 SAR 任务的标准开局**,以后每次都要先做。
**② 手把手带做**:在 `20-代码实验/utils/sar_preprocess.py` 写:① 读 SAR 数据 → ② 若为复数则取幅度 → ③ `img_db = 20*np.log10(amp+1)` → ④ 归一化到 0–255(`(x-min)/(max-min)*255`,可加分位裁剪去极值)→ ⑤ 存 PNG。
**③ 合格样例**:输出 PNG **能看清结构**(船、海岸、纹理),不是一片黑或一片白。对比"不做 log 直接归一化"的版本,直观感受 log 的作用。
**④ 常踩的坑**:① 不做 log 直接归一化→图几乎全黑;② `log(0)` 报错→记得 `+1`;③ 不裁极值→个别超亮点把整体拉暗,可用 1%/99% 分位裁剪。
**⑤ 卡住自救**:读不出 SAR 数据格式 → 用数据集提供的读取示例;复数读取不会 → 先拿已是幅度/PNG 的版本练 log+归一化这步,核心是体会动态范围压缩。
**⑥ 今天(这一步)你同时学会了什么**:你写出了**第一个 SAR 预处理脚本**,真正理解了"SAR 动态范围大→必须 log 压缩"这个 SAR 工程的第一性常识。这一步以后你做任何 SAR 任务都要先做。**做了**(`sar_preprocess.py` + 可读 SAR 图)、**学了**(复数/幅度/强度、动态范围、log/dB 变换)、**会了**(把 SAR 原始数据处理成可训练/可视的图,以及分位裁剪去极值)。

## 晚上段 · 用裸 PyTorch 搭 SAR 船舶分类 baseline(理解训练内部)
**① 先垫概念(为什么这次不用 MMxx)**:
- W2 你用 MMRotate(高度封装)跑了检测;但封装太厚,你看不见"训练循环"里到底发生什么。今天**用最朴素的 PyTorch 原生代码**搭一个 SAR 分类器,**亲手写出训练的五个核心步骤**,把"训练"这个黑箱彻底打开。
- 训练循环五步(背下来,这是所有深度学习训练的心脏):**① 取一批数据 → ② 前向得到预测 → ③ 算 loss → ④ 反向传播 `loss.backward()` → ⑤ 优化器更新 `optimizer.step()`**(每步后 `optimizer.zero_grad()`)。
- **为什么一定要亲手写一遍裸 PyTorch**:框架(MMxx)把这五步都藏在配置背后,你只改 config 就能跑,但出了问题(loss 不降、梯度异常)你不知道去哪查。亲手写一遍,你就**彻底看清了"训练"的内部机制**——以后无论用什么框架,你都知道它底层在做这五步,调试时能直接定位"是前向、loss、还是反向更新出了问题"。**这是从"调包侠"到"懂原理"的关键一跃**。
- **裸 PyTorch 和框架不是对立的**:简单任务(SAR 分类)用裸 PyTorch 看得清、改得快;复杂任务(检测)用框架省事。理解了裸 PyTorch,你才能真正驾驭框架(框架只是这五步的封装+一堆工程便利)。
**② 手把手带做**(`20-代码实验/sar_cls/train.py`,用 ResNet-18):
```python
import torch, torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import models, transforms, datasets

device = "cuda"
tf = transforms.Compose([transforms.Grayscale(3), transforms.Resize((128,128)),
                         transforms.ToTensor()])   # SAR 是单通道，复制成 3 通道喂 ResNet
train_set = datasets.ImageFolder("OpenSARShip/train", transform=tf)   # 按类别分文件夹
train_loader = DataLoader(train_set, batch_size=64, shuffle=True)     # 4090 显存充裕

model = models.resnet18(weights="IMAGENET1K_V1")
model.fc = nn.Linear(model.fc.in_features, len(train_set.classes))    # 改成你的类别数
model = model.to(device)

opt = torch.optim.Adam(model.parameters(), lr=1e-3)
crit = nn.CrossEntropyLoss()

for epoch in range(20):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()
        out = model(x)              # ② 前向
        loss = crit(out, y)         # ③ 算 loss
        loss.backward()             # ④ 反向
        opt.step()                  # ⑤ 更新
    print(f"epoch {epoch} loss {loss.item():.4f}")
```
**③ 合格样例**:训练能跑、loss 逐 epoch 下降;终端每轮打印的 loss 在变小。
**④ 常踩的坑**:① SAR 是单通道,直接喂 ResNet(要 3 通道)会报维度错→`Grayscale(3)` 复制成 3 通道;② 忘了 `optimizer.zero_grad()`→梯度累加,训练乱;③ 数据没按"每类一个文件夹"组织→`ImageFolder` 读不出标签;④ 把数据放 CPU、模型放 GPU→`.to(device)` 要一致。
**⑤ 卡住自救**:loss 不降→先把 lr 调到 1e-4,或在极小子集(每类 20 张)上过拟合验证模型能学;读数据报错→先 `print(len(train_set), train_set.classes)` 确认数据被正确读入。
**⑥ 今天(这一步)你同时学会了什么**:你**亲手写出了一个完整训练循环**,把"训练"从黑箱变成了你看得见的五步。从此你读任何模型代码,都能一眼定位"它的前向/loss/反向/更新在哪"。**做了**(裸 PyTorch SAR 分类训练)、**学了**(训练五步、单通道喂 CNN、ImageFolder)、**会了**(从零写训练循环、按"zero_grad/前向/loss/backward/step"排查训练 bug)。

> **技能卡｜训练循环五步**:`zero_grad()` → 前向 `out=model(x)` → `loss=crit(out,y)` → `loss.backward()` → `opt.step()`。任何训练 bug,先对照这五步查。

## 中午段 · 写 SAR 数据增强脚本(模拟 speckle + 旋转 + 裁剪)
**① 先垫概念**:
- **speckle 是乘性噪声**:不同于光学常见的加性高斯噪声(`I+n`),speckle 是**乘上去**的(`I*n`),所以**高斯滤波这类加性去噪对它效果差**——这正是"SAR 去噪是独立研究方向"的原因。
- 做数据增强模拟 speckle,可用乘性 Gamma 噪声:`I_noisy = I * gamma_noise`。
**② 带做**:`20-代码实验/utils/sar_augment.py`:实现 ① 乘性 speckle 噪声(Gamma 分布)② 随机旋转 ③ 随机裁剪。把它接进 D17 训练的数据变换里(可选)。
```python
import numpy as np
# 乘性 speckle 噪声（Gamma 分布）——注意是"乘"不是"加"，这才符合 SAR 物理
def add_speckle(img, looks=4):
    # looks(等效视数)越大噪声越弱；Gamma 均值=1，乘到图上不改变整体亮度只加颗粒
    gamma = np.random.gamma(shape=looks, scale=1.0/looks, size=img.shape)
    return img.astype(np.float32) * gamma          # ← 乘性！加性(img+noise)是错的
# 对比：光学常见的是加性高斯 img + sigma*randn —— 这套对 SAR 的 speckle 无效
# 简化近似（不会写 Gamma 时）：img * (1 + k*np.random.randn(*img.shape))，k 取小值(如0.1)
```
**③ 合格样例**:对一张 SAR 图施加增强后可视化,能看到"颗粒感增强但结构还在";脚本可被训练调用。
**④ 坑**:① 用加性噪声冒充 speckle(机理错)——要乘性;② 旋转后没处理边界黑边。
**⑤ 卡住**:Gamma 噪声不会写→先用"乘以 1 附近的随机数"近似(`I*(1+k*randn)`,k 小),核心是体会"乘性"。
**⑥ 同时学会了什么**:你理解了 **speckle 是乘性噪声**这个 SAR 关键特性,并能在代码里模拟它——"乘性 vs 加性"这一点,本身就能引出"针对乘性噪声设计的鲁棒模块"这类小而硬选题。

## 中午段 · 把可视化工具适配 SAR(灰度 + log 显示)
**① 概念**:SAR 是单通道、动态范围大,直接用光学的可视化会看不清。要把你 D6/D13 的可视化工具**适配 SAR**(灰度 + log 显示 + 框)。**为什么可视化工具要专门适配模态**:你 W2 写的 `vis_results.py` 默认按光学图(3 通道、动态范围正常)处理;SAR 是单通道、动态范围跨数量级,直接套用会一片黑、看不出任何结构。适配的核心就两点——**先 log+归一化压缩动态范围**(否则全黑)、**灰度转 3 通道再画彩色框**(便于区分预测/GT)。**让工具跨模态可用的意义**:你以后做光学、SAR、甚至光学-SAR 融合,都用同一套可视化逻辑(只是预处理分支不同),既省事又统一。这也呼应一个通用习惯:**好的工具要能适应不同输入,而不是为每种数据重写一遍**。
**② 带做**:改造 `vis_results.py`(或新建 `vis_sar.py`):读 SAR 图→log+归一化显示→画框。
```python
import numpy as np, cv2
def vis_sar_with_boxes(amp, boxes, out):
    # SAR 单通道、动态范围大：先 log+归一化到 8bit 再转 3 通道画彩色框
    db = 20*np.log10(np.abs(amp)+1.0)
    lo, hi = np.percentile(db, (1, 99))
    gray = np.clip((db-lo)/(hi-lo+1e-8)*255, 0, 255).astype(np.uint8)
    canvas = cv2.cvtColor(gray, cv2.COLOR_GRAY2BGR)        # 灰度→3通道好画彩框
    for b in boxes:
        cv2.polylines(canvas, [obb_to_corners(b)], True, (0,255,0), 2)
    cv2.imwrite(out, canvas)
# 关键：SAR 不先 log 直接显示会全黑；框坐标格式要先统一成角点
```
**③ 合格样例**:SAR 图能 log+灰度正常显示并画框,不是一片黑。
**④ 坑**:① 直接套光学可视化(不 log)→ SAR 动态范围大会显示全黑;② 框坐标格式没对齐 → SAR 标注/预测格式可能与光学不同,要转成统一角点再画。
**⑤ 卡住自救**:显示全黑 → 记得先 log 再归一化;框坐标对不上 → 确认 SAR 标注格式(是否归一化、坐标顺序),转成 8 点角点再画。

## 上午段 · 用 Swin-Transformer-Tiny backbone 重训 Oriented R-CNN(冲 mAP 77+)
**① 先垫概念**:
- **Swin-Transformer**:目前最主流的视觉 backbone 之一,**比 ResNet 强但计算量更大**。在遥感中表现尤其好(遥感图大、细节多,Transformer 的全局建模有优势)。

```python
# ① sar_preprocess.py —— SAR 幅度/复数 → log(dB) → 归一化 → PNG（含分位裁剪去极值）
import numpy as np, cv2
def sar_to_png(amp, out_path, clip=(1, 99)):
    amp = np.abs(amp).astype(np.float32)          # 复数则取幅度
    db = 20 * np.log10(amp + 1.0)                  # log 变换(+1 防 log0)
    lo, hi = np.percentile(db, clip)              # 1%/99% 分位裁剪去极亮点
    db = np.clip(db, lo, hi)
    norm = ((db - lo) / (hi - lo + 1e-8) * 255).astype(np.uint8)
    cv2.imwrite(out_path, norm); return norm
```
```python
# ② 裸 PyTorch SAR 分类训练循环（训练五步：zero_grad→前向→loss→backward→step）
import torch, torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import models, transforms, datasets
device = "cuda"
tf = transforms.Compose([transforms.Grayscale(3),               # SAR 单通道→复制成3通道喂ResNet
                         transforms.Resize((128,128)), transforms.ToTensor()])
train = datasets.ImageFolder("OpenSARShip/train", transform=tf)  # 按类别分文件夹
loader = DataLoader(train, batch_size=64, shuffle=True)
model = models.resnet18(weights="IMAGENET1K_V1")
model.fc = nn.Linear(model.fc.in_features, len(train.classes)); model = model.to(device)
opt = torch.optim.Adam(model.parameters(), lr=1e-3); crit = nn.CrossEntropyLoss()
for ep in range(20):
    model.train()
    for x, y in loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()                 # ①
        loss = crit(model(x), y)        # ②前向 ③loss
        loss.backward()                 # ④
        opt.step()                      # ⑤
    print(f"epoch {ep} loss {loss.item():.4f}")
```
```python
# ③ 混淆矩阵（D18 诊断"哪两类易混"）
from sklearn.metrics import confusion_matrix; import seaborn as sns, matplotlib.pyplot as plt
def plot_cm(y_true, y_pred, classes, out="cm.png"):
    cm = confusion_matrix(y_true, y_pred)
    sns.heatmap(cm, annot=True, fmt="d", xticklabels=classes, yticklabels=classes)
    plt.xlabel("pred"); plt.ylabel("true"); plt.tight_layout(); plt.savefig(out, dpi=150)
```

## 四、本周报错速查表

| 现象 | 根因 | 解法 |
|---|---|---|
| SAR 图存出来一片黑/一片白 | 没做 log / 没分位裁剪 | 先 `20*log10(amp+1)` 再归一化;加 1%/99% 裁剪 |
| `log(0)` 报错或出现 inf | 幅度有 0 值 | 一律 `+1` 再取 log |
| 喂 ResNet 维度错(期望3通道) | SAR 是单通道 | `transforms.Grayscale(3)` 复制成 3 通道 |
| ImageFolder 读不出标签 | 数据没按"每类一个文件夹"组织 | 整理成 `train/类名/xxx.png` 结构 |
| 训练 loss 不降/NaN | lr 不当 / 数据未归一化 | 先在每类 20 张小子集上过拟合验证模型能学;调 lr 到 1e-4 |
| 模型在 GPU、数据在 CPU 报错 | `.to(device)` 不一致 | x、y、model 都 `.to("cuda")` |
