## 中午段 · 处理需修改的论文起步（如第一篇大修/第三篇反馈 → 评估工作量）

**① 先垫概念（查清状态后：评估要处理什么）**
- 中午**处理需修改的论文起步**——根据上午查清的状态，评估本周要处理什么：① ★ **如第一篇是大修/小修**（major/minor revision）：这是**好消息**（离接收近了）——先**通读审稿意见**（几位审稿人、各提了什么、哪些是必须改的、哪些是建议）、**评估工作量**（要补实验吗？要改写吗？大概几天能完成？编辑给的 deadline 是什么时候[通常大修 1-3 月、小修 2-4 周]）；② **如第三篇有合作者反馈**：看老师/师兄要改什么、评估工作量；③ ★ **排处理优先级**（有 deadline 的论文修改优先[别错过 revision deadline，错过可能当拒稿处理]；第一篇大修通常最优先）；④ **如第一篇是接收/拒稿**：接收→无需修改、转更新材料（D494/W72）；拒稿→评估改投（复用 W46 流程）。② ★ **核心心态：大修/小修是好消息**——审稿人愿意给你修改机会，说明论文有价值、离发表一步之遥；认真对待 revision 比什么都重要（很多论文就是 revision 没做好被拒的）。③ ★ **侧线节奏**：论文处理是遥感侧线，用中午/晚上碎片+周末，不挤垮博士主线（但 revision 有 deadline 时可临时加权）。
- ★ **和你的论文修改功底对接**：你前两篇投稿、改过论文；处理 revision 是同一套"读意见+评估+改"，这次面向审稿意见。
- ★★ **远程模式**：同样评估处理。

**② 手把手带做**：① 如第一篇大修/小修→通读审稿意见+评估工作量+看 deadline；② 如第三篇有反馈→看要改什么+评估；③ ★ 排处理优先级（有 deadline 的优先、第一篇大修通常最优先）；④ 接收→转更新材料 / 拒稿→评估改投；⑤ 侧线节奏（碎片+周末，revision 有 deadline 可加权）。
**③ 这一步合格的样子**：论文处理评估——通读了审稿意见（如第一篇大修）、评估了工作量和 deadline、排了优先级，知道本周论文要处理什么、怎么排。
**④ 最常踩的坑**
- 把大修当坏消息沮丧（其实是好消息）→ ★ 大修=离接收近，认真对待。
- 不看 deadline（错过 revision 截止，当拒稿处理）→ ★ 看清 deadline、按时提交。
- revision 随便改（敷衍审稿人，被拒）→ ★ 认真逐条对待（D492 展开）。

**⑤ 卡住怎么自救（决策树）**：第一篇大修工作量多大？→ 看审稿意见(要补实验/大改写=工作量大；只改表述=小)、估几天；revision deadline 紧？→ 优先处理、必要时博士临时让路；不知先处理哪篇？→ 有 deadline 的优先、第一篇大修通常最急。
**⑥ 今天（这一步）你同时学会了什么**：你**评估了论文处理工作量**。**做了**（读意见 + 评估工作量/deadline + 排优先级）、**学了**（大修/小修是好消息、看清 deadline、认真对待 revision、侧线节奏）、**会了**（根据论文状态评估处理工作量与优先级）。

## 二、完整可运行代码 · 论文状态管理器（+ 预期输出）

> 这个脚本帮你管理多篇不同阶段的论文：状态总览 + 下一步 + deadline 提醒 + 第一篇三情形提示。复制到 `paper_status_manager.py` 运行。

```python
# paper_status_manager.py —— 多篇论文状态管理器(回校后善后用)
# 用法: python paper_status_manager.py
from datetime import date, timedelta

TODAY = date(2026, 6, 28)  # 示意"今天", 实际用date.today()

# ============ 论文状态总览 ============
# (篇名, 状态, 期刊, 投稿日, revision截止[None=无], 下一步)
papers = [
    ("第一篇(独作)",       "大修",  "[期刊1]", date(2026,3,15), date(2026,7,10), "做rebuttal+补实验+改写"),
    ("第二篇(独作)",       "在审",  "[期刊2]", date(2026,4,20), None,            "等结果、留意系统"),
    ("第三篇(空天院合作)", "初审",  "[期刊3]", date(2026,6,20), None,            "等送审、处理合作者反馈"),
]

# 第一篇有结果的应对提示
ACTIONS = {
    "接收": "🎉 立即更新简历/主页/作品集'在审'→'已发表'; 走校样/版权流程",
    "大修": "★好消息! 认真rebuttal(逐条回应+补实验+改写), deadline前提交",
    "小修": "按意见小改(表述/格式)+简短rebuttal, 快速提交",
    "拒稿": "★不气馁! 复用W46: D1读意见→D2-3改→D4改投下一期刊→D5提交",
}

def days_left(deadline):
    if deadline is None: return None
    return (deadline - TODAY).days

if __name__ == "__main__":
    print("="*60, "\n【三篇论文·状态总览】(", TODAY, ")")
    for name, st, jrnl, sub, ddl, nxt in papers:
        line = f"  · {name}: {st} @ {jrnl} (投于{sub})"
        dl = days_left(ddl)
        if dl is not None:
            flag = "🔴紧急" if dl <= 7 else ("🟡留意" if dl <= 21 else "🟢")
            line += f" | revision截止{ddl}(剩{dl}天){flag}"
        print(line)
        print(f"      下一步: {nxt}")

    print("\n【第一篇·三情形应对提示】")
    for k, v in ACTIONS.items():
        print(f"  [{k}] {v}")

    # deadline预警汇总
    print("\n【deadline预警】")
    urgent = [(n, days_left(d)) for n,_,_,_,d,_ in papers if d and days_left(d) is not None and days_left(d) <= 14]
    if urgent:
        for n, dl in urgent:
            print(f"  🔴 {n}: revision剩{dl}天 → 优先处理、别错过(错过可能当拒稿)!")
    else:
        print("  无14天内紧急deadline")
    print("="*60)
```
