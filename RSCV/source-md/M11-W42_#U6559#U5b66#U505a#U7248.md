## 上午段 · 搭 10 页 PPT 结构（每页放什么）

**① 先垫概念（10 页研究汇报 PPT 的标准结构）**
- 一份 20 分钟的研究汇报 PPT，**10 页是合适的篇幅**（每页讲 2 分钟）。标准结构：Slide 1 标题 + 自我介绍；Slide 2–3 研究背景与问题；Slide 4–6 方法（架构图 + 核心公式）；Slide 7–8 实验结果（表格 + 可视化）；Slide 9 总结与未来工作；Slide 10 致谢 + 联系方式。**这个结构是"讲清一个研究"的通用骨架**（背景→问题→方法→结果→展望），老师/面试官都熟悉。
- **和论文/poster 的不同**：论文是详尽书面证明；poster 是一页海报吸引驻足；**汇报 PPT 是"你站着讲 20 分钟"的视觉辅助**——要点上 PPT、细节靠你口头讲，节奏由你掌控。它最能完整、生动地展示你的研究和你这个人。对你这种非传统路径的人尤其重要：一份讲得清、有逻辑、有亮点的汇报，能让老师在 20 分钟里直接感受到"这个人虽然是转型来的，但研究做得扎实、表达也清楚"——这比简历上的任何一行字都更有说服力，因为它是"现场证明"你的能力。

**② 手把手带做**：在 W40 骨架基础上做 10 页 v1（见补充包范例 1 逐页骨架）——① 标题页（论文题目 + 你 + 一句定位）；② 自我介绍融入（零基础转型→两篇论文的一句话路径，可放标题页或单独一句）；③ 背景与问题（2–3 页，讲清你做的任务为什么重要、有什么未解问题）；④ 方法（4–6，架构图 + 核心思想 + 关键公式，**复用论文的架构图**）；⑤ 实验结果（7–8，主表 + 可视化，**突出 SOTA + 单卡高效**）；⑨ 总结 + 未来工作；⑩ 致谢 + 联系方式；每页**要点化**（不堆满字）。
**③ 这一步合格的样子**：10 页 PPT v1 结构完整、每页有要点、逻辑顺（背景→问题→方法→结果→展望），能撑起一个 20 分钟汇报。
**④ 最常踩的坑**
- 每页堆满文字（像论文）→ PPT 是给观众看的视觉辅助，要点化、留白，细节口头讲。
- 方法页只堆公式无架构图 → 配架构图（直观），公式只放核心的。
- 不突出差异化/结果 → 实验页突出 SOTA + 单卡 4090 高效（你的卖点）。

**⑤ 卡住怎么自救（决策树）**：不知每页放什么？→ 按标准结构（背景→问题→方法→结果→展望）一页页填，参考补充包逐页骨架；内容太多 10 页放不下？→ 聚焦一个课题讲透（如第二篇），或两个课题各精简，要点化。
**⑥ 今天（这一步）你同时学会了什么**：你**搭出了完整的 10 页研究汇报 PPT 结构**。**做了**（10 页 v1 + 标准结构 + 要点化 + 复用架构图）、**学了**（汇报 PPT 两用途、10 页对应 20 分钟、要点上 PPT 细节口头讲、突出差异化）、**会了**（把研究组织成一个可汇报的视觉骨架）。

> **技能卡｜研究汇报 PPT（10 页结构）**：20 分钟汇报=10 页（每页 2 分钟）。结构：①标题+自我介绍 ②-③背景与问题 ④-⑥方法（架构图+核心公式）⑦-⑧实验结果（表+可视化，突出 SOTA+单卡高效）⑨总结+未来 ⑩致谢+联系。两用途：联系老师后"20 分钟线上汇报"+面试自我介绍。要点上 PPT、细节口头讲、不堆满字、配架构图。现在做好后面直接用。

## 中午段 · 制作 PPT 图表

**① 先垫概念**：PPT 的图表是"一眼传达"的关键——架构图（讲清方法）、结果表（突出 SOTA + 高效）、可视化（直观展示效果）。**好的图表让观众秒懂**，比一堆文字有效。这些图大多能从你论文/作品集素材里取（复用），按 PPT 展示需要适当简化/放大重点。这也是前面"作品集素材包"（W40）和论文图的价值兑现——你不用为 PPT 从头画图，已有的素材稍加调整即可，省时又保证系列感（PPT、论文、主页的图风格一致，整体显专业）。
**② 手把手带做**：做/整理 PPT 用图表——① 架构图（从论文取，简化到适合投影看清）；② 结果表（精简到关键对比，**粗体标你的最优 + 标注单卡 4090**）；③ 可视化（选最直观的几张，正面/困难案例）；④ 必要的示意图（讲背景/问题用）；确保投影时清晰（字够大、对比够强）。
**③ 这一步合格的样子**：PPT 图表齐备、清晰、突出重点（SOTA + 高效），投影可看清。
**④ 坑**：① 图表直接搬论文（太密、字太小）→ 为投影简化、放大重点；② 结果表不标卖点 → 标注单卡 4090 / 高效（你的差异化）；③ 可视化选太多太杂 → 选最直观的代表性几张。
**⑤ 自救**：图投影看不清？→ 放大字号、提高对比、减少一页信息量；不知选哪些可视化？→ 选最能让外行看懂效果的。
**⑥ 今天（这一步）你同时学会了什么**：你**做出了一眼传达的 PPT 图表**。**做了**（架构图/结果表/可视化 + 简化适配投影 + 标卖点）、**学了**（图表秒懂胜过文字、复用论文图按展示简化、标差异化卖点）、**会了**（为汇报准备清晰有力的视觉素材）。

## 晚上段 · 完善 PPT 动画和设计

**① 先垫概念**：基本内容和图表就位后，**适度的设计和动画**能提升专业度和清晰度——统一的模板/配色（专业不花哨）、关键内容的逐步出现（动画引导注意力，但别过度）。**设计是为内容服务的**（让观众更易跟上），不是炫技。
**② 手把手带做**：完善 PPT 设计——① 统一模板/配色（简洁专业，避免花哨）；② 字号/排版一致、对齐；③ 适度动画（如方法的逐步展开、结果的重点高亮，引导注意力，但不滥用花哨切换）；④ 通读一遍确认整体专业、清晰、节奏好；存为 PPT v1。**控时长**——设计够用即可，重点是内容讲得清。
**③ 合格样例**：PPT v1 完成——内容/图表/设计齐备，专业清晰、动画适度，可用于汇报。
**④ 坑**：① 过度设计/花哨动画 → 简洁专业，动画服务于引导注意力；② 模板/字号不统一 → 统一（细节显专业）；③ 把时间全花在美化忽略内容 → 内容讲得清是核心，设计够用即可。
**⑤ 自救**：不会设计？→ 用专业的简洁模板（学术风），别自创花哨；动画不会用？→ 只用最基本的"逐步出现/高亮"，引导注意力即可。
**⑥ 今天（这一步）你同时学会了什么**：你**完成了专业清晰的 PPT v1**。**做了**（统一模板/配色 + 适度动画 + 通读 + 存 v1）、**学了**（设计为内容服务、简洁专业不炫技、动画引导注意力）、**会了**（产出一份专业可用的研究汇报 PPT v1）。

## 上午段 · 对镜练习（计时 20 分钟）+ 标不顺处

**① 先垫概念（为什么要对镜计时练习）**
- 做好 PPT ≠ 能讲好。**汇报是表达能力**，要练——对着镜子（或录音/录像）讲一遍、**计时**（确认 20 分钟内讲完、每页节奏对），能暴露问题：哪里卡壳、哪里超时、哪里逻辑不顺、哪里不知道怎么过渡。**第一次讲总会发现"PPT 看着顺、讲起来卡"**，这正是练习的价值。
- **和"只做 PPT 不练"对比**：只做不练，真到汇报时容易紧张、超时、念稿、答不上问题。**练习把这些问题提前暴露、修掉**——尤其你后面真要向老师做汇报，练熟了才不怯场、讲得清。

**② 手把手带做**：对着镜子（或手机录像）完整讲一遍 PPT，**计时 20 分钟** → 边讲边/讲完标记：① 哪页超时/太快（节奏）；② 哪里卡壳/不知怎么讲（内容或过渡）；③ 哪里在念 PPT 文字（要改成口头展开）；④ 哪里逻辑不顺（顺序问题）；记下所有"不顺处"。
**③ 这一步合格的样子**：完整对镜讲了一遍、计了时，标记出所有讲得不顺的地方（超时/卡壳/念稿/逻辑），清楚知道要改什么。
**④ 最常踩的坑**
- 只在脑子里"过一遍"不真讲 → 必须真讲出声（默念发现不了卡壳/超时）。
- 不计时 → 20 分钟的约束很重要（汇报通常有时限），计时才知道节奏。
- 发现念稿不改 → 念 PPT 是大忌，标记并改成口头展开。
- 练习时跳过开头和结尾（只练中间方法）→ 开头（第一印象）和结尾（最后记忆点）最关键，要练熟；很多人恰恰栽在"开场紧张语无伦次"上。

**⑤ 卡住怎么自救（决策树）**：讲着讲着卡住？→ 那页就是没想清怎么讲，标记后补讲稿要点；总超时？→ 砍内容或加快非重点页；不好意思对镜讲？→ 录音/录像回放也行，关键是真讲出来。
**⑥ 今天（这一步）你同时学会了什么**：你**通过对镜计时练习暴露了汇报问题**。**做了**（对镜计时讲一遍 + 标超时/卡壳/念稿/逻辑问题）、**学了**（汇报要练不能只做、计时把控节奏、真讲才暴露问题）、**会了**（用练习发现汇报中的真实问题）。

## 中午段 · 据反馈修改 PPT + 写讲稿

**① 先垫概念（讲稿写什么、为什么 PPT 和讲稿分离）**
- **讲稿 = 你每页要讲的内容要点**（不是 PPT 上的字，是"不在 PPT 上的展开"）。★ 关键原则：**PPT 是给观众看的（要点/图），讲稿是你要说的（展开/解释/故事/过渡）**——两者分离，你才不会念 PPT。讲稿可以是每页几个 bullet 的口头要点（不必逐字稿，逐字稿容易念）。
- **为什么要有讲稿**：练习暴露的"卡壳/不知怎么讲"，靠写讲稿解决——把每页"我要讲什么、怎么过渡到下一页"想清楚、记成要点，讲起来就顺。

**② 手把手带做**：据上午标记修改——① 改 PPT（超时的砍内容、逻辑不顺的调顺序、念稿的把文字改成图/要点）；② **写讲稿**：每页几个"口头要点"（要讲的展开内容 + 到下一页的过渡句），重点是"不在 PPT 上的内容"；③ 准备 **3 个可能被问到的问题的回答**（如"为什么用这个方法""单卡怎么做到的""和 X 方法比"）。
**③ 这一步合格的样子**：PPT 据问题改好（v2）、讲稿成形（每页口头要点 + 过渡）、3 个预备问答写好。
**④ 坑**：① 讲稿写成逐字稿 → 容易念，写口头要点即可；② 不准备问答 → 汇报后常有提问，备 3 个高频问题答案；③ 改 PPT 又堆字 → 念稿问题靠"PPT 要点化 + 讲稿展开"解决，别把展开内容塞回 PPT。
**⑤ 自救**：不知讲稿写啥？→ 写"这页我要让观众明白什么 + 怎么讲 + 怎么过渡";不知备哪些问题？→ 想审稿人/面试官最可能质疑的（方法选择/卖点/对比）。
**⑥ 今天（这一步）你同时学会了什么**：你**改好了 PPT 并写出了讲稿、备好问答**。**做了**（改 PPT v2 + 写讲稿口头要点 + 备 3 问答）、**学了**（PPT 给观众看/讲稿你来说、讲稿写要点非逐字、备高频问答）、**会了**（让汇报内容与表达分离、有备无患）。

## 中午段 · 润色简历——每条突出量化成果

**① 先垫概念（为什么每条都要量化）**
- ★ 简历的说服力来自**量化的结果**。"做了 X"是过程，"X 带来了 Y 结果（数字）"是成果。**每条经历都要落到数字**：mAP 提升 X%、GitHub XX stars、竞赛 Top X%、读 100+ 篇……。**数字让你的工作可衡量、可信、有冲击力**——招生老师/面试官一眼看到"这人做出了实打实的东西"。
- **量化前后对比**：① 差："使用 MMRotate 做了遥感目标检测"（只说过程，没结果）；② 好："独立设计旋转检测方法，DOTA-v1.0 mAP 78.5（+1.3 vs SOTA），开源 60+ stars"（设计=主导、78.5/+1.3=结果、60+ stars=影响力）。**后者每个短语都在传递"我做出了什么"。**

**② 手把手带做**：逐条润色简历，每条改成"动作 + 量化结果"——① 研究经历：从"做了 X"改成"设计/提出 X，达到 [指标数字]（+X vs SOTA），[效率/单卡卖点]"；② 论文：标清状态 + 核心贡献一句；③ 开源：repo + star 数 + 一句亮点（一键复现/Model Zoo）；④ 竞赛：排名/Top X%；⑤ 突出"独立/主导"（体现你的能力）；每条问自己"这条传递了什么结果"。
**③ 这一步合格的样子**：简历每条都有量化结果（mAP/star/排名/数量）、用"动作+结果"句式、突出独立主导和差异化卖点。

## 二、完整可运行代码 · 简历量化检查器（+ 预期输出）

> 这个脚本扫描你简历的每条经历，检查是否含量化结果（数字/百分比/指标/star），标出"没量化"的弱条目并给改进提示，算"量化率"。写完简历跑一下，确保每条都用结果说话。

```python
#!/usr/bin/env python3
# resume_checker.py —— 简历量化包装检查器
import re

bullets = [
    "独立设计旋转目标检测方法，DOTA-v1.0 mAP 78.5（+1.3 vs SOTA），开源 60+ stars",
    "提出 speckle-aware 模块解决 SAR 检测噪声敏感，3 个数据集 SOTA，仅用单张 RTX 4090",
    "使用 MMRotate 框架做了遥感目标检测",          # 弱：无量化
    "研究了 SAR 图像的检测问题",                    # 弱：无量化、无结果
    "某遥感检测竞赛 Top 5%，主导多模型 Ensemble 方案",
]

# 量化信号：数字、百分比、mAP/F1、stars、Top X、+X 提升
QUANT = re.compile(r'\d+\.?\d*\s*(%|stars?|mAP|F1|Top|\+)|\bmAP\b|\bSOTA\b|\+\d')

def has_quant(b):
    return bool(QUANT.search(b))

def check(bullets):
    print("=== 简历量化检查 ===\n")
    weak = []
    for i, b in enumerate(bullets, 1):
        ok = has_quant(b)
        mark = "✅" if ok else "⚠️ 缺量化"
        print(f"{i}. [{mark}] {b}")
        if not ok:
            weak.append(b)
    rate = (len(bullets) - len(weak)) / len(bullets) * 100
    print(f"\n量化率：{rate:.0f}%（{len(bullets)-len(weak)}/{len(bullets)} 条有量化结果）")
    if weak:
        print("\n⚠️ 需改进（改成'动作+量化结果'）：")
        for w in weak:
            print(f"   · {w}")
            print(f"     → 加上：做了什么 + 数字结果（指标/star/排名/+提升）+ 卖点")
    else:
        print("\n🎉 每条都有量化结果，简历很有说服力！")

if __name__ == "__main__":
    check(bullets)
```

**预期输出**：
```
=== 简历量化检查 ===

1. [✅] 独立设计旋转目标检测方法，DOTA-v1.0 mAP 78.5（+1.3 vs SOTA），开源 60+ stars
2. [✅] 提出 speckle-aware 模块解决 SAR 检测噪声敏感，3 个数据集 SOTA，仅用单张 RTX 4090
3. [⚠️ 缺量化] 使用 MMRotate 框架做了遥感目标检测
4. [⚠️ 缺量化] 研究了 SAR 图像的检测问题
5. [✅] 某遥感检测竞赛 Top 5%，主导多模型 Ensemble 方案

量化率：60%（3/5 条有量化结果）

⚠️ 需改进（改成'动作+量化结果'）：
   · 使用 MMRotate 框架做了遥感目标检测
     → 加上：做了什么 + 数字结果（指标/star/排名/+提升）+ 卖点
   · 研究了 SAR 图像的检测问题
     → 加上：做了什么 + 数字结果（指标/star/排名/+提升）+ 卖点
```
> 解读：脚本逐条标记有无量化、算量化率、列出需改进的弱条目。把你的简历条目填进 bullets，目标是量化率接近 100%——每条都用数字结果说话。弱条目按提示改成"动作+量化结果+卖点"。
