# D477 周一 · 第三篇论文投稿（如时间合适）——或等离开后再投（给老师更多审阅时间）

> **预期管理**：W69 第一天——① 上午做**投稿决策**（"现在投" vs "等离开后投"——合作论文要尊重老师/团队节奏，权衡时间是否合适、是否给老师更多审阅时间）；② 中午**执行**（决定投 → 复用前两篇投稿流程把论文投出；决定等 → 把论文调到"待投就绪"+ 和老师确认何时投）；③ 晚上投稿/待投确认 + 博士维护 1h。提醒：★ 这第三篇是**合作论文**，和你前两篇"自己决定何时投"不同——"等离开后投、给老师更多审阅时间"在合作里常常是更稳的选择，不要为了"在访问内投出"而抢时间。★★ 远程模式：同样（投稿/确认线上做）。

## 上午段 · 投稿决策（现在投 vs 等离开后投·尊重合作节奏）

**① 先垫概念（合作论文的投稿决策怎么做）**
- 上午做**投稿决策**——和你前两篇（自己的论文、自己决定何时点 Submit）最大的不同是：第三篇是**合作论文**，投稿是**合作决策**，要尊重老师和团队的节奏。两个选项：① **现在投**（如果论文已定稿、老师也认可、时间合适——访问内投出，干净利落）；② ★ **等离开后再投**（给老师/合作师兄更多审阅时间——合作论文多一轮审阅往往更稳，且你离开后老师可能还想再调；不要为了"在访问期内投出"这个虚的目标抢时间）。② **决策依据**：论文是否真的定稿到投稿级（W68 已做）/ 老师是否明确说"可以投了"/ 是否还有合作师兄没看完 / 投稿系统材料是否齐（W68 已备）。③ ★ **关键原则：投稿节奏由合作关系定，不由"访问日历"定**——这是合作论文的基本尊重。
- ★ **和你前两篇的对比**：第一/第二篇你留了 48h 冷静期、自己点 Submit；这第三篇，"何时投"要先问老师。**合作论文的每一步都比独作多一层"和合作者对齐"。**
- ★★ **远程模式**：同样——远程合作更要尊重老师节奏，"等老师审完再投"是常态。

**② 手把手带做**：① 确认论文定稿状态（W68 已到投稿级）；② ★ 问/回顾老师意见（"老师说可以投了吗？还有师兄没看吗？"）；③ 权衡现在投 vs 等离开后投（时间合适？给老师更多审阅时间更稳？）；④ ★ 做出决策并和老师对齐（合作论文投稿是合作决策）；⑤ 决策记录（投/等 + 理由 + 谁拍板）。
**③ 这一步合格的样子**：投稿决策——确认了定稿状态、回顾了老师意见、权衡了两个选项、和老师对齐了决策（投 or 等离开后投），决策有理由、尊重合作节奏。
**④ 最常踩的坑**
- 为"在访问内投出"抢时间，不顾老师还想再审 → ★ 投稿节奏由合作定，等老师审完更稳。
- 不问老师自己拍板投了（合作论文越权）→ ★ 合作论文投稿是合作决策，先和老师对齐。
- 论文其实还没真定稿就投（W68 没做扎实）→ 确认到投稿级再决策。

**⑤ 卡住怎么自救（决策树）**：现在投还是等？→ 老师明确认可 + 时间合适 + 师兄都看完 → 可现在投；老师还想审/师兄没看完/不确定 → ★ 等离开后投(更稳)。老师没明确表态？→ ★ 当面/邮件直接问"您看现在投合适，还是我离开后您再审一轮我们再投？"。
**⑥ 今天（这一步）你同时学会了什么**：你**做了合作论文的投稿决策**。**做了**（确认定稿 + 回顾老师意见 + 权衡两选项 + 和老师对齐）、**学了**（★ 合作论文投稿是合作决策、节奏由合作定不由日历定、等老师审完更稳）、**会了**（在合作关系里做投稿决策、尊重合作节奏）。

## 中午段 · 执行：投出（复用前两篇流程）或调到"待投就绪"+ 和老师约定投稿时间

**① 先垫概念（投/等两条路怎么执行）**
- 中午**执行决策**——分两条路：① **决定投** → 复用你前两篇的投稿流程：登投稿系统（ScholarOne 等）→ 填元数据/作者/单位（★合作论文作者顺序、通讯作者按 W66 协商的来）→ 上传论文 PDF + Cover Letter + supplementary + 其他材料（W68 已备）→ ★ **Submit 前务必预览生成的 PDF**（确认无乱码/图表完整）→ 点 Submit → 同步 arXiv（如老师同意）。② ★ **决定等离开后投** → 把论文和所有材料整理成"待投就绪包"（论文定稿 PDF + Cover Letter + supplementary + 投稿系统所需信息清单），交给老师/约定好"离开后 X 周内、老师审完就投"，并确认**谁来点 Submit**（通常是你或老师，合作论文要说清）。② **两条路都要留痕**：投了 → 记录投稿号/日期；等 → 记录"待投就绪包"位置 + 约定时间 + 谁来投。
- ★ **复用前两篇经验**：投稿系统操作、Cover Letter、Submit 前预览 PDF——这些你做过两遍了，第三篇是肌肉记忆，效率高。
- ★★ **远程模式**：投/约定都线上做，"待投就绪包"发给老师（云盘/邮件）。

**② 手把手带做**：① 按决策走对应路；② **投**：登系统→填元数据(★作者顺序/通讯)→传材料→★预览 PDF→Submit→arXiv(如老师同意)；③ **等**：整理"待投就绪包"+约定投稿时间+说清谁点 Submit；④ 留痕（投稿号/日期 或 就绪包位置/约定/责任人）；⑤ 和老师确认这一步到位。
**③ 这一步合格的样子**：执行到位——投了（有投稿号/日期、Submit 前预览过 PDF）或调到待投就绪（就绪包齐、约定了时间和责任人），并和老师确认了。
**④ 最常踩的坑**
- 投稿元数据作者顺序/通讯写错（合作论文敏感）→ ★ 按 W66 协商的来，拿不准问老师。
- Submit 前不预览 PDF（乱码/缺图）→ ★ 必预览生成的 PDF。
- 决定"等"却不说清谁点 Submit、何时投（悬着）→ 约定时间 + 责任人 + 就绪包位置。

**⑤ 卡住怎么自救（决策树）**：作者顺序拿不准？→ 看 W66 协商记录，仍不确定 → 问老师；投稿系统卡住？→ 复用前两篇笔记/截图流程；决定"等"怎么交接？→ "待投就绪包"+约定时间+责任人，发给老师确认。
**⑥ 今天（这一步）你同时学会了什么**：你**执行了投稿决策**。**做了**（投出 或 调到待投就绪 + 留痕 + 和老师确认）、**学了**（复用投稿流程、合作论文作者顺序/通讯要对、Submit 前预览 PDF、"等"也要交接清楚）、**会了**（执行合作论文的投稿/待投交接）。
