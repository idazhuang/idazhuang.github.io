## 2. 深度学习最小概念(看懂训练在干嘛)

**① 神经网络是什么**:一个**带大量可调参数的函数** `y = f(x; W)`。给它输入 x(图像),它输出预测 y;**训练 = 自动调参数 W,让预测越来越准**。类比:一个有几百万个旋钮的机器,训练就是自动拧旋钮。

**② 张量(tensor)**:就是**多维数组**。一张 RGB 图 = `(3, H, W)` 的张量;一批(batch)图 = `(N, 3, H, W)`。PyTorch 里的数据都是张量(和 numpy 数组几乎一样,但能放 GPU、能自动求导)。

**③ 训练的核心循环(记住这五步,计划 M1-W3 会让你亲手写)**:
1. **取一批数据**(batch);
2. **前向**:`pred = model(x)`(算出预测);
3. **算 loss**:`loss = 损失函数(pred, 真值)`(预测离真值多远);
4. **反向传播**:`loss.backward()`(自动算每个参数该往哪调=梯度);
5. **更新参数**:`optimizer.step()`(按梯度拧旋钮);每步前 `optimizer.zero_grad()`(清空上一轮梯度)。

**④ 几个必懂词**:
- **loss(损失)**:衡量"预测有多差",训练就是让 loss 变小。分类常用**交叉熵 CrossEntropy**。
- **optimizer(优化器)**:决定"怎么根据梯度调参数",常用 **SGD / Adam**。
- **learning rate(学习率 lr)**:每步调多大。**太大→震荡/NaN,太小→学不动**(最关键的超参)。
- **batch / batch_size**:一次喂多少张图。受**显存**限制(4090 上旋转检测常 bs=2)。
- **epoch**:把整个训练集过一遍叫一个 epoch;通常训多个 epoch。
- **过拟合(overfitting)**:在训练集很好、在没见过的数据上差(死记硬背了)。
- **train / val / test 划分**:训练集学、验证集调参选模型、测试集只在最后评估——**不能用测试集调参**(作弊)。

**⑤ 一句话记牢**:训练 = 反复"前向→算 loss→反向→更新",目标是 loss 下降且**在验证/测试集**上也好(不只训练集)。

## 3. CNN 基础(遥感 CV 的主力网络)

**① 卷积(convolution)**:用一个小窗口(卷积核)在图上滑动、做加权求和,**提取局部特征**(边缘、纹理…)。多层卷积叠起来,从低级特征(边)到高级特征(物体部件)。

**② 池化 / 下采样(pooling/downsample)**:把特征图变小(如尺寸减半),扩大"视野"、减计算。**副作用:小目标特征会丢**——这正是遥感小目标难检的原因之一(差异表第 2 条)。

**③ 特征图(feature map)/ 感受野(receptive field)**:卷积输出的中间结果叫特征图;一个输出像素"看得到"的输入区域大小叫感受野(越深越大)。

**④ 一个检测/分割网络的三段式(计划 W2 会反复见)**:
- **backbone(主干)**:负责"从图像提特征"。常用 **ResNet**(经典 CNN)、**Swin Transformer**(更强但更重)、ConvNeXt。
- **neck(颈)**:融合不同尺度的特征,最常见是 **FPN(特征金字塔)**——让大目标小目标都能被检到。
- **head(头)**:在特征上输出最终结果(框/类别/掩膜)。

**⑤ 一句话记牢**:`图 →[backbone 提特征]→[neck 多尺度融合]→[head 出结果]`。换 backbone/neck/head 的某一块来看效果,就是**消融实验**(计划 W2 起反复做)。

## 4. CV 三大任务范式(把"做什么"搞清)

| 任务 | 输出 | 关键概念 |
|---|---|---|
| **分类(classification)** | 一张图一个类别 | softmax、交叉熵 |
| **目标检测(detection)** | 每个目标:一个**框** + 类别 | 框、anchor、NMS、IoU |
| **语义分割(segmentation)** | **每个像素**一个类别(掩膜) | 逐像素分类、上采样还原细节 |

**检测必懂的几个词**:
- **框(bounding box)**:框住目标的矩形。通用 CV 用**水平框**(左上+右下);遥感目标斜着,用**旋转框**(计划 W2 详讲)。
- **anchor(锚框)**:预设的一堆候选框,网络在其上微调(两阶段/部分一阶段检测器用);**anchor-free** 则不用预设框。
- **两阶段 vs 一阶段**:两阶段(如 Faster/Oriented R-CNN)先选候选区再分类回归,准但慢;一阶段(如 RetinaNet/YOLO 系)直接出框,快。
- **IoU(交并比)**:两个框"交集/并集",衡量预测框和真值框重叠度(0–1)。**判断"检测对不对"的尺子**。
- **NMS(非极大值抑制)**:同一目标常出多个重叠框,NMS 只保留最高分的、删掉其余(计划竞赛周会见到更优的 WBF)。

**一句话记牢**:分类=整图一个标签;检测=框+类别(看 IoU、用 NMS);分割=逐像素标签。

## 5. 评价指标(看懂论文的数字 + 知道何时用哪个)

| 指标 | 用于 | 含义(直觉) |
|---|---|---|
| **accuracy(准确率)** | 分类(类别均衡时) | 预测对的比例 |
| **precision(精确率)** | 检测/分类 | "我说是的里,有多少真是" |
| **recall(召回率)** | 检测/分类 | "真有的里,我找到多少" |
| **F1** | **类别不平衡**(如变化检测) | precision 与 recall 的调和平均 |
| **mAP** | **目标检测** | 各类 AP(平均精度)的平均;越高越好 |
| **mIoU** | **语义分割** | 各类 IoU 的平均 |

**为什么不同任务用不同指标**:类别极不平衡时(如变化检测里"变"的像素很少),光看 accuracy 会骗人(全猜"没变"也高)→ 用 F1。**记住对照:检测=mAP,分割=mIoU,变化检测=F1,均衡分类=accuracy。**(计划 M2-W5 会让你亲手体会。)

## 6. PyTorch 最小够用(能读懂、能改别人代码)

```python
import torch, torch.nn as nn
# ① 张量 & 放 GPU
x = torch.randn(8, 3, 224, 224)     # 一批8张3通道224图
x = x.to("cuda")                    # 放到 GPU；模型也要 .to("cuda")，两者必须一致

# ② 自定义模型：继承 nn.Module，写 __init__(定义层) 和 forward(定义前向)
class Net(nn.Module):
    def __init__(self, n_cls):
        super().__init__()
        self.conv = nn.Conv2d(3, 16, 3, padding=1)
        self.pool = nn.AdaptiveAvgPool2d(1)
        self.fc   = nn.Linear(16, n_cls)
    def forward(self, x):
        x = torch.relu(self.conv(x))
        x = self.pool(x).flatten(1)
        return self.fc(x)

# ③ 数据：Dataset 定义"怎么取一条"，DataLoader 负责"成批+打乱"
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
tf = transforms.Compose([transforms.Resize((224,224)), transforms.ToTensor()])
ds = datasets.ImageFolder("data/train", transform=tf)   # 每类一个文件夹
loader = DataLoader(ds, batch_size=32, shuffle=True)

# ④ 训练循环五步（=第2节的五步）
model = Net(len(ds.classes)).to("cuda")
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
crit = nn.CrossEntropyLoss()
for x, y in loader:
    x, y = x.to("cuda"), y.to("cuda")
    opt.zero_grad()                  # 清梯度
    loss = crit(model(x), y)         # 前向+算loss
    loss.backward()                  # 反向
    opt.step()                       # 更新
```
**必懂三件事**:① 数据和模型要在同一设备(都 `.to("cuda")`);② `Dataset` 定义"怎么取一条"、`DataLoader` 负责"成批+打乱";③ 训练就是那五步。**这些计划 M1-W3 会带你亲手写,这里先混个眼熟。**

## 7. 数学够用部分(只取看懂方法所需,不深究)

- **线性代数**:向量、矩阵、**矩阵乘法**(神经网络的全连接层就是矩阵乘 + 偏置)。知道"特征 = 一个高维向量"即可。
- **概率**:**分布、期望、方差**;**高斯(正态)分布**(很多噪声/初始化用它);softmax 把分数变成"概率"。
- **梯度与链式法则(直觉即可)**:梯度 = "loss 对每个参数的偏导 = 该参数往哪调能让 loss 变小";反向传播就是用**链式法则**自动把梯度从输出层一层层传回去。**PyTorch 自动求导,你不用手算**,但要知道"`loss.backward()` 在算梯度"。
- **够用原则**:看不懂论文里的某个公式时,先抓"它想表达什么直觉",细节做实验/用到时再补。**不要因为数学没学透就不敢开始**。
