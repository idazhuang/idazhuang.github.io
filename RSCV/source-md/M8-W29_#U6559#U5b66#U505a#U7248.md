## 上午段 · 写 Sec1 背景 + Sec2 数据分析

**① 先垫概念(技术报告 ≠ 论文,是另一种文档类型)**:
- **技术报告(technical report)是一种介于论文和博客之间的文档**——比论文轻(不需要严格的相关工作、理论分析、与SOTA的全面对比),但比博客正式(有结构、有数据、讲清方法)。它的目的是**清楚地讲明"这个竞赛/项目我是怎么做的、效果如何"**。
- **为什么要会写技术报告(一种重要的文档能力)**:技术报告是**工业界和竞赛中最常用的成果呈现形式**——做完一个项目/竞赛,写一份技术报告说清楚你的方案和结果。它比论文快(不用那么严谨的学术包装)、比口头讲清楚(有文档可查)。**会写技术报告,是把你的工作系统呈现给别人(同事、面试官、社区)的核心能力**。这次写竞赛技术报告,就是学这种文档类型。
- **技术报告的标准结构**:① **Sec1 背景**——竞赛是什么、任务是什么、为什么有挑战;② **Sec2 数据分析**——数据的特点(你 EDA 的发现:类别分布、目标尺度、难点);③ **Sec3 方法概述**——你的方案(pipeline 图 + 各模块);④ **Sec4 实验**——trick 列表 + 每个 trick 的提升 + 消融;⑤ **Sec5 结果分析**——失败案例、经验教训(D192 写)。
- **Sec1+Sec2 怎么写**:① **背景**——简述竞赛任务(检测/分割什么)、评测指标、挑战在哪(用 2-3 段说清);② **数据分析**——把你 EDA 的发现写出来(类别分布是否长尾、目标尺度、标注特点、难点),并说明这些发现如何指导了你的方案(如"小目标多→用 SAHI")。**数据分析体现你"先理解数据再动手"的专业性**。

**② 手把手带做**:
1. 写 Sec1 背景(竞赛任务、指标、挑战)。
2. 写 Sec2 数据分析(EDA 发现 + 如何指导方案)。
3. 用简洁的技术报告语言(清楚 > 华丽)。

**③ 合格样例**:技术报告 Sec1(背景)+ Sec2(数据分析)成形,数据分析体现 EDA 发现和方案动机。

**④ 常踩的坑**:
- **把技术报告写成论文(过度学术包装)** → 技术报告讲清"怎么做的"即可,不用论文那么严谨的包装。

**⑤ 卡住自救(决策树)**:不知技术报告写多详细?→ 目标是"别人看完能理解并复现你的方案",够这个详细度即可;背景写多长?→ 2-3 段说清任务和挑战。

## 中午段 · 写 Sec3 方法概述(pipeline 图 + 各模块)

**① 先垫概念**:Sec3 方法概述——**用一张 pipeline 图 + 文字,讲清你的整体方案**:数据怎么处理、用了什么模型、训练用了哪些 trick、推理怎么做。pipeline 图是核心(一图讲清整体流程),文字补充各模块细节。
- **pipeline 图怎么画**:画出你方案的整体流程——数据预处理 → 模型(backbone+head)→ 训练(用了哪些 trick:多尺度/半监督/自监督预训练…)→ 推理(TTA/SAHI/Ensemble+WBF)。**一张图让读者一眼看懂你的整体方案**。
- **为什么 pipeline 图重要**:你的方案有很多组件(多个 trick、多个阶段),纯文字描述读者难以建立整体印象。**一张 pipeline 图把所有组件和它们的关系可视化,读者一眼就懂整体流程**,再配文字看各模块细节。这是技术报告(和论文 Method)的标配。
- **画 pipeline 图也在帮你理清自己的方案**:画 pipeline 图的过程,本身就是一次"梳理"——你要想清楚:数据怎么流、各模块的输入输出是什么、各 trick 在哪个阶段起作用、它们的先后关系。**很多人画图时才发现自己的方案某处其实没想透,或某两个组件的关系含糊**。所以画 pipeline 图不只是"为了让读者懂",也是**逼自己把方案的逻辑彻底理顺**的好机会。画清楚了,说明你真正理解了自己做的东西;画不清楚的地方,正是你需要再想想的地方。这种"用图理清思路"的能力,在做研究、讲方案、写论文 Method 时都用得上。

**② 手把手带做**:
1. 画 pipeline 图(数据→模型→训练trick→推理trick 的整体流程)。
2. 写 Sec3 文字(各模块描述:用了什么、为什么)。
3. 图文配合(图给整体、文给细节)。

**③ 合格样例**:Sec3 方法概述成形,有 pipeline 图(整体流程清晰)+ 各模块文字描述。

**④ 常踩的坑**:没 pipeline 图纯文字 → 画 pipeline 图(一图讲清整体);图太复杂看不懂 → 图要清晰(主流程突出,细节放文字)。

**⑤ 卡住自救**:pipeline 图怎么画?→ 按"数据→训练→推理"三阶段画,每阶段标用了什么;不会画图工具?→ 用 draw.io/PPT 画框图。

**⑥ 今天(这一步)你同时学会了什么**:你学会**用 pipeline 图 + 文字写方法概述**。**做了**(画 pipeline 图 + 写 Sec3)、**学了**(pipeline 图讲清整体、图文配合)、**会了**(系统呈现你的技术方案)。

## 晚上段 · 写 Sec4 实验(trick 列表 + 提升 + 消融)
