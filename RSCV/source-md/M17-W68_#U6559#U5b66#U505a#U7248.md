## 上午段 · 收集所有合作者反馈 + 梳理分类

**① 先垫概念（怎么处理合作者反馈）**
- 上午**收集所有合作者反馈 + 梳理分类**——① **收集所有反馈**（老师 + 所有合作师兄的反馈——合作论文需要处理所有合作者的意见）；② ★ **逐条梳理分类**（把所有反馈逐条列出，分类：**必改**[切中要害、影响质量]、**可改**[改了更好]、**可不改**[主观偏好/已合理]）；③ **理解每条反馈**（每条反馈想表达什么、怎么改）；④ **不抵触**（合作者的反馈是为论文好，虚心接受）。★ **逐条梳理分类，让修改有条理、有优先级**——合作者了解领域/期刊/团队工作，反馈尤其有价值。
- ★★ **远程模式**：同样收集线上反馈、梳理分类。

**② 手把手带做**：① 收集所有合作者反馈（老师 + 师兄）；② ★ 逐条梳理分类（必改/可改/可不改）；③ 理解每条反馈；④ 不抵触、虚心；⑤ 修改清单成型。
**③ 这一步合格的样子**：合作者反馈梳理——收集了所有反馈、逐条分类（必改/可改/可不改）、理解了每条，修改清单成型。
**④ 最常踩的坑**
- 漏处理某合作者反馈（不尊重）→ 收集所有合作者反馈。
- 不分类（修改无优先级）→ ★ 分类必改/可改/可不改。
- 抵触反馈（不虚心）→ 虚心接受、为论文好。

**⑤ 卡住怎么自救（决策树）**：反馈怎么分类？→ 必改(切中要害)/可改(更好)/可不改(主观/已合理);某条不理解？→ 标记,面对面问师兄。
**⑥ 今天（这一步）你同时学会了什么**：你**梳理分类了合作者反馈**。**做了**（收集所有反馈 + 分类 + 理解 + 虚心）、**学了**（逐条分类必改/可改/可不改、合作者反馈有价值、虚心）、**会了**（系统梳理合作者反馈）。

## 中午段 · ★ 与师兄面对面讨论修改方案

- ★★ **远程模式**：如果是远程合作，视频/语音讨论（虽不如面对面，但比文字邮件高效）。

**② 手把手带做**：① 列疑难/有分歧的反馈；② ★ 与师兄面对面讨论（当面聊清楚）；③ 当场定修改方案；④ 趁访问还在多面对面；⑤ 疑难方案定了。

**⑤ 自救**：哪些面对面讨论？→ 疑难的、有分歧的反馈;面对面聊啥？→ 怎么改、方案是什么。
**⑥ 今天（这一步）你同时学会了什么**：你**和师兄面对面讨论了修改方案**。**做了**（列疑难反馈 + 面对面讨论 + 当场定方案 + 趁访问多面对面）、**学了**（★ 面对面比邮件高效 10 倍、疑难处当面定方案、珍惜访问机会）、**会了**（利用面对面高效讨论论文修改）。

## 上午段 · 逐条修改（核心问题：方法/实验/表述）

**① 先垫概念**：上午**逐条修改核心问题**——① **改方法相关反馈**（如方法讲不清、创新点不突出——按反馈改）；② **改实验相关反馈**（如实验不充分、需补分析/对比——按反馈改，如需补实验则补）；③ **改表述相关反馈**（如逻辑/表达不清——按反馈改）；④ ★ **核心问题优先**（影响论文质量的核心反馈先改）。**逐条改核心问题，把论文的关键短板补上。**
- ★★ **远程模式**：同样。
**② 手把手带做**：① 改方法反馈（讲清/突出创新）；② 改实验反馈（补分析/对比，如需补实验则补）；③ 改表述反馈（逻辑/表达）；④ ★ 核心问题优先；⑤ 关键短板补上。
**③ 这一步合格的样子**：核心问题修改——方法/实验/表述的核心反馈改了、关键短板补上，论文质量提升。
**④ 坑**：① 核心问题不改（论文有硬伤）→ 核心问题优先改；② 该补实验不补 → 按反馈补；③ 改表面不改实质 → 改核心。
**⑤ 自救**：核心问题改啥？→ 方法讲清/实验补充/表述逻辑;要补实验？→ 据反馈补必要的。
**⑥ 今天（这一步）你同时学会了什么**：你**改了核心问题**。**做了**（改方法/实验/表述反馈 + 核心优先 + 补短板）、**学了**（核心问题优先改、补关键短板、提升质量）、**会了**（据反馈修改论文的核心问题）。

## 二、完整可运行代码 · 论文定稿投稿就绪 + M17 硬交付追踪器（+ 预期输出）

> 这个脚本追踪论文定稿投稿的就绪度 + M17 硬交付对照——看论文投稿前是否就绪、M17 收官还差什么（尤其 W69 要做的访问收尾项）。

```python
#!/usr/bin/env python3
# paper_finalize_tracker.py —— 论文定稿投稿就绪 + M17硬交付追踪器
finalize = {  # 论文定稿投稿就绪
    "所有合作者反馈处理完": True, "与师兄确认修改到位": True, "论文定稿(投稿级)": True,
    "选投稿目标(与老师商量)": True, "投稿材料(Cover Letter等)": True,
    "格式调整": True, "最终proofreading": True,
}
M17_deliverables = {  # M17硬交付6项
    "第三篇论文草稿完成(或已投)": True,
    "空天院数据完整实验结果": True,
    "组会汇报≥2次(累计)": True,
    "访问工作总结(2000字)": False,        # W69写
    "★推荐信请求已提出": False,            # W69最终1v1
    "与≥3位团队成员建立微信联系": False,   # W69告别时
}

def rate(d):
    done = sum(1 for v in d.values() if v); return done, len(d), round(done/len(d)*100)

def track():
    print("=== 论文定稿投稿就绪 + M17硬交付(W68)===\n")
    f_done, f_tot, f_pct = rate(finalize)
    print(f"【论文定稿投稿就绪】{f_done}/{f_tot} = {f_pct}%")
    for k, v in finalize.items():
        print(f"  {'✅' if v else '□'} {k}")
    d_done, d_tot, d_pct = rate(M17_deliverables)
    print(f"\n【M17硬交付】{d_done}/{d_tot} = {d_pct}%")
    for k, v in M17_deliverables.items():
        print(f"  {'✅' if v else '⏳ (W69做)'} {k}")
    print("\n" + "="*42)
    if f_pct == 100:
        print("🎉 论文投稿就绪!W69可投稿(或离开后投给老师更多审阅时间)。")
    todo = [k for k, v in M17_deliverables.items() if not v]
    if todo:
        print(f"M17还差(W69访问收官做): {len(todo)}项")
        for t in todo:
            print(f"  - {t}")

if __name__ == "__main__":
    track()
```
