# D16 · SAR 成像 + 预处理脚本

## 中午段 · SAR 数据的三种形态

见 [《名词逐个讲透》§3.1–§3.2](../start/rs-basics-deep.html)（SLC/GRD、幅度/强度/dB），那里讲得比原文细。**这里只补一个原文没说清的点。**

### ★ 20log10 还是 10log10（原文写的公式有个隐含前提）

原文给的是 `20*log10(amplitude+1)`。**这个式子在幅度上是对的，但有两个问题**：

| 问题 | 说明 | 正确做法 |
|---|---|---|
| **系数取决于你手上是幅度还是强度** | 幅度用 `20*log10`；强度（= 幅度²）用 `10*log10`。**弄反了整张图的对比度就错了一倍** | 先确认你的数据是哪种 |
| **`+1` 是个粗糙的补丁** | 它是为了防 `log(0)`，但会把小值往上抬。SAR 的暗区值常远小于 1，加 1 之后**暗部信息被压平了** | 用 `np.maximum(amp, eps)`，eps 取 `1e-6` |

## 晚上段 · 完整的 `sar_preprocess.py`

原文给了五个步骤，**没给代码**。下面是完整版，**我实测跑过**。

新建 `20-代码实验/utils/sar_preprocess.py`：

```python
"""sar_preprocess.py —— SAR 原始数据 -> 可看可训的 8bit 图。

标准链路：取幅度 -> dB -> 分位裁剪 -> 归一化 -> 8bit
这是你做任何 SAR 任务的开局动作，每次都要先做。
"""
import numpy as np
import cv2


def to_amplitude(arr):
    """复数 -> 幅度；已是实数则取绝对值。"""
    return np.abs(arr).astype(np.float32)


def amp_to_db(amp, eps=1e-6):
    """幅度 -> dB。

    ★ 注意系数：幅度用 20*log10，强度（幅度的平方）用 10*log10。
    ★ 用 maximum(amp, eps) 而不是 amp+1 —— 后者会把暗区抬平。
    """
    return 20.0 * np.log10(np.maximum(amp, eps))


def stretch(db, lo_pct=1.0, hi_pct=99.0):
    """分位裁剪 + 归一化到 0-1。

    为什么要分位裁剪：SAR 上个别超亮点（强散射体）会把整体拉暗，
    砍掉最亮/最暗的 1% 之后，中间的结构才看得清。
    """
    lo, hi = np.percentile(db, [lo_pct, hi_pct])
    if hi - lo < 1e-6:
        hi = lo + 1e-6
    return np.clip((db - lo) / (hi - lo), 0, 1)


def sar_to_png(arr, out_path, lo_pct=1.0, hi_pct=99.0):
    """一条龙：原始数组 -> 存成可看的 PNG。"""
    vis = (stretch(amp_to_db(to_amplitude(arr)), lo_pct, hi_pct) * 255).astype(np.uint8)
    cv2.imwrite(out_path, vis)
    return vis


if __name__ == '__main__':
    # 自测：不需要任何数据，用仿真 SAR 验证"为什么必须做 log"
    rng = np.random.default_rng(0)
    H = W = 256
    truth = np.full((H, W), 0.02)        # 暗区：海面
    truth[60:200, 60:120] = 1.0          # 亮区：船体（是海面的 50 倍）
    truth[80:180, 150:220] = 0.2         # 中等：海岸

    # 单视 SAR 成像：复高斯 -> 幅度服从 Rayleigh（原理见《名词逐个讲透》§1）
    z = rng.normal(0, np.sqrt(truth / 2)) + 1j * rng.normal(0, np.sqrt(truth / 2))
    amp = np.abs(z)

    print(f'原始幅度动态范围: min={amp.min():.5f} max={amp.max():.4f} '
          f'比值={amp.max() / max(amp.min(), 1e-9):.0f}x')

    lin = ((amp - amp.min()) / (amp.max() - amp.min()) * 255).astype(np.uint8)  # 不做 log
    log = (stretch(amp_to_db(amp)) * 255).astype(np.uint8)                       # 做 log
    cv2.imwrite('sar_linear.png', lin)
    cv2.imwrite('sar_log.png', log)

    print(f'线性显示: 均值={lin.mean():.1f}  低于10灰阶的像素占比={100*(lin<10).mean():.1f}%')
    print(f'log显示 : 均值={log.mean():.1f}  低于10灰阶的像素占比={100*(log<10).mean():.1f}%')
```

## ③ 合格样例 —— ★ 用数字证明 log 的必要性

**直接 `python sar_preprocess.py`**（不需要任何数据），实测输出：

```text
原始幅度动态范围: min=0.00043 max=3.0510 比值=7033x
线性显示: 均值=20.5   低于10灰阶的像素占比=40.2%
log显示 : 均值=125.6  低于10灰阶的像素占比=1.4%
```

**读这三行**：

- **动态范围 7033 倍** —— 这就是"SAR 动态范围极大"的量化含义。
- **线性显示下 40.2% 的像素低于灰阶 10**（肉眼基本是纯黑）→ **四成信息看不见**。
- **做完 log 只剩 1.4%**，平均灰度从 20.5 升到 125.6 → **图像被真正"打开"了**。

打开 `sar_linear.png` 和 `sar_log.png` 对比一眼，比读十遍解释管用。

> **★ 这就是原文说的"对比不做 log 的版本，直观感受 log 的作用"** —— 但原文没给你能跑的东西。现在你有了，而且有数字。

## ④ 常踩的坑

| 坑 | 症状 | 解 |
|---|---|---|
| 用了 `+1` 而不是 `eps` | 暗部细节丢失 | `np.maximum(amp, eps)` |
| 幅度用了 `10*log10` | 对比度只有正确值的一半 | 确认数据是幅度还是强度 |
| 不做分位裁剪 | 个别超亮点把整体拉暗 | 1%/99% 裁剪 |
| 对整个数据集用同一组 min/max | 不同图之间不可比 | **训练时逐图归一化**；若要跨图可比，用全局固定的 dB 范围 |

# D17 · 格式转换 + 裸 PyTorch baseline

## ★ 中午段增补：格式转换（全书从没教过的一类活）

### ① 先垫概念：为什么必须转换

你 W2 用的 DOTA，标注是 `.txt`，一行八个数加类别。**但 SAR 数据集不是这个格式**：

| 数据集 | 标注格式 | 长什么样 |
|---|---|---|
| DOTA | `.txt`，四点 + 类别 + difficult | `x1 y1 x2 y2 x3 y3 x4 y4 ship 0` |
| **HRSID** | **COCO JSON**，一个大 json 装所有图 | `{"images":[...], "annotations":[{"bbox":[x,y,w,h],"segmentation":[...]}]}` |
| **SSDD** | **VOC XML**，每张图一个 xml | `<bndbox><xmin>..</xmin>...</bndbox>` |

**MMRotate 只认 DOTA 格式**（也支持 COCO，但旋转框流程按 DOTA 走最顺）。**所以第一步必须转。**

### ② 完整转换脚本（实测跑过）

新建 `20-代码实验/utils/to_dota.py`：

```python
"""to_dota.py —— 把 SAR 船舶数据集的标注转成 DOTA 格式。

支持两种来源：
    COCO JSON（HRSID 等）：  python to_dota.py --coco train.json --out labelTxt/
    VOC  XML （SSDD  等）：  python to_dota.py --voc  Annotations/ --out labelTxt/
"""
import os
import json
import argparse
import xml.etree.ElementTree as ET

import numpy as np
import cv2


def hbb_to_poly(x, y, w, h):
    """水平框 (x,y,w,h) -> 四点，顺时针。"""
    return [x, y, x + w, y, x + w, y + h, x, y + h]


def seg_to_poly(seg):
    """COCO 分割多边形 -> 最小外接【旋转】框的四点。

    ★ 这一步才用上了旋转框的价值：直接用 bbox 会退化成水平框，
      白白浪费了 HRSID 提供的分割标注。
    """
    pts = np.array(seg, dtype=np.float32).reshape(-1, 2)
    return cv2.boxPoints(cv2.minAreaRect(pts)).reshape(-1).tolist()


def write_dota(out_dir, stem, objs):
    os.makedirs(out_dir, exist_ok=True)
    with open(os.path.join(out_dir, stem + '.txt'), 'w', encoding='utf-8') as f:
        f.write('imagesource:converted\ngsd:null\n')   # DOTA 的两行元信息，必须有
        for poly, cls, diff in objs:
            f.write(' '.join(f'{v:.1f}' for v in poly) + f' {cls} {diff}\n')


def from_coco(json_path, out_dir, use_seg=True):
    d = json.load(open(json_path, encoding='utf-8'))
    cats = {c['id']: c['name'].replace(' ', '-') for c in d['categories']}
    imgs = {i['id']: i['file_name'] for i in d['images']}
    per = {}
    for a in d['annotations']:
        seg = None
        if use_seg and a.get('segmentation') and isinstance(a['segmentation'], list):
            seg = a['segmentation'][0] if a['segmentation'] else None
        poly = seg_to_poly(seg) if seg and len(seg) >= 8 else hbb_to_poly(*a['bbox'])
        per.setdefault(a['image_id'], []).append(
            (poly, cats.get(a['category_id'], 'ship'), a.get('iscrowd', 0)))
    for iid, fn in imgs.items():
        # ★ 没有标注的图也要写一个空文件，否则框架会报"找不到标注"
        write_dota(out_dir, os.path.splitext(fn)[0], per.get(iid, []))
    return len(imgs), sum(len(v) for v in per.values())


def from_voc(xml_dir, out_dir):
    n_img = n_obj = 0
    for fn in sorted(os.listdir(xml_dir)):
        if not fn.endswith('.xml'):
            continue
        root = ET.parse(os.path.join(xml_dir, fn)).getroot()
        objs = []
        for o in root.findall('object'):
            name = (o.findtext('name') or 'ship').replace(' ', '-')
            diff = int(o.findtext('difficult') or 0)
            rb = o.find('rotated_bndbox')      # 部分 SSDD 版本自带旋转框
            if rb is not None:
                poly = [float(rb.findtext(k)) for k in
                        ('x1', 'y1', 'x2', 'y2', 'x3', 'y3', 'x4', 'y4')]
            else:
                b = o.find('bndbox')
                x1, y1 = float(b.findtext('xmin')), float(b.findtext('ymin'))
                x2, y2 = float(b.findtext('xmax')), float(b.findtext('ymax'))
                poly = [x1, y1, x2, y1, x2, y2, x1, y2]
            objs.append((poly, name, diff))
            n_obj += 1
        write_dota(out_dir, os.path.splitext(fn)[0], objs)
        n_img += 1
    return n_img, n_obj


if __name__ == '__main__':
    ap = argparse.ArgumentParser()
    ap.add_argument('--coco'); ap.add_argument('--voc')
    ap.add_argument('--out', required=True)
    a = ap.parse_args()
    if a.coco:
        print('转换完成: %d 张图 / %d 个目标' % from_coco(a.coco, a.out))
    elif a.voc:
        print('转换完成: %d 张图 / %d 个目标' % from_voc(a.voc, a.out))
```

### ④ 转换的常见坑

| 坑 | 症状 | 解 |
|---|---|---|
| COCO 用了 `bbox` 而不是 `segmentation` | 框全是水平的，旋转框白做 | 优先用 `segmentation` + `minAreaRect` |
| 没标注的图没生成 txt | 框架报"找不到标注文件" | 上面的代码已经处理（写空文件） |
| 类别名里有空格 | DOTA 用空格分隔，会解析错位 | 代码里已 `replace(' ', '-')` |
| COCO 的 bbox 是 `(x,y,w,h)` 当成了 `(x1,y1,x2,y2)` | 框大小全错 | **COCO 是 xywh，VOC 是 xyxy，两者不同** |
| 图片扩展名不匹配（jpg vs png） | 框架找不到图 | 转换只管标注，**图片名的 stem 必须和 txt 一致** |

## 晚上段 · 裸 PyTorch baseline（补全原文缺的三块）

原文给的代码能跑，**但缺了三样让它成为"实验"而不只是"能跑"的东西**：**没有验证集、没有准确率、没有保存模型**。补全版：

### 先解决数据组织（原文假设你已经有了 ImageFolder 结构）

原文的 `datasets.ImageFolder("OpenSARShip/train")` 要求数据长这样：

```text
sar_cls/
├── train/{ship/, no-ship/}     ← 每类一个文件夹
└── val/{ship/, no-ship/}
```

**如果你用的是 SSDD/HRSID（检测数据集），先切出分类数据**：

```python
"""make_cls_data.py —— 从检测标注切出分类小图。"""
import os, cv2, numpy as np, random
from to_dota import *          # 复用上面的工具

def crop_patches(img_dir, lbl_dir, out_dir, size=64, neg_per_img=3):
    for lf in sorted(os.listdir(lbl_dir)):
        stem = os.path.splitext(lf)[0]
        img = None
        for ext in ('.jpg', '.png', '.tif'):
            p = os.path.join(img_dir, stem + ext)
            if os.path.exists(p):
                img = cv2.imread(p); break
        if img is None: continue
        H, W = img.shape[:2]
        boxes = []
        for line in open(os.path.join(lbl_dir, lf), encoding='utf-8'):
            p = line.split()
            if len(p) < 9 or line.startswith(('imagesource', 'gsd')): continue
            pts = np.array([float(v) for v in p[:8]]).reshape(4, 2)
            boxes.append(pts)
        # 正样本：每个目标切一块
        for i, pts in enumerate(boxes):
            x, y, w, h = cv2.boundingRect(pts.astype(np.int32))
            cx, cy = x + w // 2, y + h // 2
            half = max(w, h, size) // 2
            x1, y1 = max(cx - half, 0), max(cy - half, 0)
            patch = img[y1:min(cy + half, H), x1:min(cx + half, W)]
            if patch.size:
                os.makedirs(f'{out_dir}/ship', exist_ok=True)
                cv2.imwrite(f'{out_dir}/ship/{stem}_{i}.png',
                            cv2.resize(patch, (size, size)))
        # 负样本：随机切不含目标的区域
        for k in range(neg_per_img):
            x1, y1 = random.randint(0, max(W - size, 0)), random.randint(0, max(H - size, 0))
            if any(cv2.boundingRect(b.astype(np.int32))[0] < x1 + size and
                   x1 < cv2.boundingRect(b.astype(np.int32))[0] +
                   cv2.boundingRect(b.astype(np.int32))[2] for b in boxes):
                continue                       # 和目标重叠就跳过
            os.makedirs(f'{out_dir}/no-ship', exist_ok=True)
            cv2.imwrite(f'{out_dir}/no-ship/{stem}_n{k}.png',
                        cv2.resize(img[y1:y1 + size, x1:x1 + size], (size, size)))
```

### 完整训练脚本

`20-代码实验/sar_cls/train.py`：

```python
import torch, torch.nn as nn
from torch.utils.data import DataLoader, random_split
from torchvision import models, transforms, datasets

device = 'cuda' if torch.cuda.is_available() else 'cpu'

tf = transforms.Compose([
    transforms.Grayscale(3),                 # ★ SAR 单通道 -> 复制成 3 通道喂 ResNet
    transforms.Resize((128, 128)),
    transforms.ToTensor(),
])

full = datasets.ImageFolder('sar_cls/train', transform=tf)
print(f'共 {len(full)} 张，类别 {full.classes}')      # ★ 先确认数据读进来了
n_val = int(len(full) * 0.2)
train_set, val_set = random_split(full, [len(full) - n_val, n_val],
                                  generator=torch.Generator().manual_seed(42))
train_loader = DataLoader(train_set, batch_size=64, shuffle=True, num_workers=2)
val_loader   = DataLoader(val_set,   batch_size=64, shuffle=False, num_workers=2)

model = models.resnet18(weights='IMAGENET1K_V1')
model.fc = nn.Linear(model.fc.in_features, len(full.classes))
model = model.to(device)

opt  = torch.optim.Adam(model.parameters(), lr=1e-3)
crit = nn.CrossEntropyLoss()

best = 0.0
for epoch in range(20):
    model.train()
    tot = 0.0
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()                 # ① 清梯度
        out = model(x)                  # ② 前向
        loss = crit(out, y)             # ③ 算 loss
        loss.backward()                 # ④ 反向
        opt.step()                      # ⑤ 更新
        tot += loss.item() * x.size(0)

    # ★ 验证（原文缺这一整段）
    model.eval()
    correct = n = 0
    with torch.no_grad():
        for x, y in val_loader:
            x, y = x.to(device), y.to(device)
            correct += (model(x).argmax(1) == y).sum().item()
            n += y.size(0)
    acc = correct / n
    print(f'epoch {epoch:2d} | train loss {tot/len(train_set):.4f} | val acc {acc:.4f}')

    if acc > best:                      # ★ 保存最好的（原文缺）
        best = acc
        torch.save(model.state_dict(), 'best.pth')

print(f'最好验证准确率 {best:.4f}')
```

# D18 · SAR 数据增强 + 第一次调 lr

## 中午段 · speckle 增强（原文的代码是对的，补两件事）

原文给的 Gamma 噪声写法正确：

```python
gamma = np.random.gamma(shape=looks, scale=1.0/looks, size=img.shape)
return img.astype(np.float32) * gamma
```

**补充 1：为什么这个写法是对的**

`Gamma(shape=L, scale=1/L)` 的**均值 = L × (1/L) = 1**，方差 = `1/L`。这正好对应 [《名词逐个讲透》§1](../start/rs-basics-deep.html) 说的：**L 视平均后，speckle 的变异系数是 `1/√L`**。**所以 `looks` 参数有明确的物理含义，不是随便调的旋钮。**

**补充 2：★ 一个必须注意的顺序问题（原文没提，但错了效果全反）**

```text
❌ 错误顺序：log 变换后的图 × Gamma 噪声
✅ 正确顺序：原始幅度/强度 × Gamma 噪声 → 再做 log
```

**理由**：speckle 在**线性域**是乘性的。你已经做完 log 之后，乘性已经变成加性了（`log(R·n) = log R + log n`）。**在 log 域上再乘一次 Gamma，物理上说不通。**

如果你的数据已经是 log 后的 PNG（多数公开数据集都是），**有两个选择**：

| 选择 | 做法 | 评价 |
|---|---|---|
| A | 先 `10**(x/20)` 反变换回幅度 → 乘噪声 → 再 log | 严谨，但要知道原来的 dB 范围 |
| B | 直接在 log 域**加**噪声（因为 log 域里 speckle 本来就是加性的） | **更简单且物理上自洽**，推荐 |

**这个细节值得写进你的笔记**——它说明"照搬公式"和"理解公式"的区别。

# 在 vis_dota.py 的 main 里，cv2.imread 之后加：
if img.ndim == 2 or (img.ndim == 3 and (img[:,:,0] == img[:,:,1]).all()):

## D20 晚上段 · 《SAR vs 光学五大差异》

**★ 直接用 [《名词逐个讲透》](../start/rs-basics-deep.html) 的内容**，那一页 §1–§3 就是这份文档的素材库。骨架：

| # | 差异 | 光学 | SAR | ★ 所以呢 |
|---|---|---|---|---|
| 1 | **成像方式** | 被动，收太阳光 | **主动，自己发微波** | SAR 能夜间/穿云工作 |
| 2 | **噪声** | 加性高斯 | **乘性 speckle** | 通用去噪/增强方法直接搬会失效 |
| 3 | **动态范围** | 8bit 够用 | **跨好几个数量级** | 必须 log 压缩，见 D16 那三行数字 |
| 4 | **几何** | 中心投影 | **侧视 + 按距离排像素** | layover/shadow/foreshortening 这些畸变光学没有 |
| 5 | **目标外观** | 和人眼一致 | **方位角敏感，换个角度长相全变** | 模型容易过拟合某个方位角 |

**每条都写"所以呢"**——差异本身不值钱，差异导致的技术后果才值钱。**这是你 W1-D2 就学过的写法。**
