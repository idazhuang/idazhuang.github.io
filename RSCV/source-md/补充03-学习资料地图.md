# 补充 03 · 学习资料地图
## 去哪找、去哪看、怎么找、怎么看 —— 每条资料都标注"什么时候用、读哪部分、读多久"

> **这一页解决什么**：原手册在正文里零星提到过几本书和一门 MOOC，但没说**在哪找、从哪一章开始、读多少算够**。结果就是"知道该学，但不知道从哪下手"。
>
> **一条总原则（先读这句）**：**你不是要成为遥感专业的学生，你是要成为"能看懂遥感论文、能做遥感 CV 实验"的人。** 所以这一页里所有资料都标了"读哪部分就停"。**读完标注的部分就停下来，别顺着往下读**——遥感教材后面大半是农业、林业、水文应用，和你无关。
>
> **怎么用**：先看 §6（方法论，最重要）→ 再按 §1–§5 按需取用。**不要通读这一页。**

# 1. 中文入门：先用母语把直觉建起来

对零基础的人，先用中文建立直觉、再看英文精确定义，比一上来啃英文快得多。

## 1.1 MOOC（★ 优先级最高，因为有讲有画）

**去哪找**：中国大学 MOOC `https://www.icourse163.org` → 搜索框输入 **`遥感原理`**。

会搜到好几个学校的版本（武汉大学、西北大学、武汉理工等），**选哪个都行**，判断标准只有两个：① 有没有正在开课或可回看；② 试听第一讲，讲课人语速和画风你受不受得了。

**看哪几讲就停**：

| 主题 | 对应你的什么 | 必看 |
|---|---|---|
| 电磁波与地物波谱 | M0 §2 波段 | ✅ |
| 传感器与成像原理 | M0 §3 主动/被动 | ✅ |
| 遥感图像的几何处理 | M0 §6 几何校正 | ✅ |
| 遥感图像的辐射处理 | M0 §6 辐射校正 | ✅ |
| 图像分类（监督/非监督） | 了解传统方法，知道深度学习之前大家在干嘛 | ✅ 快看 |
| 遥感在农业/林业/水文的应用 | 与你无关 | ❌ 跳过 |
| ENVI/ERDAS 软件操作 | 你用 Python，不用这些 | ❌ 跳过 |

**投入**：**总共 6–8 小时，1.5 倍速**。原手册 W1-D3 安排了"第一节遥感物理 MOOC"，就从这里挑。

**怎么看**：**不要做笔记做到暂停十次。** 一遍过，只在听到 M0 里出现过的词时暂停，把 MOOC 的讲法补进你的 `00-基础理论/术语卡片.md`。**目标是"混个耳熟"，不是掌握。**

## 1.2 中文教材（当字典用，不通读）

| 书 | 什么时候翻 | 只读哪部分 |
|---|---|---|
| **韦玉春《遥感数据处理方法》** | 原手册 W1-D7 已经安排了第 3 章 | 第 3 章（几何/辐射处理）。**其余按需查** |
| **梅安新《遥感导论》** | 想把某个概念的中文说法弄准时 | 当词典查，**不要通读** |
| **赵英时《遥感应用分析原理与方法》** | 需要知道某个地物的物理机理时 | 查目录，只读你要的那节 |

**去哪找**：这三本各高校图书馆都有；电子版在读秀、超星、各校图书馆的数据库里。**买纸质的话，二手就够，遥感基础十年不变。**

**怎么读教材（重要）**：**先读小节标题和图，再读正文。** 遥感教材的信息密度低、废话多，**图和公式才是干货**。一节读 10 分钟没抓到重点就跳过，去看 MOOC 对应那讲。

# 2. 英文经典：按"我要解决什么问题"选书，不按书单读

**关键认知**：这几本你**一本都不需要通读**。它们是工具书。

| 书 | 它能回答什么 | 什么时候读 | 读哪几章 |
|---|---|---|---|
| **Oliver & Quegan《Understanding Synthetic Aperture Radar Images》** | speckle 的统计到底是怎么回事、去斑算法为什么那样设计 | **确定做 SAR 方向后立刻读** | **第 4–5 章。这是 speckle 的权威来源，其他资料都是它的转述** |
| **Richards《Remote Sensing Digital Image Analysis》** | 遥感图像处理的标准方法与数学 | 需要严谨定义时 | 查目录取用 |
| **Lee & Pottier《Polarimetric Radar Imaging》** | 极化 SAR 的完整理论 | **只有真要做极化才读**，否则别碰 | 第 1–3 章 |
| **Cumming & Wong《Digital Processing of SAR Data》** | SAR 成像算法（原始回波怎么变成图像） | **你大概率永远不需要** | 第 1 章建立概念，够了 |

**去哪找**：先在 Google Scholar 或 Google 搜书名，很多大学会挂课程用的章节 PDF；学校图书馆的 IEEE/Wiley/Springer 电子书数据库通常有；实在不行图书馆馆际互借。

**怎么读英文专著**：**读图 → 读公式旁边的那段解释 → 遇到推导跳过。** 你要的是"这个量为什么这样定义"，不是重推一遍。**一章配一张术语卡片就算读完。**

# 3. 免费官方教程（★ 性价比最高的一类，很多人不知道）

这类资料是航天机构做的科普培训，**图好、免费、权威、专门写给跨行进来的人**。比教材友好得多。

## 3.1 优先级排序

| 资料 | 去哪找 | 是什么 | 投入 | 什么时候用 |
|---|---|---|---|---|
| **ASF《Introduction to SAR》** | `https://hyp3-docs.asf.alaska.edu/guides/introduction_to_sar/` | 一个网页讲完 SAR 基础，配图极佳 | **30 分钟** | **今天就读，读完 M0 §9 立刻读它** |
| **NASA《The SAR Handbook》** | NASA Earthdata 站内搜 "SAR Handbook"，整本 PDF 可下（约 50 MB） | 理论 + 逐步教程 + 数据 + 脚本 | 按章 2 小时 | 第 2 章当 SAR 系统入门 |
| **NASA ARSET 培训** | NASA Earthdata → Learn → Trainings，搜 "Synthetic Aperture Radar" | 免费网络研讨会，**有录像 + PDF 讲义** | 每讲 1 小时 | 想听人讲一遍的时候 |
| **NRCan《Microwave Remote Sensing》** | 搜 "Natural Resources Canada microwave remote sensing tutorial" | 成像几何畸变讲得最清楚 | 40 分钟 | 搞不懂 layover/shadow 时 |
| **NASA NISAR 教育资源页** | `https://science.nasa.gov/mission/nisar/sar-education-resources/` | 上面这些的**总索引**，还链了公开的 SAR 课程 | 5 分钟 | 想找更多时从这里进 |

## 3.2 怎么用这类资料

**它们的正确用法是"先看图后看字"**。ARSET 的讲义 PDF 尤其如此——**一页一个概念一张图**，快速翻完就能建立整体感，比读教材快 5 倍。

**一个具体动作**：现在就把 ASF 那一页和 SAR Handbook 第 2 章下载/存到 `RS-CV/00-基础理论/`。**离线存一份**，因为这些站点偶尔改版换链接。

# 4. 论文：怎么找、找哪些、怎么判断值不值得读

## 4.1 三个入口，各有各的用

| 平台 | 网址 | 强项 | 弱项 |
|---|---|---|---|
| **Google Scholar** | `scholar.google.com` | 覆盖最全、能看引用数和被引列表 | 国内需自备网络条件 |
| **arXiv** | `arxiv.org` | 最新预印本，免费全文。看 `cs.CV` 和 `eess.IV` | 未经同行评审，质量参差 |
| **IEEE Xplore** | `ieeexplore.ieee.org` | 遥感顶刊都在这 | 要机构订阅 |

**国内替代**：Semantic Scholar（`semanticscholar.org`）功能接近 Google Scholar 且访问顺畅；中文文献用知网/万方。

## 4.2 遥感 CV 该盯哪些期刊会议（**这张表建议背下来**）

| 名称 | 定位 | 你的用法 |
|---|---|---|
| **IEEE TGRS** | 遥感领域最主要的期刊，量大 | **你的主战场**，第一篇大概率投这 |
| **IEEE GRSL** | Letters，篇幅短、周期快 | **适合第一篇小工作** |
| **IEEE JSTARS** | 偏应用 | 备选 |
| **ISPRS J. P&RS** | 影响因子高，偏方法与摄影测量 | 读，暂时别投 |
| **Remote Sensing of Environment (RSE)** | 遥感科学顶刊，偏地学 | 了解即可，不是你的方向 |
| **CVPR / ICCV / ECCV** | CV 顶会 | **方法创新看这里**，遥感的活很多是 CV 方法的迁移 |
| **EARTHVISION（CVPR workshop）** | 遥感 × CV 的交叉 workshop | **最贴你方向，必看** |

## 4.3 「三步法」建立一个领域的地图

这是你在 M3 选方向时要反复用的动作：

**第一步：找综述定骨架。**
Google Scholar 搜 `<方向> survey` 或 `<方向> review`，**按引用数排序**，选**近三年内 + 引用较高**的一篇。原手册 W1 安排的 Zhu 2017、Cheng 2020 就是这类。
> 读综述只读三处：**分类框架图**（这个领域怎么切分）、**方法对比表**（谁比谁强）、**Future Directions 那一节**（★别人替你列好的选题清单）。

**第二步：顺引用链往回挖经典。**
综述里被反复提到的那几篇 = 该方向的地基。挨个读。

**第三步：往前追最新。**
在 Google Scholar 里点开经典论文的 **"被引用次数"** → 勾选"按时间排序" → 看最近一年谁在引用它。**这一步能让你看到这条线现在做到哪了**，是判断"这个题还有没有空间"的关键动作。

## 4.4 怎么判断一篇论文值不值得花两小时

**60 秒筛选法**，按顺序：

1. **看发表在哪、哪一年**。三年内 + 前面那张表里的地方 → 继续；否则大概率跳过。
2. **看图 1**。看不懂图 1 在讲什么，多半这篇写得不好，或者你还不该读它。
3. **看实验表格用了哪些数据集**。和你的方向不重合 → 跳过。
4. **看 Conclusion 最后一段的 limitation**。**这是最快找到"可做口子"的地方。**

通过这四关才值得走原手册的"精读 5 遍法"。**一天精读 1 篇 + 60 秒筛掉 10 篇，是正常节奏。**

## 4.5 榜单与代码索引

- **Papers with Code**（`paperswithcode.com`）：搜 `oriented object detection`、`SAR ship detection`，能看到榜单和对应开源实现。**判断"当前 SOTA 是多少"最快的方式。**
- **GitHub 的 awesome 列表**：搜 `awesome remote sensing object detection`、`awesome SAR`。这些列表由领域内的人维护，**比你自己搜全得多**。
- **注意**：榜单上的数字要看清楚**用的哪个 split、哪种 mAP 算法**（见《名词逐个讲透》§5.3），否则会被误导。

**下大数据集的三条纪律**：

1. **先下一个小子集验证流程**，别一上来下 40 GB 才发现格式不对。
2. **`wget -c` 或用支持续传的下载器**，长时间下载必然断。
3. **数据放在项目目录外，用软链接指过去**（`ln -s /data/DOTA ./data/DOTA`）。否则你迟早会把几十 GB 提交进 git。

# 6. ★ 方法论：遇到一个不认识的词，具体该怎么做

**这一节是这一页最值钱的部分。** 资料清单会过期，方法不会。

## 6.1 三层查法（照着做，每次不超过 20 分钟）

**第 0 层（10 秒）**：先查手册自己的《名词逐个讲透》和 `glossary.html`。**很多词已经在里面了。**

**第 1 层（3 分钟）—— 建立粗直觉**
- 搜**英文原词 + explained / tutorial / introduction**，例如 `speckle noise SAR explained`。**一定用英文搜**，中文资料在这个领域少一个量级。
- 英文维基百科可以看，但**只当骨架，不当权威**——记它的定义句和公式，别信它的细节。
- 如果这个词属于 SAR，**直接去 ASF 那一页 Ctrl+F**，命中率很高。

**第 2 层（15 分钟）—— 弄准确**
- 搜 `<词> site:earthdata.nasa.gov` 或 `<词> site:esa.int`。**用 `site:` 限定优质来源，是过滤内容农场最有效的一招。**
- 或者 Google Scholar 搜 `<词> review`，打开一篇综述，Ctrl+F 找这个词第一次出现的地方——**综述里的定义句通常是最精炼准确的。**

**第 3 层（按需）—— 挖到底**
- 去 §2 那几本书里找对应章节。
- 或者去看**最早提出这个概念的那篇论文**（综述的引用里能找到）。

**止损规则**：**20 分钟没搞懂就停**，把它记进 `00-基础理论/待查清单.md`，继续手上的事。原手册那句"记下来的'不懂'是任务不是失败"就是这个意思——**但要真的记下来，并且每周复盘时清一次**。

## 6.2 怎么判断一个搜到的资料值不值得看

| 信号 | 判断 |
|---|---|
| 来自 NASA / ESA / 高校课程页 / 教科书 | ✅ 优先 |
| 有公式、有配图、有参考文献 | ✅ |
| 作者是这个领域发过论文的人 | ✅ |
| 农场式博客，通篇文字无图，互相抄 | ❌ 跳过 |
| CSDN / 知乎 | ⚠️ **查报错和装环境时很好用**（中文实战经验多）；**学概念时不要依赖**，错误率不低 |
| 大模型给的解释（包括这一页） | ⚠️ 当**索引和入门**用，涉及具体数字、公式、版本号时**回到一手来源核对** |

## 6.3 「怎么看」—— 三条读法纪律

1. **15 分钟规则**：任何一份资料，**先花 15 分钟粗读**（标题 + 图 + 小结）。15 分钟后问自己"它能不能回答我此刻的问题"。不能就换。**新手最大的浪费是从第一页老实读起。**
2. **"能给别人讲一遍"才算懂**：合上资料，用自己的话说出 ① 它是什么 ② 打个比方 ③ 不懂它会在哪卡住。**说不出来 = 没懂**，回去再看一遍那张图。
3. **当场沉淀，否则等于没看**：立刻写进术语卡片。**没写卡片的阅读，三个月后等于零。**

## 6.4 术语卡片模板（存到 `RS-CV/00-基础理论/术语卡片.md`）

```markdown
## speckle（相干斑）
- **一句话**：SAR 相干成像固有的颗粒噪声，乘性，不是设备缺陷。
- **比方**：激光照白墙看到的闪烁花纹。
- **关键式子**：I = R·n，E[n]=1；单视强度 CV=1，L 视 CV=1/√L。
- **在图上**：均匀农田变成跳动的黑白麻点。
- **不懂会卡在**：读不懂 SAR 论文动机段；不理解虚警从哪来。
- **一手来源**：Oliver & Quegan 第 4–5 章 / ASF Introduction to SAR
- **它引出的问题**：去斑与检测联合优化？乘性场景的数据增强？
- **首次遇到**：M0 §9 ｜ **复习日期**：____
```

**用法**：每读到一个新词就填一张。三个月后你会有一份**比任何教材都贴合你自己的字典**——因为它是用你自己的话写的。
