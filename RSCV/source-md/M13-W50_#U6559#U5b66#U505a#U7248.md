## 中午段 · 第三课题候选 1 toy 实验（跑 baseline + your method 看信号）

**① 先垫概念（toy 实验"看信号"是什么）**
- 第三课题选题前，对候选 idea 跑 toy 实验**"看信号"**——用小数据快速跑：① **baseline**（不加你的方法）；② **your method**（加上你的 idea）；③ 看 your method 相比 baseline 有没有**正向信号**（指标提升、或定性效果改善）。**toy 实验不追求完整结论，只看"这个 idea 有没有戏"**——有正向信号→值得深入；没信号→可能要调整或换 idea。这是用小成本快速筛选 idea 的关键。
- **为什么看信号而非完整实验**：完整实验耗时耗算力，3 个候选都做完整不现实（单卡）。toy 实验快速看信号，能在小成本下判断每个 idea 的潜力，为三选一提供依据。这正是单卡研究者必须掌握的"决策智慧"——你没有算力把三个 idea 都做成完整实验再挑最好的，但你可以用三次小成本的 toy 实验，快速看出哪个最有戏，把有限的算力押到最对的那一个上。比起"广撒网式"地烧算力，这种"先侦察后进攻"的打法效率高得多。

**② 手把手带做**：① 用 W49 搭好的 toy 框架，跑候选 1：baseline（基线）+ your method（加 idea）；② 看信号（your method vs baseline 的指标差异、或定性效果）；③ 记录 toy 信号（提升多少/有无改善/是否符合预期，见补充包范例 2）；④ 控制规模（小数据、快速跑，单卡几小时内）；⑤ 初步判断候选 1 的潜力（有信号/无信号/待定）。
**③ 这一步合格的样子**：候选 1 toy 实验跑完——baseline + your method 的信号记录清楚（提升/改善/无信号），初步判断了潜力。
**④ 最常踩的坑**
- toy 实验做成完整实验（耗时）→ 小数据快速看信号即可（toy 的意义）。
- 不跑 baseline 只跑 method → 要对比 baseline 才知道是不是你的方法带来的提升。
- 信号不记录 → 记清楚（提升多少/改善/无信号，为三选一）。

**⑤ 卡住怎么自救（决策树）**：toy 跑太慢？→ 减小数据/降分辨率/减 epoch（看信号够用）；没看到信号？→ 记录"无明显信号"（也是有用的决策信息），可能调整或这个 idea 不行。
**⑥ 今天（这一步）你同时学会了什么**：你**用 toy 实验看了候选 1 的信号**。**做了**（候选 1 toy:baseline+your method + 记信号 + 控规模 + 初判潜力）、**学了**（toy 看信号不求完整结论、对比 baseline、小成本筛 idea）、**会了**（用 toy 实验快速判断一个 idea 的潜力）。

## 二、完整可运行代码 · 选题决策器（toy 信号 + idea 评分综合，+ 预期输出）

> 这个脚本把 toy 实验信号量化后，和 W49 的 idea 评分综合，给出最终的选题推荐——把"三选一"从拍脑袋变成 toy 信号 + 战略评分的综合决策。

```python
#!/usr/bin/env python3
# topic_decider.py —— 第三课题三选一决策器（toy信号 + idea评分）
# toy 信号量化：强=10 中=6 弱=3 无=0
SIGNAL = {"强": 10, "中": 6, "弱": 3, "无": 0}
# 综合权重：toy信号占 0.4（技术潜力），idea评分占 0.6（战略契合，含能否对接）
W_SIGNAL, W_SCORE = 0.4, 0.6

candidates = {
    "候选1 (speckle-aware跨模态)": {"signal": "强", "idea_score": 8.4},
    "候选2 (旋转检测few-shot)":    {"signal": "中", "idea_score": 7.3},
    "候选3 (跨域泛化新范式)":      {"signal": "无", "idea_score": 6.85},
}

def decide(cands):
    print("=== 第三课题三选一决策（toy信号 + idea评分）===\n")
    ranked = []
    for name, c in cands.items():
        sig = SIGNAL[c["signal"]]
        final = sig * W_SIGNAL + c["idea_score"] * W_SCORE
        ranked.append((name, final, c["signal"], c["idea_score"]))
    ranked.sort(key=lambda x: -x[1])
    for r, (name, final, sig, score) in enumerate(ranked, 1):
        print(f"{r}. {name}")
        print(f"   toy信号={sig}（量化{SIGNAL[sig]}）| idea评分={score} | 综合={final:.2f}")
    top = ranked[0]
    print(f"\n🏆 推荐第三课题：{top[0]}（综合 {top[1]:.2f}）")
    if top[2] == "无":
        print("   ⚠️ 注意：首选的 toy 信号为'无'，技术风险高，建议复核或换候选")
    else:
        print("   ✅ 首选 toy 有信号 + 评分综合最优，可锁定立项")
    print("   注：决策器是辅助，最终结合你的兴趣/把握定。")

if __name__ == "__main__":
    decide(candidates)
```

**预期输出**：
```

1. 候选1 (speckle-aware跨模态)
   toy信号=强（量化10）| idea评分=8.4 | 综合=9.04
2. 候选2 (旋转检测few-shot)
   toy信号=中（量化6）| idea评分=7.3 | 综合=6.78
3. 候选3 (跨域泛化新范式)
   toy信号=无（量化0）| idea评分=6.85 | 综合=4.11

🏆 推荐第三课题：候选1 (speckle-aware跨模态)（综合 9.04）
   ✅ 首选 toy 有信号 + 评分综合最优，可锁定立项
```
> 解读：把 3 个候选的 toy 信号（强/中/弱/无）和 idea 评分填进 candidates，脚本量化 toy 信号、和评分加权综合、推荐选题。注意 toy 信号"无"的候选会被警示（技术风险高）——呼应"别选 toy 完全没信号的"。决策器辅助你把 toy 信号和战略评分综合起来，最终结合你的判断定。
