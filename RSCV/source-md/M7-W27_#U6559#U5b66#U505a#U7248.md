## 中午段 · 同步上传 arXiv(可选但推荐)

**① 先垫概念(arXiv:提前获得学术关注)**:
- **arXiv** 是一个开放的论文预印本平台。把论文同步上传 arXiv(可选但推荐)——**能让你的工作提前被学术社区看到**(不用等期刊审稿几个月后才公开),可能更早被引用、被关注。很多研究者投稿同时挂 arXiv。
- **arXiv 需要 endorsement(背书)**:第一次在某个领域提交 arXiv,需要 **endorsement**(已有 arXiv 投稿记录的人给你背书,或通过机构邮箱认证)。这是 arXiv 防止滥用的机制。**提前解决 endorsement**(找导师/同领域有 arXiv 账号的人背书,或用学校邮箱注册)。
- **挂 arXiv 的注意点**:① 确认目标期刊允许预印本(大多数允许,但要确认 IEEE 的政策);② 挂的版本和投稿版本一致;③ 选对 arXiv 分类(cs.CV 等)。
- **为什么推荐挂 arXiv(对你的意义)**:你是转型新人,需要让领域(尤其空天院方向的人)看到你的工作。**arXiv 是让你的工作被看见的好渠道**——挂上去、配好关键词,做相关方向的人搜索时就可能看到你的工作。这对建立你在领域的存在感、未来联系空天院(让他们看到你围绕 RingMo/空天·灵眸方向的工作)都有帮助。

**② 手把手带做**:
1. 确认目标期刊允许预印本(查 IEEE 政策)。
2. 解决 arXiv endorsement(机构邮箱或找人背书)。
3. 上传论文到 arXiv(选对分类 cs.CV、版本和投稿一致)。

**③ 合格样例**:论文同步上传 arXiv(分类正确、版本一致),获得一个 arXiv 编号(或:确认期刊政策后决定暂不挂)。

**④ 常踩的坑**:没确认期刊预印本政策就挂 → 先查期刊政策(虽大多允许);endorsement 没解决卡住 → 提前用机构邮箱或找人背书。

## 上午段 · 用竞赛数据做 MAE 自监督预训练(原理 + 启动)

**① 先垫概念(MAE 自监督预训练——M2 所学的实战应用)**:
- **MAE(Masked Autoencoder)**:你 M2 学过——一种自监督预训练方法,**随机遮挡图像的大部分(如 75%)patch,让模型重建被遮挡的部分**。模型为了重建,必须学到图像的内在结构和语义——这样**不用任何标注**,就从大量图像里学到了好的表征(特征提取能力)。
- **为什么竞赛里用 MAE 自监督预训练能提分**:竞赛常有**大量无标注数据**(或测试集)。① 用这些无标注数据做 MAE 自监督预训练,模型学到一个**更适配竞赛数据分布的表征底座**(比在 ImageNet 上预训练的更贴近竞赛数据);② 然后在有标注数据上 finetune(微调),下游任务精度往往提升。**这是"用无标注数据预训练 + 有标注数据微调"的经典范式**,在数据分布特殊(如遥感)的竞赛里尤其有效。
- **为什么这契合你的定位(M2 所学 + 标注稀缺发力线)**:① **这是你 M2 学的 MAE 的实战应用**——把学过的自监督预训练用到真实提分场景,知识落地;② **自监督利用无标注数据,正契合你"标注稀缺"的发力线**——遥感无标注数据多、标注贵,自监督预训练是充分利用无标注数据的核心手段。所以这不只是竞赛 trick,也是你研究方向(标注稀缺下如何学好表征)的实战练兵。
- **单卡跑 MAE 预训练的现实**:MAE 预训练(尤其 ViT)耗时长、耗资源。你单卡 4090——**用适中的模型规模和分辨率(够用即可),提前启动、后台挂机训练**。别追求超大规模(单卡跑不动也没必要),目标是学到比通用预训练更贴竞赛数据的表征。
- **MAE 自监督也可能是你第二课题的方向(往前看一步)**:你这次把 MAE 用作竞赛提分,但**"自监督预训练 + 遥感"本身就是一个很有研究价值的方向**——遥感有海量无标注卫星图,如何用自监督(MAE 这类)从这些无标注数据里学到好的遥感表征,是学界的热点(RingMo 等遥感基础模型背后就有自监督的影子)。**对你而言,一个可能的差异化切入点是:不做"更大的遥感自监督基础模型"(那是大组的赛道),而是研究"如何在单卡预算内、用自监督高效地适配到具体下游任务"**——比如轻量的自监督预训练、或把大的遥感基础模型通过自监督+蒸馏高效适配到小模型。这又回到你"下游特化/高效适配/单卡高效"的定位。今天用 MAE 提分,也是在为这个潜在方向积累实操经验。

**② 手把手带做**:
1. 用竞赛的无标注/全部数据,配置 MAE 自监督预训练(遮挡比例如 75%)。
2. 启动预训练(适中模型/分辨率,后台挂机)。
3. 监控预训练进度(重建 loss 下降)。

**③ 合格样例**:MAE 自监督预训练在竞赛数据上启动、正常训练(重建 loss 下降)。

**④ 常踩的坑**:
- **预训练耗时长没提前启动** → 提前一天启动、后台挂(预训练慢,别临时跑)。
- **4090 跑超大 ViT 预训练 OOM/超慢** → 用适中模型/分辨率,够用即可。

**⑤ 卡住自救(决策树)**:预训练太慢?→ 降模型规模/分辨率、减预训练 epoch(够用即可,不必充分);重建 loss 不降?→ 检查遮挡比例、学习率、数据加载。

**⑥ 今天(这一步)你同时学会了什么**:你**把 MAE 自监督预训练用到了竞赛实战**。**做了**(配置 + 启动 MAE 预训练)、**学了**(自监督预训练学更贴数据的表征、M2所学的实战应用、契合标注稀缺)、**会了**(用无标注数据做自监督预训练提分)。

## 中午段 · 监控预训练 + 准备 finetune

**① 先垫概念**:MAE 预训练是"学表征底座",预训练后要**用预训练的权重初始化下游模型,在有标注数据上 finetune**(微调)——这才是最终用于竞赛任务的模型。预训练时监控重建 loss,准备好 finetune 的配置。
- **预训练 → finetune 的衔接**:预训练学到的是通用表征(encoder 权重),finetune 是把这个 encoder 接上任务头(检测/分割头),在有标注数据上微调。预训练好的 encoder 给 finetune 一个好的起点。

**② 手把手带做**:
1. 监控 MAE 预训练(重建 loss、可视化重建效果)。
2. 准备 finetune 配置(用预训练 encoder 初始化 + 任务头)。

## 上午段 · 换任务特定 loss(旋转角度 KLD / SmoothL1+IoU)

**① 先垫概念(任务特定 loss——贴任务特性的优化)**:
- **标准的检测 loss(如 SmoothL1 回归框)不一定最适合旋转框**。旋转目标检测有它的特殊性——**旋转框比水平框多了一个"角度"参数,而角度有周期性**(0° 和 180° 在某些定义下接近、角度的回归有边界跳变问题)。用标准 loss 直接回归角度,会遇到角度周期性带来的优化困难。

> 上午实现 SAHI 切片推理(大图切小 patch 推理再合并)、解决小目标漏检;中午晚上提交看效果。

> **预期管理**:今天竞赛冲刺Day3——SAHI切片推理。提醒:**SAHI(Slicing Aided Hyper Inference)推理时把大图切成小patch分别检测再合并**——遥感大图里小目标在原图上太小易漏检,切成小块后小目标相对变大、检出率提升,是**遥感小目标检测的神器**;切片合并时重复框用NMS/WBF去重,切片overlap太小会漏检边界目标(呼应你M1学的大图切块/overlap概念);这招和你M1学的"大图切块"、小目标难题一脉相承。

## 上午段 · 实现 SAHI 切片推理(小目标神器)

**① 先垫概念(SAHI——遥感小目标检测的实用利器)**:
- **SAHI(Slicing Aided Hyper Inference,切片辅助超推理)**:推理时,**把大图切成若干小 patch(切片),对每个 patch 分别做检测,再把各 patch 的检测结果合并回原图**。
- **为什么 SAHI 对遥感小目标有奇效(原理)**:遥感大图(如 4000×4000)里,小目标(车、船)可能只有几十个像素——**在整张大图上直接检测,小目标占比太小、容易漏检**(模型"看不清"那么小的东西)。**而把大图切成小 patch(如 1024×1024)后,同样的小目标在 patch 里相对变大了(占比提升)**,模型更容易检出。检完各 patch 再合并回原图。**这相当于"凑近了看"——大图整体看漏掉的小目标,切块凑近看就检出了**。所以 SAHI 是遥感小目标检测的"神器"。
- **SAHI 和你 M1 所学一脉相承(知识的连贯)**:回想你 M1 学的——遥感大图要"切块(tiling)"处理(因为整图太大放不进显存/模型),切块时要留 **overlap(重叠)** 避免切断边界目标。**SAHI 本质就是把"切块"这个思路用到推理阶段的小目标检测上**:切块让小目标相对变大、检出率提升,overlap 避免边界目标被切断漏检。**你 M1 学的大图切块、小目标难题,在这里得到了实战应用和深化**——知识是连贯的,早期学的基础概念在后期反复用上。
- **SAHI 的关键:切片合并去重 + overlap**:① **合并去重**——各 patch 检测的框合并回原图时,**重叠区域的目标可能被多个 patch 重复检测,要用 NMS/WBF 去重**;② **overlap**——切片时留重叠(避免目标正好被切在 patch 边界上而漏检/检不全),但 overlap 也会增加重复(靠去重解决)。**合理的切片大小 + overlap + 去重,是 SAHI 用好的关键**。
- **SAHI 这类"看似简单却很有效"的技巧,值得你重视**:SAHI 的原理朴素得近乎"常识"——大图看不清小目标,就切块凑近了看。**但正是这种朴素、贴合任务本质的技巧,往往在实战中极有效**(尤其遥感小目标这个真痛点)。这给你一个重要启示:**好的方法不一定复杂、不一定要大模型,有时一个贴合问题本质的简单技巧就能解决大问题**。这正契合你"不拼规模、拼对问题的理解"的定位——SAHI 不需要更大的模型、更多的算力,只需要对"遥感小目标为什么难"有正确的理解(尺度问题),就能设计出有效的解法。你做研究、找 idea 时,也该多想"这个问题的本质是什么、有没有贴合本质的简单解法",而非一味追求复杂。

**② 手把手带做**:
1. 实现 SAHI 切片推理:大图切成小 patch(带 overlap)→ 各 patch 检测 → 合并回原图。
2. 合并时用 NMS/WBF 去重(重叠区域的重复框)。
3. 准备提交。
```python
# SAHI 切片推理思路（可用 sahi 库：pip install sahi）
def sahi_inference(big_image, model, slice=1024, overlap=0.2):
    H, W = big_image.shape[:2]
    step = int(slice * (1 - overlap))          # 带 overlap 的步长
    all_boxes = []
    for y in range(0, H, step):
        for x in range(0, W, step):
            patch = big_image[y:y+slice, x:x+slice]
            boxes = model(patch)               # 在小 patch 上检测（小目标相对变大）
            boxes[:, [0,2]] += x; boxes[:, [1,3]] += y   # 框坐标映射回原图
            all_boxes.append(boxes)
    return nms_or_wbf(concat(all_boxes))       # 合并 + 去重（重叠区重复框）
```

**③ 合格样例**:SAHI 切片推理跑通(切片→检测→合并去重),小目标检出率提升。

**④ 常踩的坑**:
- **切片合并时重复框没去重** → 重叠区目标被多 patch 检测,用 NMS/WBF 去重。
- **切片 overlap 太小** → 边界目标被切断漏检(回想 M1 的 overlap 概念),留适当 overlap。

**⑤ 卡住自救(决策树)**:重复框多?→ 调 NMS/WBF 的 IoU 阈值去重;边界目标漏?→ 增大 overlap;实现复杂?→ 用现成的 sahi 库。

## 二、实用工具 — SAHI 切片推理 + KLD loss(旋转检测)
```python
import torch
# ① SAHI 切片推理（大图小目标神器；可用 sahi 库）
def sahi_infer(img, model, slice=1024, overlap=0.2, nms_iou=0.5):
    H, W = img.shape[:2]; step = int(slice * (1 - overlap)); boxes = []
    for y in range(0, H, step):
        for x in range(0, W, step):
            b = model(img[y:y+slice, x:x+slice])     # 小patch上检测,小目标相对变大
            b[:, [0,2]] += x; b[:, [1,3]] += y       # 框映射回原图坐标
            boxes.append(b)
    return nms(torch.cat(boxes), iou=nms_iou)        # 合并+去重(重叠区重复框)

# ② 旋转检测任务特定 loss：KLD（把旋转框建成2D高斯，比较分布）
# 直接用 MMRotate 现成实现，配置里指定即可：
#   loss_bbox=dict(type='KLDLoss', ...) 或 GWDLoss/KFLoss
# 原理：不直接回归角度(避周期性跳变),而是比较两个高斯分布的KL散度 → 优化更友好
```
**预期**:① SAHI 把大图切小patch检测再合并去重,显著提升遥感小目标检出;② 旋转检测用 KLD loss(高斯建模)绕过角度周期性。两者都贴遥感/旋转检测的任务特性。
