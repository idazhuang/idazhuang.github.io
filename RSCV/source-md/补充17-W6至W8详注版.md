# 第一部分 · W6 遥感 VLM

## ★ 先算一笔账：单张 4090 在 VLM 上能做什么、不能做什么

**这是 W6 最该先说清、原文却没说的事。** 不知道这个账，你会在 D37 试图跑 GeoChat 时莫名其妙地 OOM，然后怀疑是自己配错了。

### 显存的基本换算（记住这个，后面反复用）

```text
模型参数量 × 每个参数占的字节数 = 加载模型所需显存

fp32（默认）    : 每参数 4 字节
fp16 / bf16     : 每参数 2 字节   ← 推理常用
int8 量化       : 每参数 1 字节
int4 量化       : 每参数 0.5 字节
```

**再加上**：推理时还要放激活值和 KV cache（几个 GB）；**训练时还要放梯度和优化器状态，通常是参数量的 3–4 倍**。

### 对着这张表判断（★ 4090 = 24GB）

| 模型规模 | fp16 推理 | int4 推理 | **全量微调** | LoRA 微调 |
|---|---|---|---|---|
| **CLIP 类（~0.4B）** | 约 1 GB ✅ | — | ✅ 轻松 | ✅ |
| **7B（GeoChat / LLaVA 类）** | 约 14 GB + 激活 ≈ **勉强够** ⚠️ | 约 4–6 GB ✅ | ❌ **需要 80GB+** | ⚠️ 可能，要开各种省显存技巧 |
| **13B** | 约 26 GB ❌ | 约 8 GB ✅ | ❌ | ❌ |
| **遥感基础模型预训练（从零）** | — | — | ❌ **要几十张卡训几周** | — |

## ★ D36 RemoteCLIP demo（原文标记为高危缺口的那一格）

原文说"跑 RemoteCLIP demo（zero-shot 分类）"，**没给权重地址、没说 zero-shot 分类怎么做**。

```

```

**★ zero-shot 分类的原理**（原文没解释，但这是理解 CLIP 的关键）：

```text
① 把 N 个类别名写成句子："a satellite image of a {类别}"
② 用文本编码器把这 N 句话编码成 N 个向量
③ 用图像编码器把你的图编码成 1 个向量
④ 算图像向量和 N 个文本向量的余弦相似度，最大的那个就是预测类别
```

**为什么这叫 "zero-shot"**：**模型从没在你这个数据集上训练过**，它只是把图和文字放进了同一个语义空间。**换一批类别名，不用重新训练就能分新的类。**

**★ 这个特性对遥感的意义**（值得记进 idea）：遥感标注极贵，**zero-shot 意味着可以不标注就做分类**。但它的代价是精度通常明显低于有监督——**"zero-shot 精度不够"这件事本身就是一堆论文的动机**。

## D40 · VLM 在遥感的 5 大未解问题（原文让你写，这里给候选）

| # | 问题 | 为什么难 | ★ 单卡能不能碰 |

# 第二部分 · W7 自监督 + 方向决策

## ★ D46 "启动小规模 MAE 预训练（4–6h）"—— 现实校准

原文安排了一次小规模 MAE 预训练。**这件事单卡可行，但要把预期定对**：

| 项 | 现实 |
|---|---|
| 模型 | **ViT-Small 或更小**，不要 ViT-Base 起步 |
| 数据 | NWPU-RESISC45（3 万张，256×256），**这个规模单卡能转** |
| 时间 | 4–6 小时能跑几十个 epoch |
| **★ 期望结果** | **重建图会很模糊，这是正常的**；你能看到 loss 下降就算成功 |
| **★ 不该期望** | 下游微调后超过 ImageNet 预训练。**3 万张图 vs ImageNet 130 万张，赢不了** |

**★ 这个"赢不了"本身是今天最重要的结论**，原文没有明说：

> **自监督预训练的价值来自数据规模。** 你这次实验真正学到的是"MAE 的机制怎么跑通"，**而不是"我的预训练比 ImageNet 强"**。如果你在报告里写成后者，那是自欺欺人。
>
> **诚实的写法**：*"在 3 万张图上预训练 40 epoch 后，下游微调准确率 X%，低于 ImageNet 预训练的 Y%。这符合预期——自监督的收益依赖数据规模，本实验的目的是验证流程和理解机制。"*

**★ 而这个结论直接决定你的方向选择**：**"做一个更好的遥感基础模型"这条路，对单卡的你是关死的。** 不是因为你不聪明，是因为算力门槛。**W7-D49 拍板时，这一条要写进决策书的"我排除了什么"。**

# 第三部分 · W8 Deep Dive

## ★ "差量阅读"到底怎么做（原文提了这个词，没解释）

W8 要你连读 10 篇 A 级论文。**按 W1-D2 学的 5 遍法，一篇 60–90 分钟，10 篇就是十几个小时**——这一周做不完，而且会读崩。

**"差量阅读"就是解决这个的方法。**

### 原理

**读同一方向的第 2 篇之后，大部分内容你已经知道了。** 所以从 A2 开始，**你只读"和前一篇的差异"**：

```text
A1（第一篇，最核心的）：完整走 5 遍法，90 分钟
                        ★ 这一篇要读透，它是你的"基准坐标系"

A2 起：只问四个问题，25 分钟一篇
   ① 它说 A1（或前人）差在哪？
   ② 它改了哪一处？（backbone / neck / head / loss / 数据 / 训练策略）
   ③ 改完提升了多少？在哪个数据集上？
   ④ 它自己承认还没解决什么？
```

### 差量阅读的记录表（一张表读完 10 篇）

```markdown
| # | 论文 | 年份 | 它说前人差在哪 | 改了哪一处 | 提升 | 未解决 |
|---|------|------|--------------|-----------|------|--------|
| A1 | | | （基准，完整笔记另开一篇） | | | |
| A2 | | | | loss | +1.2 mAP | |
| A3 | | | | neck | +0.8 | |
| ... |
```

**★ 这张表填完，你会自动看出三件事**（这就是 W8 的真正产出）：

1. **大家都在改哪个部件？** —— 如果 8 篇里有 6 篇改 loss，说明**loss 这个维度已经卷了**。
2. **有没有哪个部件没人碰？** —— **那可能是机会，也可能是死路**（要判断是"没人想到"还是"试过没用"）。
3. **提升幅度在递减吗？** —— 如果最近三年从 +2.0 掉到 +0.3，说明**这条线接近饱和**，该换角度了。

> **★ 第 3 条是判断"方向还有没有空间"最直接的证据**，比任何主观感觉都可靠。

## D55 · SOTA 复现 sanity check（"资格证"）

原文叫它"你的资格证"，说得对，**但没说怎么判定通过**。

### 判定标准（复用 [W2 实操 §6](w2-baseline.html) 的口径）

| 你的复现值 vs 论文报告值 | 判定 | 该做什么 |
|---|---|---|
| **±1 个点以内** | ✅ **通过，拿到资格证** | 记录协议，进 M3 |
| 1–3 个点 | ⚠️ 可接受 | **必须在报告里写清你的协议和论文的差异** |
| **> 3 个点** | ❌ 有实质问题 | 按 [排查顺序](../self-rescue.html)：① 评测协议 ② 数据预处理 ③ 训练配置 ④ 随机种子 ⑤ 环境 ⑥ 才怀疑实现 |

> **★ 为什么这是"资格证"**：**你要改进一个方法，前提是你能复现它。** 复现不出来就改，你根本分不清"我的改进有用"和"我复现得比别人差"。**M3 之后你所有的对比实验都以这个复现值为基准**——这个数字错了，后面全错。
