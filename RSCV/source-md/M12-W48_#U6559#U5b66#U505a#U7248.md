## 二、完整可运行代码 · 邮件发送追踪器（+ 预期输出）

> 这个脚本追踪你发出的每封邮件，自动算出"该追问"的邮件（发出超过 7 天还没回复的），帮你按计划跟进，不漏不乱。把它当作你学术社交的小助手。

```python
#!/usr/bin/env python3
# email_outreach_tracker.py —— 邮件发送追踪器
from datetime import date

emails = [
    # 收件人, 发送日(序号), 回复状态
    {"to": "孙显", "sent_day": 324, "status": "待回复"},
    {"to": "付琨", "sent_day": 325, "status": "待回复"},
    {"to": "王超", "sent_day": 326, "status": "已回复"},  # 已回复
]

TODAY = 333  # 当前是 D333（示例）
FOLLOW_UP_DAYS = 7

def track(emails, today):
    print(f"=== 邮件发送追踪（当前 D{today}）===\n")
    todo = []
    for e in emails:
        due = e["sent_day"] + FOLLOW_UP_DAYS
        line = f"· {e['to']}（D{e['sent_day']} 发出）—— {e['status']}"
        if e["status"] == "已回复":
            print(line + " ✅ 已回复，准备后续(汇报/材料)")
        elif today >= due:
            print(line + f" ⚠️ 已超 7 天（追问日 D{due}）→ 该礼貌追问了")
            todo.append(e["to"])
        else:
            print(line + f"（追问日 D{due}，还需等待）")
    print()
    if todo:
        print(f"📋 该追问：{todo}（礼貌追问一次，用追问模板，W49）")
    else:
        print("📋 暂无需追问的邮件，继续等待 + 推进第三课题")

if __name__ == "__main__":
    track(emails, TODAY)
```

**预期输出**：
```
=== 邮件发送追踪（当前 D333）===

· 孙显（D324 发出）—— 待回复 ⚠️ 已超 7 天（追问日 D331）→ 该礼貌追问了
· 付琨（D325 发出）—— 待回复 ⚠️ 已超 7 天（追问日 D332）→ 该礼貌追问了
· 王超（D326 发出）—— 已回复 ✅ 已回复，准备后续(汇报/材料)

📋 该追问：['孙显', '付琨']（礼貌追问一次，用追问模板，W49）
```
> 解读：把你三封邮件的发送日和状态填进 emails、当前日填进 TODAY，脚本自动算出哪些"超过 7 天没回复、该追问了"。它把"什么时候该追问谁"这件容易忘的事自动化——已回复的提示准备后续，到期没回的提示礼貌追问（W49 用追问模板）。
