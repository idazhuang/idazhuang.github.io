## 二、完整可运行代码 · 汇报日就绪检查器（+ 预期输出）

> 这个脚本把"汇报日就绪度"做成可勾选的检查器——输入 PPT/网络/备用/着装/Q&A/记录等各项准备状态，输出就绪度和"还差什么"，帮你在汇报前一项不漏地准备好。

```python
#!/usr/bin/env python3
# report_day_readiness.py —— 汇报日就绪检查器
checklist = {
    "PPT 定制": {
        "加最新实验结果": True, "加与老师研究的关联": True, "准备3个定制问题": True,
        "20min时长+逻辑顺": True,
    },
    "演练": {"完整演练1遍": True, "Q&A预案": True, "找朋友模拟+据反馈改进": True},
    "技术": {"★网络有线优先": True, "备用方案(手机热点)": True, "确认链接+设备正常": False},
    "形象与状态": {"整洁上衣": True, "早休息养状态": False},
    "汇报后准备(模板就绪)": {"致谢邮件D-5模板": True, "纪要500字模板": True},
}

def check(checklist):
    print("=== 汇报日就绪度 ===\n")
    total = done = 0
    todo = []
    for cat, items in checklist.items():
        c_done = sum(1 for v in items.values() if v)
        total += len(items); done += c_done
        bar = "✅" if c_done == len(items) else "⏳"
        print(f"{bar} {cat}: {c_done}/{len(items)}")
        for k, v in items.items():
            if not v:
                todo.append(f"{cat} · {k}")
                print(f"     □ 待办: {k}")
    pct = round(done / total * 100)
    print(f"\n汇报就绪度: {done}/{total} = {pct}%")
    if todo:
        print("还差：")
        for t in todo:
            print(f"  - {t}")
        print("\n→ 汇报前补齐(尤其技术与状态)。")
    else:
        print("\n🎉 汇报就绪，提前5分钟上线，自信开讲！")

if __name__ == "__main__":
    check(checklist)
```

**预期输出**：
```
=== 汇报日就绪度 ===

✅ PPT 定制: 4/4
✅ 演练: 3/3
⏳ 技术: 2/3
     □ 待办: 确认链接+设备正常
⏳ 形象与状态: 1/2
     □ 待办: 早休息养状态
✅ 汇报后准备(模板就绪): 2/2

汇报就绪度: 12/14 = 86%
还差：
  - 技术 · 确认链接+设备正常
  - 形象与状态 · 早休息养状态

→ 汇报前补齐(尤其技术与状态)。
```
> 解读：把汇报日的各项准备状态填进 checklist，脚本算出就绪度并列出"还差什么"。示例 86%——PPT/演练/汇报后模板就绪，还差确认链接设备、早休息。这把"汇报前还差什么"从凭记忆变成一目了然，确保你带着完整的准备、稳定的状态走进汇报。
