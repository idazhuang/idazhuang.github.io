# 接力说明 —— 如果换了新的会话窗口(没有之前记忆),把这份给新的 Claude

> **你担心的问题**:这个对话窗口可能装不下全部文件;一旦满了要开新窗口,新窗口没有记忆。**解决办法很简单**:所有成果都是**文件**(在最新 zip 里),不依赖聊天记录。换窗口时,你只要做下面三步,新会话就能无缝接着写。

## 一、换新窗口时,你要做的 3 步
1. **上传两样东西**给新会话:
   - 最新的成果 zip(例如 `遥感CV带教_…已加厚.zip`,里面有所有已完成的 .md + 本说明);
   - 你最初的原始计划:`遥感CV转型24个月-终极整合执行计划-v5_0.md`。
2. **把下面"给新会话的开场白"整段复制粘贴**给它(见第四节)。
3. 新会话读完这份说明 + 已完成文件后,就能**按同一标准继续写没写完的部分**。

## 二、这个项目在做什么(一句话)
把用户的《遥感CV转型24个月执行计划 v5.0》**逐日重写**成"边做边教"(教-学-做)的带教手册:**不改动原计划的日历任务与编号**,只把每天从"日程表"重写成"牵着学习者做"的脚本。中文 Markdown,**每周一个文件**,按阶段打包。

## 三、必须严格遵守的"M1-W1 标准"(质量不打折的定义)
每个周文件 = **A. 满深度正文 + B. 加厚补充包**,两部分都要有:

**A. 正文**:把这一周 7 天、每天的 **上午段 / 中午段 / 晚上段** 都各写成一个独立教学单元(用 `## 上午段 · …` 这样的小标题),**每个时段单元都要有完整六块**:
- ① 先垫概念(假设零基础,讲清这一步用到的概念,多用"和通用 CV 对比"来讲)
- ② 手把手带做(用当天真实任务,分步骤)
- ③ 合格样例(达标的产出长什么样,给具体例子)
- ④ 常踩的坑(2–3 个具体坑)
- ⑤ 卡住自救(决策树式)
- ⑥ 今天(这一步)你同时学会了什么(可复用技能 + 偶附"技能卡")
> 参照物:`M1-W1_教学做版.md`(**实测约 2.76 万字**,21 个时段单元,每段齐六块,3+ 技能卡,每天有预期开场,末尾加厚补充包)。**新写/重写的每一周都要对齐它的密度**,不能用"压缩每天 + 只在末尾加补充包"的偷工做法。
> **字数校准(达标区间)**:写作/分析类周 **~24–32K**、实验类周 **~33–44K**(M1-W1 本体 27.6K 属写作类上半区)。差异源于每段教学点多少与动手量,**不是缩水**。低于 24K 基本意味着六块没写透或缺补充包。
> **检测口径(每周输出前用脚本自检)**:① 21 个 `## (上午段|中午段|晚上段)`;② ①②③④⑤⑥ 每个符号出现 ≥21(即每段都齐六块);③ `技能卡｜` ≥4(M1-W1 是 3,从严取 4,本项目多写到 6–8);④ 含 `加厚补充包`;⑤ 每天一句"预期管理/预期"开场(共 7 天);⑥ 今日交付 ×7;⑦ 字数落在上面区间。**注意**:不要机械只数"预期管理"四字——M1-W1 用的是自然措辞("打个预防针""重要预期管理"等);本项目新写的周统一用显式"预期管理"开场,便于检测与一致。

**B. 加厚补充包**(放每周文件末尾,标题 `# 📎 W? 加厚补充包`):
- ① 合格范例(填好的笔记/报告/表格/决策书,让学习者照着写);
- ② 完整可直接运行的代码 + 预期输出(针对该周的核心编码任务);
- ③ 每日"今日自测"(D?–D? 每天 2–3 个自测问题);
- ④ 本周报错/坑 速查表(现象→根因→解法)。
