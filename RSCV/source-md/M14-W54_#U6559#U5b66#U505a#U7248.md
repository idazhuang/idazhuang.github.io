## 上午段 · 执行老师建议——把初步结果跑出来（向 Day 3 完成）

**① 先垫概念（为什么 Day 3 要出初步结果）**
- 上周（D370）你启动了执行老师最重要的建议。今天是汇报后约第 3 天——★ **把初步结果跑出来**：① 整理执行的实验/分析（按老师的建议做了什么）；② 看初步结果（哪怕不完整，能说明方向就行——如某指标的初步变化、某现象的观察）；③ 为中午发 Day 3 进展邮件准备素材。**Day 3 的初步结果不必完整、不必完美——关键是"我立即执行了、且开始有结果"，证明你的行动力。**
- **为什么"初步"就够**：执行力展示的核心是"快速响应"，不是"一步到位"。Day 3 给初步结果（证明启动 + 方向），Day 7 给完整结果（证明扎实），Day 14 给阶段报告（证明持续）——递进即可，别为追求完美而错过 Day 3 这个"趁热"的窗口。

**② 手把手带做**：① 整理执行老师建议的实验/分析（做了什么）；② 看初步结果（指标变化/现象观察，能说明方向）；③ 提炼"按建议尝试了 X，初步结果是 Y"；④ 形成你的初步理解（为什么这样、说明什么）；⑤ 为 Day 3 进展邮件准备素材（结果 + 思考 + 下一步）。
**③ 这一步合格的样子**：老师建议的初步结果跑出来——整理了执行内容、有初步结果（能说明方向）、提炼了你的理解，Day 3 邮件素材就绪。
**④ 最常踩的坑**
- 追求完整结果错过 Day 3 窗口 → 初步结果即可（趁热发）。
- 只跑实验不提炼"说明什么" → 形成你的初步理解（思考）。
- 执行偏离老师建议 → 紧扣老师最重要的建议。

**⑤ 卡住怎么自救（决策树）**：3 天出不了结果？→ 出初步的、能说明方向的（不必完整）；结果不明显？→ 如实说初步观察 + 下一步计划（执行力不取决于结果多好，取决于你做了、在推进）。
**⑥ 今天（这一步）你同时学会了什么**：你**把老师建议的初步结果跑出来了**。**做了**（整理执行内容 + 看初步结果 + 提炼理解 + 准备邮件素材）、**学了**（Day 3 出初步结果即可、快速响应重于一步到位、提炼"说明什么"）、**会了**（在 3 天内把老师建议执行出可汇报的初步结果）。

## 中午段 · ★ 发 Day 3 进展邮件

**① 先垫概念（Day 3 进展邮件怎么写）**
- ★ **发 Day 3 进展邮件**，是执行力展示的第一炮。结构（复用补充包范例 1 的模板）：① **感谢上次汇报的建议**；② **"按您的建议，我尝试了 X"**（明确呼应老师的建议）；③ **初步结果**（简洁列出，1-2 条）；④ ★ **你的思考**（"我的初步理解是…""我怀疑是因为…"——展示独立判断，不只是执行的工具人）；⑤ **下一步计划**（"下一步我想试…"）。**简洁 + 有干货 + 体现思考 + 及时**——让老师看到你立即执行、有结果、还有想法。
- ★ **为什么体现"你的思考"很关键**：如果邮件只说"我跑了实验、结果是这样"，老师看到的是一个执行者；而加上"我的理解是…我下一步想试…"，老师看到的是一个有独立判断、能和他对话的研究者——后者才让他更愿意深入交流、长期投入。

**② 手把手带做**：① 用进展邮件模板（范例 1）；② 写"感谢建议 + 按您建议尝试了 X + 初步结果"；③ ★ 加你的思考（初步理解/判断）；④ 写下一步计划；⑤ 简洁专业、当天发出。
**③ 这一步合格的样子**：Day 3 进展邮件发出——呼应老师建议 + 初步结果 + ★ 你的思考 + 下一步，简洁有干货，及时（汇报后约 3 天）。
**④ 坑**：① 进展邮件冗长无干货 → 简洁 + 结果 + 思考 + 下一步；② 只报结果不体现思考（像工具人）→ ★ 加你的初步理解/判断；③ 拖过 Day 3（印象凉）→ 趁热当天发。
**⑤ 自救**：结果不亮眼怎么发？→ 如实 + 你的思考 + 下一步（执行力展示重在"做了、在推进、有想法"）；不知怎么加思考？→ "我的初步理解是…""我怀疑…所以下一步想试…"。
**⑥ 今天（这一步）你同时学会了什么**：你**发出了 Day 3 进展邮件**。**做了**（用模板 + 呼应建议 + 列初步结果 + 加思考 + 写下一步 + 当天发）、**学了**（进展邮件简洁有干货、★ 体现思考变工具人为对话者、及时趁热）、**会了**（写出让老师看到执行力和判断力的进展邮件）。

> **技能卡｜Day 3 进展邮件（用进展换指导·体现思考）**：汇报后约 3 天发第一封进展邮件——①感谢上次汇报的建议②"按您的建议,我尝试了 X"（明确呼应）③初步结果（简洁 1-2 条）④★ 你的思考（"我的初步理解是…""我怀疑因为…"——展示独立判断,变工具人为能对话的研究者）⑤下一步计划。★ 简洁 + 有干货 + 体现思考 + 及时（趁老师印象热乎）。核心:让老师看到你"立即执行、有结果、还有想法"——这正是他决定长期投入时最看重的。

## 晚上段 · 第三课题消融实验结果收集

**① 先垫概念（为什么收集消融结果）**
- 上周（D370）启动的消融实验现在应有部分结果——晚上**收集消融结果**：① 汇总各消融配置的结果（去掉/替换每个部分后的指标）；② 整理成对比表（完整方法 vs 去掉各部分）；③ 看初步趋势（哪些部分去掉后下降明显=贡献大）。**消融结果是论文验证方法有效性的关键证据**——今晚先收集汇总，明后天做分析。
- **为什么和执行力展示并行**：连接（执行力展示）和研究（消融）两条线并进——执行力展示赢得机会，消融实验夯实你的论文产出（你完全掌控的硬资产）。

**② 手把手带做**：① 收集消融实验各配置的结果（去掉/替换每部分的指标）；② 整理成对比表（完整 vs 各消融）；③ 看初步趋势（哪些部分贡献大）；④ 检查实验是否还有缺的配置（明后天补）；⑤ 实验管理记录。
**③ 这一步合格的样子**：消融结果收集汇总——各配置结果整理成对比表、看了初步趋势，缺的配置标出。
**④ 坑**：① 结果不整理（乱）→ 整理成对比表；② 不看趋势（白跑）→ 看各部分贡献的初步趋势；③ 漏配置不补 → 标出缺的、后续补。
**⑤ 自救**：结果乱？→ 对比表（行=完整/去掉各部分，列=指标）；趋势看什么？→ 去掉某部分后下降越多=该部分贡献越大。
**⑥ 今天（这一步）你同时学会了什么**：你**收集汇总了消融结果**。**做了**（收集各配置结果 + 整理对比表 + 看趋势 + 标缺的 + 实验管理）、**学了**（消融结果整理成对比表、看各部分贡献趋势、连接与研究并进）、**会了**（系统收集汇总消融实验结果）。

## 上午段 · 研究计划书——背景（研究背景 + 已有成果 + 为什么访问这团队）

**① 先垫概念（研究计划书的背景怎么写）**
- ★ **写一份暑期访问研究计划书（≥4 页 PDF）**——这是争取访问/实习的关键材料。今天先写**背景**：① **你的研究背景**（你做什么方向、走到了哪——简述你的研究主线）；② **已有成果**（三篇论文、开源等——你的硬资产，证明研究能力）；③ ★ **为什么访问这个团队**（和他们方向的契合：你的工作 × 他们的研究有什么结合点、为什么这个团队是你深化研究的理想之地）。**背景要让老师看到：你不是泛泛地"想来学习"，而是"基于扎实的研究基础、奔着具体的方向契合而来"。**
- **复用你的素材**：你的 Proposal、成果素材、对目标老师研究的了解（M11/W49 分析）——背景部分大量复用这些，把"我是谁、做了什么、为什么是你们"说清楚。

**② 手把手带做**：① 写研究背景（你的研究方向和主线）；② 写已有成果（三篇论文/开源，简洁有力）；③ ★ 写为什么访问这团队（方向契合 + 结合点，基于 W49 分析）；④ 体现"基于扎实基础 + 具体契合"（非空泛想学习）；⑤ 复用 Proposal/成果素材。
**③ 这一步合格的样子**：研究计划书背景写好——研究背景 + 已有成果 + 为什么访问这团队（方向契合），体现扎实基础和具体契合。
**④ 最常踩的坑**
- 背景空泛"想来学习"（没价值）→ 基于扎实基础 + 具体方向契合。
- 不说为什么是"这个"团队（通用）→ ★ 点出和他们方向的契合点。
- 成果罗列无重点 → 简洁有力（突出最相关的）。

**⑤ 卡住怎么自救（决策树）**：背景写什么？→ 研究背景 + 已有成果 + 为什么这团队；契合点怎么找？→ 你的方法/方向 × 他们的研究（W49 交叉点分析）。
**⑥ 今天（这一步）你同时学会了什么**：你**写好了研究计划书的背景**。**做了**（写研究背景 + 已有成果 + 为什么访问这团队 + 体现契合 + 复用素材）、**学了**（背景展示扎实基础 + 具体契合、非空泛想学习、点出团队契合点）、**会了**（写出有说服力的访问申请背景）。

## 二、完整可运行代码 · 汇报后执行力时间线追踪器（+ 预期输出）

> 这个脚本追踪汇报后执行力展示的时间线（Day 0/3/7/14），自动算出每个节点是否到期、该做什么——帮你把"执行力展示"系统地执行到位，不漏节点、按递进节奏持续发进展。

```python
#!/usr/bin/env python3
# followup_timeline_tracker.py —— 汇报后执行力时间线追踪器
TIMELINE = [
    (0,  "致谢邮件(D-5) + 汇报纪要(500字)"),
    (3,  "执行老师最重要建议→发进展邮件(初步结果+思考)"),
    (7,  "发更完整的结果 + 分析 + 下一步"),
    (14, "发阶段性报告(全面进展+引向合作)"),
]

DAYS_SINCE_REPORT = 8          # 汇报后第几天（示例：第 8 天）
done = {0: True, 3: True, 7: True, 14: False}   # 各节点完成情况

def track(timeline, days, done):
    print(f"=== 汇报后执行力时间线（汇报后第 {days} 天）===\n")
    for day, action in timeline:
        if done.get(day):
            status = "✅ 已完成"
        elif days >= day:
            status = "⚠️ 已到期 → 该做了！"
        else:
            status = f"⏳ 还有 {day - days} 天"
        print(f"Day {day:>2}: {action}\n        {status}\n")
    pending = [(d, a) for d, a in timeline if not done.get(d) and days >= d]
    if pending:
        print(f"📋 当前该做：Day {pending[0][0]} —— {pending[0][1]}")
    else:
        upcoming = [(d, a) for d, a in timeline if not done.get(d)]
        if upcoming:
            print(f"📋 下一节点：Day {upcoming[0][0]}（还有 {upcoming[0][0]-days} 天）")
        else:
            print("🎉 执行力展示时间线全部完成！连接已从汇报深化为持续关系。")

if __name__ == "__main__":
    track(TIMELINE, DAYS_SINCE_REPORT, done)
```

**预期输出**：
```
=== 汇报后执行力时间线（汇报后第 8 天）===

Day  0: 致谢邮件(D-5) + 汇报纪要(500字)
        ✅ 已完成

Day  3: 执行老师最重要建议→发进展邮件(初步结果+思考)
        ✅ 已完成

Day  7: 发更完整的结果 + 分析 + 下一步
        ✅ 已完成

Day 14: 发阶段性报告(全面进展+引向合作)
        ⏳ 还有 6 天

📋 下一节点：Day 14（还有 6 天）
```
> 解读：把汇报后的天数和各节点完成情况填进去，脚本告诉你当前该做什么、下一节点还有几天。它把"执行力展示"这件需要持续跟进的事自动化——确保你按 Day 3/7/14 的递进节奏持续发进展，不漏节点、不断续，把一次汇报系统地经营成持续的指导关系。
