| 事实 | 数值 | 为什么重要 |
|---|---|---|
| 图像数 | **2806** 张 | 不多，但每张巨大 |
| 图像尺寸 | 约 **4000×4000** | **所以必须切图**（W2-D9 你会做） |
| 实例数 | **188,282** | 平均每张 67 个目标，很密集 |

| 标注 | **四点旋转框** + difficult 标志 | 你 D6 要写代码解析它 |
| 划分 | train / val / **test** | **★ test 标注不公开**，评测要提交官方服务器 |

**最后一条是全书没提、但会让你 W2 白忙半天的坑**，详见 [W2 实操 §6.1](w2-baseline.html)。

### ★ 标注格式逐字段讲透（原文说"重点看标注格式"但没展开）

一个 `.txt` 标注文件长这样：

```text
imagesource:GoogleEarth
gsd:0.146343590398
2753.0 2408.0 2861.0 2385.0 2888.0 2468.0 2805.0 2493.0 plane 0
1234.0 567.0 1300.0 580.0 1290.0 640.0 1224.0 627.0 small-vehicle 1
```

| 部分 | 含义 |
|---|---|
| 第 1 行 `imagesource` | 影像来源（GoogleEarth / GF-2 / JL-1），**元信息，解析时跳过** |
| 第 2 行 `gsd` | 地面采样距离，单位米/像素。**有些图这行是 `null`，代码要处理** |
| 第 3 行起，前 8 个数 | **四个角点** `x1 y1 x2 y2 x3 y3 x4 y4`，**按顺时针或逆时针顺序** |
| 第 9 个字段 | 类别名（15 类之一） |
| 第 10 个字段 | **difficult**：`1` = 难样本，官方评测时通常忽略 |

> **★ 为什么用四点而不是 (x, y, w, h, θ)**：四点表示**没有角度周期性问题**（见 [《名词逐个讲透》§5.2](../start/rs-basics-deep.html)），也不用纠结"哪条边算宽"。代价是需要转换成模型要的格式——**这个转换你 D6 就会写。**

# D6 · 写你人生第一个遥感 CV 脚本

> **原文只说"从零写 `vis_dota.py`（读标注 → 解析旋转框 → 画框 → 存图）"，一行代码都没给。** 这一节给完整可运行版本 —— **下面的代码我实测跑过**。

## ① 先垫概念

### 这个脚本为什么值得写

你可以直接下载别人的可视化工具。**但亲手写一遍的价值在于**：

1. **你会真正搞懂标注格式** —— 这是后面所有数据处理的基础。
2. **W2 切完图之后，你要用它抽查框有没有错位** —— 这是唯一能发现"切图坏了"的手段。
3. **W2-D13 你要把它升级成 `vis_results.py`**（画预测框 vs GT 框），那是在这个基础上加东西。

### 三个必须先懂的概念

**① OpenCV 的坐标系**：`img[y, x]`，**先行后列**。而标注文件里是 `x y` 顺序。**这个错位是新手画框错位的头号原因。**

**② 多边形绘制**：旋转框是四个点，用 `cv2.polylines` 画闭合多边形，不是 `cv2.rectangle`。

**③ 四点 ↔ (cx, cy, w, h, θ)**：`cv2.minAreaRect` 能把四点转成中心+宽高+角度。**W2 用到的模型吃的是后一种格式**，所以这个转换要会。

### 第 2 步：完整代码

新建 `20-代码实验/vis_dota.py`：

```python
"""vis_dota.py —— 读 DOTA 标注，画旋转框，存图。

用法：
    python vis_dota.py --img P0001.png --label P0001.txt --out vis.jpg
"""
import argparse
import cv2
import numpy as np

# DOTA-v1.0 的 15 个类别（顺序就是官方顺序，W2 的 config 里也是这个顺序）
CLASSES = ['plane', 'baseball-diamond', 'bridge', 'ground-track-field',
           'small-vehicle', 'large-vehicle', 'ship', 'tennis-court',
           'basketball-court', 'storage-tank', 'soccer-ball-field',
           'roundabout', 'harbor', 'swimming-pool', 'helicopter']

# 给每个类别固定一个颜色（固定随机种子 → 每次运行颜色一致，方便对比）
np.random.seed(42)
COLORS = {c: tuple(int(v) for v in np.random.randint(60, 255, 3)) for c in CLASSES}


def parse_dota_label(txt_path):
    """解析 DOTA 标注文件，返回目标列表。

    每个目标是一个 dict：
        points   : (4, 2) 的 float32 数组，四个角点
        cls      : 类别名字符串
        difficult: 0 或 1
    """
    objs = []
    with open(txt_path, encoding='utf-8') as f:
        for line in f:
            line = line.strip()
            # 跳过空行和前两行元信息
            if not line or line.startswith(('imagesource', 'gsd')):
                continue
            parts = line.split()
            if len(parts) < 9:          # 有些文件末尾有残缺行，跳过
                continue
            pts = np.array([float(x) for x in parts[:8]],
                           dtype=np.float32).reshape(4, 2)
            objs.append(dict(
                points=pts,
                cls=parts[8],
                difficult=int(parts[9]) if len(parts) > 9 else 0,
            ))
    return objs


def draw(img, objs, thickness=2, show_difficult=True):
    """在图上画出所有旋转框 + 类别名。"""
    for o in objs:
        if o['difficult'] and not show_difficult:
            continue
        color = COLORS.get(o['cls'], (0, 255, 0))   # 未知类别用绿色兜底
        pts = o['points'].astype(np.int32).reshape(-1, 1, 2)
        cv2.polylines(img, [pts], isClosed=True, color=color, thickness=thickness)
        # 类别名画在第一个角点旁边
        x, y = o['points'][0].astype(int)
        cv2.putText(img, o['cls'], (x, max(y - 5, 12)),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, color, 1, cv2.LINE_AA)
    return img


def poly_to_xywha(pts):
    """四点 → (cx, cy, w, h, angle)。W2 的模型吃的就是这种格式。"""
    (cx, cy), (w, h), angle = cv2.minAreaRect(pts.astype(np.float32))
    return cx, cy, w, h, angle


if __name__ == '__main__':
    ap = argparse.ArgumentParser()
    ap.add_argument('--img', required=True, help='图像路径')
    ap.add_argument('--label', required=True, help='标注 txt 路径')
    ap.add_argument('--out', default='vis.jpg', help='输出图路径')
    ap.add_argument('--no-difficult', action='store_true', help='不画 difficult 目标')
    args = ap.parse_args()

    img = cv2.imread(args.img)
    if img is None:
        raise FileNotFoundError(f'读不到图：{args.img}')

    objs = parse_dota_label(args.label)
    print(f'读到 {len(objs)} 个目标')

    # 顺手统计每类多少个 —— 这个统计 D5 建数据集表时用得上
    from collections import Counter
    for cls, n in Counter(o['cls'] for o in objs).most_common():
        print(f'  {cls:<20} {n}')

    img = draw(img, objs, show_difficult=not args.no_difficult)
    cv2.imwrite(args.out, img)
    print(f'已保存到 {args.out}')
```

## ④ 常踩的坑

| 坑 | 症状 | 解 |
|---|---|---|
| `x y` 读成 `y x` | 框整体错位/转置 | 标注是 `x y` 顺序，OpenCV 索引是 `[y, x]`，别混 |
| 用 `cv2.rectangle` | 框全是水平的 | 旋转框必须用 `polylines` |
| 忘了跳过前两行 | 报 `ValueError: could not convert string to float` | `startswith(('imagesource','gsd'))` |
| `gsd:null` 的图 | 同上 | 上面的写法已经跳过整行，不受影响 |
| 中文路径 | `cv2.imread` 返回 `None` | **路径不要有中文**（D1 前置讲过） |
| 图太大看不清 | 4000×4000 打开很卡 | 加一句 `img = cv2.resize(img, None, fx=0.25, fy=0.25)` 再存 |

# D7 · 韦玉春第 3 章 + 第一次周复盘

## 上午段 · 韦玉春第 3 章（图像校正）

**这一章讲什么**：几何校正（把因地形和视角造成的位置偏移拉正）和辐射校正（去掉大气与传感器的影响）。

**只读这几节，其余跳过**：几何校正的原理与控制点、重采样方法（最近邻/双线性/三次卷积）、辐射定标的概念。

**★ 带着这个问题读**：**为什么 CV 里没有这两步，遥感里必须有？**

答案（读完自己应该能说出来）：**因为遥感要的是"可跨时间、跨传感器比较的物理量"，不是"好看的图"。** 一张没做辐射校正的影像，今天和明天拍的同一块地，数值可以差很多——那就没法做变化检测。

**配合看**：MOOC 里"几何校正/辐射校正"两讲，先看视频再读书，效率高一倍。
