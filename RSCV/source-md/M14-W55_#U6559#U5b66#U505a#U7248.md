## 上午段 · ★ 与博士导师沟通暑期访问（说辞委婉，尽量不让导师反感）

**① 先垫概念（为什么、怎么和博士导师沟通）**
- 你要暑期去目标团队访问 2–3 个月，需要**提前和博士导师沟通**（导师同意函是访问申请材料之一，且访问要占用暑假时间）。★ **难点在于：你的博士导师不支持你转型**——所以沟通要讲策略：① **委婉**（不说"我要转去做遥感 CV"，而说"我想利用暑假做一次学术交流访问"）；② **强调对博士课题的好处**（"这次交流对我的博士课题也有帮助，能学到 X 方法/接触 Y 资源"）；③ **给导师台阶**（"只是利用暑假时间，不影响正常的课题进度"）；④ **尽量不让导师反感**（低调、尊重、不挑战他）。**目标是争取到导师的同意（同意函），同时把摩擦降到最低。**
- **为什么这样处理**：导师不支持是你的现实约束，硬刚只会两败俱伤。聪明的做法是用"对博士课题有帮助""利用暑假"等说辞，把访问包装成"对双方都好、不冲突"的事，减少导师的抵触。这里的分寸感很重要:你不需要、也不应该向导师和盘托出"我想转型去那个团队"——那只会引发对抗。你需要的只是一个"同意你暑假去交流"的结果,而达成这个结果,用一个他能接受的理由（学术交流、利用假期）就够了。成年人的博弈,有时候不是比谁更坦诚,而是比谁更懂得用对方能接受的方式达成目标。

**② 手把手带做**：① 提前 2 周找导师沟通（面谈或邮件）；② 用委婉说辞（"想利用暑假做一次学术交流访问 2-3 个月"，不强调转型）；③ 强调对博士课题的好处（学到 X 方法/接触 Y 资源/拓展视野）；④ 给导师台阶（"不影响正常课题进度"）；⑤ 争取导师同意 + 同意函；⑥ 低调尊重、不挑战，把摩擦降到最低。
**③ 这一步合格的样子**：和博士导师沟通了暑期访问——用了委婉说辞、强调对博士课题的好处、争取到了同意（或至少不强烈反对），摩擦降到最低。
**④ 最常踩的坑**
- 直说"我要转去做遥感 CV"（激化矛盾）→ ★ 委婉（"利用暑假做学术交流访问"）。
- 不强调对博士课题的好处 → 强调（让导师觉得对他的课题也有利）。
- 挑战/对抗导师 → 低调尊重、给台阶（减少抵触）。

**⑤ 卡住怎么自救（决策树）**：导师反对怎么办？→ 强调对博士课题好处 + 利用暑假不影响进度 + 给台阶；导师还是不同意同意函？→ 看是否有其他证明方式（如学院盖章）、或暂缓争取（持续沟通、用成果说话）。
**⑥ 今天（这一步）你同时学会了什么**：你**策略性地和导师沟通了访问**。**做了**（提前 2 周沟通 + 委婉说辞 + 强调对博士课题好处 + 给台阶 + 争取同意 + 降摩擦）、**学了**（导师不支持要讲策略:委婉/强调好处/给台阶/不挑战、把访问包装成不冲突）、**会了**（在导师不支持的约束下策略性地争取访问）。

> **技能卡｜与导师沟通访问（委婉·降摩擦）**：博士导师不支持转型时,争取暑期访问要讲策略——①委婉（说"利用暑假做学术交流访问 2-3 个月",不强调"转型"）②强调对博士课题的好处（"能学到 X 方法/接触 Y 资源,对我课题也有帮助"）③给导师台阶（"不影响正常课题进度"）④低调尊重、不挑战他。目标=争取同意（同意函）+ 把摩擦降到最低。硬刚两败俱伤,聪明的做法是把访问包装成"对双方都好、不冲突"的事。

## 中午段 · 完善研究计划书（基于汇报中老师的反馈调整方向）

**① 先垫概念（为什么基于汇报反馈完善计划书）**
- 你 W53-54 写了研究计划书草稿。现在 ★ **基于汇报中老师的反馈调整方向**——如果老师汇报时说"你可以做 X""这个方向可以考虑 Y"，就**在计划书里加入 X/Y**。**这让计划书的"拟在访问期间完成的工作"和老师的建议/兴趣对齐**——老师看到自己的建议被采纳，会觉得：① 你听进去了（重视他的意见）；② 你来了能做他关心的方向（合作价值高）；③ 你们的方向契合（值得接收）。**计划书融入老师建议，大大提高被接受的概率。**
- **怎么做**：回顾汇报纪要（老师的建议）→ 把最相关、最有价值的建议融入计划书的"拟完成工作"部分（具体、可行）。

**② 手把手带做**：① 回顾汇报纪要（老师的建议/兴趣/方向）；② 把老师建议的方向融入计划书的"拟在访问期间完成的工作"（"基于您建议的 X 方向，访问期间我计划…"）；③ 确保融入自然、具体、可行；④ 调整计划书让方向和老师对齐；⑤ 完善计划书其他部分（背景/时间安排/预期成果）。
**③ 这一步合格的样子**：研究计划书基于汇报反馈完善——融入了老师的建议方向、和老师对齐、具体可行，被接受概率提高。
**④ 坑**：① 不融入老师建议（计划书和老师脱节）→ ★ 融入（显你听进去了+方向契合）；② 生硬塞入（不自然）→ 自然融入"拟完成工作"；③ 融入的方向不可行 → 具体可行（单卡能做、有价值）。
**⑤ 自救**：老师给了多个建议？→ 选最相关、最有价值的融入；不知怎么融入？→ "基于您建议的 X，访问期间我计划做…"。
**⑥ 今天（这一步）你同时学会了什么**：你**让研究计划书和老师的建议对齐了**。**做了**（回顾纪要 + 融入老师建议方向 + 自然具体可行 + 完善其他部分）、**学了**（融入老师建议显你听进去+方向契合+提高接受概率、自然融入）、**会了**（基于反馈让研究计划书更对接目标老师）。

> **技能卡｜研究计划书完善（融入汇报反馈）**：访问申请的研究计划书要★基于汇报中老师的反馈调整——老师说"可以做 X"→计划书"拟完成工作"里加入 X("基于您建议的 X 方向,访问期间我计划…")。好处:老师看到建议被采纳,觉得你听进去了+来了能做他关心的方向+方向契合,大大提高被接受概率。回顾汇报纪要→把最相关有价值的建议自然融入(具体可行)。这是把汇报的"交流"延续成访问申请的"对接"。

## 二、完整可运行代码 · 访问申请就绪检查器（+ 预期输出）

> 这个脚本把"访问申请就绪度"做成可勾选的检查器——输入研究计划书、各项材料、导师沟通、申请邮件的准备状态，输出就绪度和"还差什么"，确保你 09:30 发出申请前材料齐全、不留遗漏。

```python
#!/usr/bin/env python3
# visit_application_readiness.py —— 访问申请就绪检查器
checklist = {
    "研究计划书": {
        "≥4页PDF": True, "4部分齐全(背景/工作/时间/成果)": True,
        "融入汇报反馈": True, "针对目标团队(契合)": True, "无错别字+排版专业": False,
    },
    "申请材料": {
        "简历(最新)": True, "论文PDF": True, "导师同意函(或办理中说明)": False,
        "在读证明": True, "身份证复印件": True, "文件名规范": True,
    },
    "导师沟通": {"已委婉沟通访问": True, "争取同意/降摩擦": True},
    "申请邮件": {"D-7模板就绪": True, "收件人列表(所有沟通过的)": True, "附件齐全": False},
}

def check(checklist):
    print("=== 访问申请就绪度 ===\n")
    total = done = 0
    todo = []
    for cat, items in checklist.items():
        c_done = sum(1 for v in items.values() if v)
        total += len(items); done += c_done
        bar = "✅" if c_done == len(items) else "⏳"
        print(f"{bar} {cat}: {c_done}/{len(items)}")
        for k, v in items.items():
            if not v:
                todo.append(f"{cat} · {k}")
                print(f"     □ 待办: {k}")
    pct = round(done / total * 100)
    print(f"\n访问申请就绪度: {done}/{total} = {pct}%")
    if todo:
        print("还差：")
        for t in todo:
            print(f"  - {t}")
        print("\n→ 发送前补齐(尤其同意函/附件)。")
    else:
        print("\n🎉 申请就绪，09:30 趁热打铁发给所有沟通过的人！")

if __name__ == "__main__":
    check(checklist)
```
