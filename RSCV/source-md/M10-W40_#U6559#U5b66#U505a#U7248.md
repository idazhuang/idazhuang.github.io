## 中午段 · 做"批注式笔记"：每篇 ≥3 个"尖锐但有建设性的问题"

**① 先垫概念（什么是"尖锐但有建设性的问题"）**
- **★ 这是本周最重要的方法点**。"尖锐但有建设性的问题"≠ 挑刺攻击（"你这篇论文有什么问题？"——攻击性、显得无知或冒犯）。它是**展示你读得深、想得深的好问题**，形式像："您在 X 部分用了 Y 方法，我理解它的优势是 Z，但我好奇在 W 场景下是否需要调整？"
- **这种问题的三个要素**：① **先准确复述他的做法**（X 用了 Y，证明你读懂了）；② **理解其优势**（我理解优势是 Z，证明你想过为什么）；③ **提出一个有深度的延伸/边界问题**（但在 W 场景下是否……，证明你能想到他没说的）。**它让对方感到"这人真读懂了我的工作、还想得很深"**——这种问题在邮件/会议中提出，会让老师印象深刻。

## 二、完整可运行代码 · 进度量化仪表盘（M1 vs M10 对比，+ 预期输出）

> 这个脚本把"M1 起点"和"M10 现在"的关键指标放一起，自动算增长、输出 markdown 对比表、并高亮跃迁最大的维度。写进度报告/月复盘时跑一下，量化一目了然。

```python
#!/usr/bin/env python3
# progress_dashboard.py —— 转型进度量化仪表盘（M1 起点 vs M10 现在）
metrics = {
    # 维度: (M1起点, M10现在, 单位)
    "已投稿论文":   (0, 2,  "篇"),
    "arXiv 预印本": (0, 2,  "篇"),
    "GitHub star":  (0, 70, "★"),   # 填你的真实数
    "累计读论文":   (0, 120,"篇"),   # 填你的真实数
    "自建实验框架": (0, 1,  "套"),
    "完整论文流程": (0, 2,  "次"),   # 找Gap→实验→写作→投稿→审稿
    "竞赛参与":     (0, 1,  "次"),
}

def grow(a, b):
    if a == 0:
        return "从无到有" if b > 0 else "—"
    return f"+{b-a}（×{b/a:.1f}）"

def to_markdown(m):
    head = "| 维度 | M1 起点 | M10 现在 | 增长 |\n|---|---|---|---|\n"
    rows = "".join(
        f"| {k} | {v[0]}{v[2]} | {v[1]}{v[2]} | {grow(v[0], v[1])} |\n"
        for k, v in m.items())
    return head + rows

def biggest_jumps(m):
    # 从无到有的维度（最能体现质变）
    return [k for k, v in m.items() if v[0] == 0 and v[1] > 0]

if __name__ == "__main__":
    print("=== 转型进度仪表盘：M1 起点 → M10 现在 ===\n")
    print(to_markdown(metrics))
    jumps = biggest_jumps(metrics)
    print(f"\n★ 从无到有的跃迁（{len(jumps)} 项）：{', '.join(jumps)}")
    done = metrics["完整论文流程"][1]
    print(f"最大质变：从「读不懂论文」到「独立走完 {done} 次完整论文流程」")
```
