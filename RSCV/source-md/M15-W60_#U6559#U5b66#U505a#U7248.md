## 上午段 · 确认住宿（最终敲定 + 签约 + 入住时间）

**① 先垫概念（怎么最终敲定住宿）**
- W59 你筛了几个候选（通勤近/价格合理/短租灵活/配套齐）。今天**最终敲定**——① 从候选里选一个（综合通勤、价格、房况、房东靠谱度）；② **确认关键信息**（租期能否匹配访问时间、押金和租金、是否拎包入住、退租灵活度）；③ **签约/付定金**（短租平台或合租，按流程；★ 注意合同条款，别被坑押金）；④ **确认入住时间**（和报到时间对得上，提前 1–2 天能入住安顿）。
- **为什么今天定**：住宿是出发的硬前提，定下来你才能安心买定行程、收拾行李；拖到最后容易没合适的房或仓促签约被坑。

**② 手把手带做**：① 从 W59 候选里综合选定一个；② 确认关键信息（租期/押金租金/拎包入住/退租）；③ 签约/付定金（看清合同条款）；④ 确认入住时间（对得上报到、提前到能安顿）；⑤ 记录住宿信息（地址/房东联系方式/入住退租时间）。
**③ 这一步合格的样子**：住宿最终敲定——选定房源、确认关键信息、签约/付定金、入住时间和报到对得上，信息记录清楚。
**④ 最常踩的坑**
- 拖到最后才定（没合适房/仓促签约）→ 本周一最终敲定。
- 不看合同被坑押金 → 看清条款（押金/退租/违约）。

**⑤ 卡住怎么自救（决策树）**：候选难取舍？→ 通勤近优先 + 价格房况靠谱度综合；担心被坑？→ 选靠谱平台/合同写清押金退租；入住对不上？→ 和房东协商提前入住或调整。
**⑥ 今天（这一步）你同时学会了什么**：你**最终敲定了访问期间的住宿**。**做了**（综合选定 + 确认信息 + 签约付定金 + 对齐入住时间 + 记录）、**学了**（最终敲定看通勤/价格/条款/入住对齐、看清合同防坑）、**会了**（为短期访问最终敲定并签约住宿）。

## 中午段 · ★ 与接待师兄确认报到时间地点

**① 先垫概念（报到细节要问清哪些）**
- ★ 报到是你进团队的第一步，**细节一定要提前和接待师兄确认清楚**，别到了抓瞎：① **报到时间**（具体哪天几点到、第一天几点去）；② **报到地点**（去哪栋楼哪个房间、门禁怎么进）；③ **找谁**（接待师兄/师姐的联系方式，到了找谁对接）；④ **带什么**（证件/材料/是否需要提前办手续）；⑤ **实验室作息**（几点开门关门、组会时间、服务器使用规则——W61 报到日会细了解，先有个底）。
- **为什么提前确认**：报到第一天给人的印象很重要——准时、有准备、不手忙脚乱，靠的就是提前把细节问清楚。和师兄确认的过程，本身也是一次自然的沟通、建立联系。

**② 手把手带做**：① 联系接待师兄（礼貌、具体）；② 确认报到时间（哪天几点）+ 地点（楼/房间/门禁）；③ 确认到了找谁（联系方式）；④ 确认带什么（证件/材料/手续）；⑤ 问实验室作息（开关门/组会/服务器，先有个底）+ 记录报到安排。
**③ 这一步合格的样子**：报到细节确认清楚——时间/地点/找谁/带什么/作息都问到了，报到安排记录下来，第一天能准时有准备地报到。
**④ 坑**：① 不提前确认（报到日抓瞎）→ 提前问清细节；② 问得太笼统（到了还是不清楚）→ 具体到时间/地点/联系人；③ 不记录（临时忘）→ 记下报到安排。
**⑤ 自救**：怕打扰师兄？→ 报到细节是正当且必要的沟通,礼貌问即可;师兄没回？→ 隔一两天再问/问其他联系人;不知问啥？→ 按"时间/地点/找谁/带什么/作息"五项。
**⑥ 今天（这一步）你同时学会了什么**：你**确认了报到的全部细节**。**做了**（联系师兄 + 确认时间地点找谁带什么作息 + 记录）、**学了**（报到细节要提前问清五项、确认过程也是建立联系）、**会了**（提前确认报到细节,第一天准时有准备）。

## 晚上段 · 自我介绍 30 秒版（电梯演讲）

**① 先垫概念（30 秒版怎么写）**
- 进团队你会在不同场景做自我介绍——今晚先写**最精简的 30 秒版（电梯演讲）**：电梯里、走廊上、午饭时偶遇同学，30 秒内说清"我是谁"。结构：① **我是谁**（来自哪、博士在读、做什么方向——一句话）；② **亮点**（最有分量的：如"做遥感 CV，有三篇论文/两篇在审"——一句话）；③ **来做什么**（来访问交流、想和大家学习合作——一句话）。★ **精简有力**——30 秒不是讲全部，是给人一个清晰的"标签"，让人记住你是谁、做什么。
- **为什么从 30 秒版开始**：先把最核心的"我是谁"提炼到极致，2 分钟、5 分钟版都是在这个核心上展开。

**② 手把手带做**：① 写 30 秒版（我是谁 + 亮点 + 来做什么，各一句）；② 提炼最有分量的亮点（三篇论文/方向）；③ 控制在 30 秒（约 60–80 字，张口就来）；④ 口语化（不是书面语，是自然说话）；⑤ 念一遍计时（确保 30 秒内）。
**③ 这一步合格的样子**：自我介绍 30 秒版写好——我是谁 + 亮点 + 来做什么，精简有力、口语化、30 秒内说完。
**④ 坑**：① 30 秒版太长（啰嗦记不住）→ 各一句、控时；② 不提亮点（没记忆点）→ 点最有分量的；③ 书面语生硬（不自然）→ 口语化、像说话。
**⑤ 自救**：不知说啥？→ 我是谁 + 亮点 + 来做什么三句;亮点是啥？→ 三篇论文/遥感 CV 方向;太长？→ 删修饰,只留核心。
**⑥ 今天（这一步）你同时学会了什么**：你**写好了自我介绍 30 秒版**。**做了**（写三句 + 提炼亮点 + 控时 + 口语化 + 计时念）、**学了**（30 秒版给人清晰标签、精简有力、从核心展开）、**会了**（提炼出张口就来的电梯演讲）。

> **技能卡｜自我介绍 30 秒版（电梯演讲）**：偶遇场景 30 秒说清"我是谁"——①我是谁（来自哪 + 博士在读 + 做什么方向,一句）②亮点（最有分量的:遥感 CV + 三篇论文/在审,一句）③来做什么（来访问交流 + 想学习合作,一句）。★ 精简有力（约 60-80 字,张口就来）+ 口语化（像说话非书面语）+ 控时 30 秒内。给人清晰"标签"让人记住你是谁/做什么——2 分/5 分版都在此核心上展开。

> **今日交付**：✅ 住宿最终敲定（签约 + 入住时间对齐）✅ ★ 报到细节确认（时间/地点/找谁/带什么/作息）✅ 自我介绍 30 秒版写好。

## 上午段 · 自我介绍 2 分钟版（初次见面）

**① 先垫概念（2 分钟版怎么写）**
- **2 分钟版**用于初次见面、和工位周围同学聊天的稍完整介绍。在 30 秒版的核心上展开：① **背景**（来自哪、博士方向、为什么做遥感 CV——简述转型/兴趣）；② **研究方向**（你做什么——如下游特化/高效适配/SAR，1–2 句说清）；③ **代表成果**（三篇论文，各一句话点出做了什么/解决什么）；④ **访问想做什么**（来这想学习什么、可能在什么方向合作）。★ **2 分钟≈300–400 字**，有内容但不冗长，让人对你有较完整的了解。
- **为什么需要 2 分钟版**：30 秒太简（只够留印象），组会 5 分钟太正式（日常用不上）——2 分钟版是初次见面最常用的"刚刚好"。

**② 手把手带做**：① 在 30 秒核心上展开（背景 + 方向 + 成果 + 访问想做什么）；② 三篇论文各一句（做了什么/解决什么）；③ 控制 2 分钟（约 300–400 字）；④ 口语化、有逻辑（自然过渡）；⑤ 念一遍计时。
**③ 这一步合格的样子**：自我介绍 2 分钟版写好——背景 + 方向 + 三篇成果 + 访问想做什么，约 2 分钟、口语自然有逻辑。
**④ 坑**：① 2 分钟版变成念简历（生硬）→ 口语化、讲故事感；② 成果只报标题（没说价值）→ 各一句点做了什么/解决什么；③ 超时（啰嗦）→ 控 300–400 字。
**⑤ 自救**：展开什么？→ 背景/方向/成果/访问想做什么;论文怎么说？→ 一句话:做了 X 解决 Y;超时？→ 删细节留主线。
**⑥ 今天（这一步）你同时学会了什么**：你**写好了自我介绍 2 分钟版**。**做了**（核心上展开 + 三篇各一句 + 控时 + 口语逻辑）、**学了**（2 分钟版是初见最常用、有内容不冗长、点出成果价值）、**会了**（写出初次见面的完整自我介绍）。

## 二、完整可运行代码 · M15 出发就绪 + 硬交付总检查器（+ 预期输出）

> 这个脚本把"出发就绪度"和"M15 硬交付"合在一起检查——输入各项状态，输出出发就绪百分比 + M15 硬交付达成情况 + 还差什么。M15 收官，用它确认你既准备好了出发、又达成了 M15 的核心目标。

```python
#!/usr/bin/env python3
# m15_final_check.py —— M15 出发就绪 + 硬交付总检查器
departure = {   # 出发就绪各项: True=就绪
    "住宿签约": True, "交通票": True, "设备数据双备份": True,
    "物资齐(证件/生活/打印材料/礼物)": True, "自我介绍三版定稿": True,
    "报到细节确认": True, "出发前最后一晚清单实操": True,
}
phd_handover = {  # 博士交接各项
    "现状梳理": True, "与导师沟通离开安排": True, "交接文档": True,
    "课程/助教替代": True, "低摩擦维持计划": True,
}
m15_hard = {  # M15 硬交付 4 项
    "第三篇论文 v1.0(已投/待合作后投)": True,
    "访问确认(或 Plan B 确认)": True,
    "行前准备完成(住宿/交通/物资/博士交接)": True,
    "《访问期间工作计划》": True,
}

def rate(d):
    done = sum(1 for v in d.values() if v)
    return done, len(d), round(done/len(d)*100)

def report(name, d):
    done, total, pct = rate(d)
    print(f"\n【{name}】{done}/{total} = {pct}%")
    for k, v in d.items():
        print(f"   {'✅' if v else '□ 待办:'} {k}")
    return pct

print("===== M15 出发就绪 + 硬交付总检查 =====")
p1 = report("出发就绪", departure)
p2 = report("博士课题交接", phd_handover)
p3 = report("M15 硬交付", m15_hard)

print("\n" + "="*40)
if p1 == 100 and p2 == 100 and p3 == 100:
    print("🎉 出发就绪 100% + 博士交接 100% + M15 硬交付 100%")
    print("   M15 收官!可以踏实出发,迈向 M16(访问/远程合作)。")
else:
    print(f"出发就绪 {p1}% / 博士交接 {p2}% / M15 硬交付 {p3}%")
    print("→ 把未达成项补齐(出发前/交接/硬交付)。")
print("★ 从'零遥感基础'到'即将走进空天院'——把最后准备做扎实,带着底气出发。")

if __name__ == "__main__":
    pass
```
