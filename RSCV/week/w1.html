为什么用 00- / 10- / 20- 这种数字前缀？（原文没说，但这个设计有讲究）

  1. 强制排序：文件管理器按字典序排，数字前缀让它们永远按你要的逻辑顺序排列，而不是拼音顺序。

前置 1 · 终端（命令行）
它是什么

终端 = 用打字代替点鼠标来操作电脑。 你敲一行字，电脑执行一个动作。

为什么科研必须用它：① 深度学习的工具绝大多数没有图形界面；② 你做的操作要能被记录、被重复——鼠标点击没法写进日志，命令可以；③ 远程服务器上根本没有桌面。

conda activate rs 做的事情，就是修改 PATH 环境变量，让你敲 python 时找到的是 envs/rs/bin/python 而不是系统的那个。

理解这一点，你就理解了三件事： 1. 为什么忘了 activate 就装包会“白装”——装到别的目录去了。 2. 为什么删环境只要 conda env remove -n rs——就是删个文件夹，不会污染系统。 3. 怎么确认自己在哪个环境：which python（Windows：where python），看输出路径里有没有 envs/rs。

实操规则（背下来，后面天天用）

一条纪律：每个项目一个环境，环境用完即弃。 环境搞坏了不要修，conda env remove -n rs 删掉重建，五分钟的事。新手最大的时间浪费是修一个坏掉的环境。

  • 虚拟环境(virtual environment)：就是上面说的“一间无菌实验室”。conda create -n rs 就是开一间叫 rs 的房间;conda activate rs 是走进这间房；之后你装的所有包都只在这间房里。
  • GPU / CUDA：你的 4090 显卡是专门做大规模并行计算的硬件，训练神经网络比 CPU 快几十倍。CUDA 是 NVIDIA 让代码能调用 GPU 的“驱动+工具包”。PyTorch 是你写模型用的框架，它要装“对应 CUDA 版本”的那一版，才能真正用上你的 4090。
  • 为什么现在需要：科研第一步是“能跑代码”；而“能跑代码”的硬门槛，就是“PyTorch 能看见你的 GPU”。

结论（记住这三条，能省你半天）：

  1. 你不需要单独装 CUDA Toolkit。 带 cu121 的 PyTorch 轮子里已经打包了运行时。
  2. 你需要保证显卡驱动够新。 驱动版本 ≥ 你要用的 CUDA 版本要求即可。

pip 默认从 PyPI 下载。PyPI 上的 torch 是 CPU 版（因为 GPU 版太大）。--index-url 告诉 pip：“别去 PyPI，去 PyTorch 官方这个专门放 GPU 版轮子的地址下”。丢了它，你会装到一个能跑但用不了显卡的 PyTorch，而且不报错——这是最坑的地方，你要跑起来才发现慢得离谱。

★ 标注格式逐字段讲透（原文说“重点看标注格式”但没展开）

一个 .txt 标注文件长这样：

部分 含义
第 1 行 imagesource 影像来源（GoogleEarth / GF-2 / JL-1），元信息，解析时跳过
第 2 行 gsd 地面采样距离，单位米/像素。有些图这行是 null，代码要处理
第 3 行起，前 8 个数 四个角点 x1 y1 x2 y2 x3 y3 x4 y4，按顺时针或逆时针顺序
第 9 个字段 类别名（15 类之一）
第 10 个字段 difficult：1 = 难样本，官方评测时通常忽略

★ 为什么用四点而不是 (x, y, w, h, θ)：四点表示没有角度周期性问题（见 《名词逐个讲透》§5.2），也不用纠结“哪条边算宽”。代价是需要转换成模型要的格式——这个转换你 D6 就会写。
