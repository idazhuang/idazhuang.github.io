上午段 · 精读 Zhu 2021 SAR 综述

0. 拿到论文

原文写的是 “Zhu 2021《SAR Image Classification Using Deep Learning: A Survey》”。这个标题不够精确，直接搜可能搜不到。

更可靠的做法：搜 SAR deep learning survey 或 Deep learning meets SAR，在 Google Scholar 里按引用数排，选近五年、引用高的一篇综述。Zhu Xiao Xiang（就是 D2 那篇的第一作者）团队在 SAR 深度学习方向有多篇高引综述，任选一篇都能达到今天的目的。

★ 这是个通用技能：当资料给的文献信息不精确时，用“关键词 + survey + 按引用排序”去找，而不是死磕作者名。 领域内的高引综述是可替换的——你要的是那张地图，不是那一篇论文本身。

★ 读 SAR 综述时，重点抓这三样

原文说“记牢 SAR 三大特有挑战”，但没说是哪三大。这里给出对照（读完你应该能在论文里找到这些）：

挑战 具体是什么 在你手册里的位置
① speckle（相干斑） 乘性噪声，不是设备缺陷，是相干成像的必然产物 《名词逐个讲透》§1 有 3000 字详解 + 动手仿真
② 数据稀缺 + 标注昂贵 SAR 图人眼都难判读，标注要专家 → 指向自监督、迁移学习、仿真数据
③ 成像机理特殊 方位角敏感、几何畸变（layover/shadow）、极化 《名词逐个讲透》§2–§3

★ 强烈建议的顺序：先读 《名词逐个讲透》的 §1–§3，再读这篇综述。 那一页把 speckle、后向散射、SLC/GRD、极化这些词按六段讲透了，带着它去读综述，你不会被术语淹没。原手册的 M0 只给了名词表，那是不够读这篇综述的。

中午段 · SAR 数据的三种形态

见 《名词逐个讲透》§3.1–§3.2（SLC/GRD、幅度/强度/dB），那里讲得比原文细。这里只补一个原文没说清的点。

★ 20log10 还是 10log10（原文写的公式有个隐含前提）

原文给的是 20*log10(amplitude+1)。这个式子在幅度上是对的，但有两个问题：

问题 说明 正确做法
系数取决于你手上是幅度还是强度 幅度用 20*log10；强度（= 幅度²）用 10*log10。弄反了整张图的对比度就错了一倍 先确认你的数据是哪种
+1 是个粗糙的补丁 它是为了防 log(0)，但会把小值往上抬。SAR 的暗区值常远小于 1，加 1 之后暗部信息被压平了 用 np.maximum(amp, eps)，eps 取 1e-6

坑 症状 解

① 先垫概念：为什么必须转换

你 W2 用的 DOTA，标注是 .txt，一行八个数加类别。但 SAR 数据集不是这个格式：

数据集 标注格式 长什么样
DOTA .txt，四点 + 类别 + difficult x1 y1 x2 y2 x3 y3 x4 y4 ship 0
HRSID COCO JSON，一个大 json 装所有图 {"images":[...], "annotations":[{"bbox":[x,y,w,h],"segmentation":[...]}]}
SSDD VOC XML，每张图一个 xml <bndbox><xmin>..</xmin>...</bndbox>

MMRotate 只认 DOTA 格式（也支持 COCO，但旋转框流程按 DOTA 走最顺）。所以第一步必须转。

④ 转换的常见坑

坑 症状 解
COCO 用了 bbox 而不是 segmentation 框全是水平的，旋转框白做 优先用 segmentation + minAreaRect
没标注的图没生成 txt 框架报“找不到标注文件” 上面的代码已经处理（写空文件）

COCO 的 bbox 是 (x,y,w,h) 当成了 (x1,y1,x2,y2) 框大小全错 COCO 是 xywh，VOC 是 xyxy，两者不同
图片扩展名不匹配（jpg vs png） 框架找不到图 转换只管标注，图片名的 stem 必须和 txt 一致

D18 · SAR 数据增强 + 第一次调 lr

中午段 · speckle 增强（原文的代码是对的，补两件事）

原文给的 Gamma 噪声写法正确：

补充 1：为什么这个写法是对的

Gamma(shape=L, scale=1/L) 的均值 = L × (1/L) = 1，方差 = 1/L。这正好对应 《名词逐个讲透》§1 说的：L 视平均后，speckle 的变异系数是 1/√L。所以 looks 参数有明确的物理含义，不是随便调的旋钮。

补充 2：★ 一个必须注意的顺序问题（原文没提，但错了效果全反）

理由：speckle 在线性域是乘性的。你已经做完 log 之后，乘性已经变成加性了（log(R·n) = log R + log n）。在 log 域上再乘一次 Gamma，物理上说不通。

如果你的数据已经是 log 后的 PNG（多数公开数据集都是），有两个选择：

选择 做法 评价
A 先 10**(x/20) 反变换回幅度 → 乘噪声 → 再 log 严谨，但要知道原来的 dB 范围
B 直接在 log 域加噪声（因为 log 域里 speckle 本来就是加性的） 更简单且物理上自洽，推荐

这个细节值得写进你的笔记——它说明“照搬公式”和“理解公式”的区别。

D20 晚上段 · 《SAR vs 光学五大差异》

★ 直接用 《名词逐个讲透》 的内容，那一页 §1–§3 就是这份文档的素材库。骨架：

# 差异 光学 SAR ★ 所以呢
1 成像方式 被动，收太阳光 主动，自己发微波 SAR 能夜间/穿云工作
2 噪声 加性高斯 乘性 speckle 通用去噪/增强方法直接搬会失效
3 动态范围 8bit 够用 跨好几个数量级 必须 log 压缩，见 D16 那三行数字
4 几何 中心投影 侧视 + 按距离排像素 layover/shadow/foreshortening 这些畸变光学没有
5 目标外观 和人眼一致 方位角敏感，换个角度长相全变 模型容易过拟合某个方位角

每条都写“所以呢”——差异本身不值钱，差异导致的技术后果才值钱。这是你 W1-D2 就学过的写法。
