上午段

系统检索你方向的核心论文，列成清单

1先垫概念（为什么第一步是“列全集”而不是“开始读”）

  • 进一个方向做研究，和你 W1 读 Zhu 综述时最大的不同：那时你是“被喂”一篇地图；现在你要自己把这个方向的论文全集捞出来。捞全集 = 先有“这个领域到底有哪些工作”的鸟瞰，才知道哪篇重要、哪篇可跳。
  • 和通用 CV 对比：通用 CV 你随便搜 “object detection survey” 就有海量梳理；遥感子方向（如旋转检测）英文关键词更分散（oriented / rotated / arbitrary-oriented object detection 都指同一件事），只搜一个词会漏掉半个领域。所以遥感检索要多关键词 + 多平台。
  • 为什么现在需要：这张清单是本周后面所有事（分级、SOTA 榜、Gap）的“原料库”。原料不全，后面全偏。

2手把手带做

（按这个顺序捞，别漏）

3这一步合格的样子

4最常踩的坑

  • 只搜一个关键词：遥感子方向同义词多，只搜 “rotated detection” 会漏掉所有写 “oriented” 的工作。务必多词检索。
  • 只收最新、漏掉必引经典：经典论文（常是公认 baseline 的来源）被引最多、最该读。新 ≠ 重要。
  • 中文检索为主：顶会顶刊主战场是英文，只搜中文会系统性漏掉核心工作。

5卡住怎么自救（决策树）

  • 不确定收全没? → 看 1 篇最新综述的参考文献 + 1 篇最新 SOTA 的 Related Work，两边的高频名字你清单里都有 = 大概率全了。
  • 一个词搜出几千篇、无从下手? → 加限定:近3年 + 引用排序，先收高引的；或用 Connected Papers / Semantic Scholar 看引用簇，簇中心就是核心。
  • 实在拿不准某篇要不要收? → 先收进来标 C，分级阶段再筛，捞全比漏掉安全。

6今天（这一步）你同时学会了什么

你掌握了“为一个方向系统检索、建立论文全集”这项研究地基能力——多关键词 + 顺藤摸瓜，而不是零散读几篇。这套你以后每开一个新方向、每写一篇论文的 Related Work 都要用。做了（方向论文清单）、学了（系统文献检索 vs 零散阅读）、会了（把一个方向的论文捞成“全集”）。

中午段

给清单做 A/B/C 分级

1先垫概念（为什么要分级）

  • 清单 20 多篇，一周不可能都精读。分级 = 按“与我方向相关度 × 影响力”把论文分成三档：A（必精读,~10 篇）/ B（应泛读,~15 篇）/ C（扫摘要即可）。先分级，才能把“精读”这种昂贵动作只花在最值钱的 A 级上。
  • 和你 W1 的对比:W1 你每篇都老老实实 5 遍法精读（因为篇数少、要练读法）；现在篇数多了，你要学会给阅读“配额”——这是从“学生式通读”到“研究者式有选择地读”的升级。

2手把手带做

  1. 给清单每篇标 A/B/C。判据：A = 顶会/顶刊(CVPR/ICCV/ECCV/TGRS/ISPRS)+ 高引，或被反复当对比基准的；B = 次级期刊 / 高质量 arXiv 预印本，相关但非核心；C = 沾边但不是你要做的那块。
  2. A 级控制在 ~10 篇(本周精读的就是这 10 篇，排好优先序 A1…A10,A1 = 最核心/最该先读的那篇，通常是公认 baseline 或开创性工作)。
  3. B 级列出来本周泛读(D54),C 级只在清单里记一句摘要。

3这一步合格的样子

清单每篇都有 A/B/C 标记；A 级恰好约 10 篇（不是 3 篇也不是 20 篇），且 A 级里同时含“公认经典”和“最新 SOTA”两类。

4最常踩的坑

  • 全标 A（舍不得降级）：结果一周读不完 10+ 篇，分级形同虚设。A 必须克制在 ~10。
  • A 级全是最新、没有经典：那你会不知道“公认 baseline 是谁”。A 级要老少搭配。
  • 分级一次定死：读着读着发现某 B 其实很关键，随时可升 A——分级是动态的。

5卡住怎么自救（决策树）

  • 某篇 A 还是 B 拿不准? → 问自己：“它是不是公认 baseline 或当前最强？” 是 → A;“只是相关” → B;“边缘沾边” → C。
  • A 级超过 12 篇下不去? → 把“方法雷同、只是小改”的合并成“读 1 篇代表 + 其余记差异”，压回 10 篇。

6今天（这一步）你同时学会了什么

你学会了论文分级阅读策略(A/B/C)——把有限精力按“相关度×影响力”投到核心 10 篇上。这是研究者和学生读文献的分水岭。做了（A/B/C 分级 + A1–A10 优先序）、学了（分级阅读的判据）、会了（给阅读分配“配额”）。

技能卡｜文献分级 A/B/C:① 全集捞出（多关键词+顺藤摸瓜）→ ② 按“相关度×影响力”标级：A=顶会顶刊/高引/公认基准（精读,~10篇）、B=相关预印本（泛读）、C=沾边（记摘要）→ ③ A 级排优先序，老（经典baseline）少（最新SOTA）搭配 → ④ 分级动态可调。

晚上段

精读 A1（方向最核心的一篇）

1先垫概念（A1 为什么先读、它是什么角色）

  • A1 = 你 A 级里最核心的一篇，通常是这个方向的公认 baseline 或开创性工作（旋转检测里常是 Oriented R-CNN 或更早的 RoI Transformer 这类奠基方法）。它是你理解整个方向的“锚”：后面每篇都在和它对话（改进它、对比它）。

4最常踩的坑

  • 第 4 段偷懒写空话：“方法还可以改进”——这对找 Gap 毫无用处。要具体到“在什么样本/什么指标上，差在哪”。
  • 被公式劝退：奠基论文常有旋转框表示、角度回归的数学（如角度周期性、边界不连续问题），第一遍别纠缠，先抓“它解决了什么、怎么解决的直觉”，公式留到需要时。

5卡住怎么自救（决策树）

  • 不确定 A1 选得对不对? → 看它是不是后面多篇 A 级论文对比表里的“基准行”；是 = 选对了。

6今天（这一步）你同时学会了什么

你精读了方向的锚点论文，并刻意从中挖“未解决点”。这套“先读穿锚点 → 用它当后续差量阅读的基准 → 顺手攒 Gap”的打法，是高效进入任何新方向的标准姿势。做了（A1 笔记 + ≥2 条 Gap 线索）、学了（方向的核心工作）、会了（从锚点论文切入一个方向并攒 Gap）。

  • 差量阅读 = 读同一方向第 N 篇时，不再从背景概念啃起，而是直接问“它相对前面那些，新增/改进了什么”。因为同方向论文有大量重复的背景、相同的 baseline、相似的数据集，真正值钱的是“这一篇独有的那点增量”。

晚上段

确定方向的“公认 baseline”

1先垫概念（公认 baseline 为什么是头等大事）

  • 公认 baseline = 这个方向大家做实验必然要对比的那个（些）方法，通常是经典、开源、被反复当“基准行”的。为什么至关重要：你未来的方法必须和它比，否则审稿人第一句就是“为什么不和 XXX 比？”——不比公认 baseline，论文直接被质疑。
  • 和通用 CV 对比：通用检测的公认 baseline 很清晰(Faster R-CNN / RetinaNet / DETR)；遥感旋转检测的公认 baseline 要你从多篇论文的对比表里自己识别（常见的有 Rotated RetinaNet、Oriented R-CNN、ReDet 等）。

2手把手带做

  1. 把你已读的 A 级论文的实验对比表摊开，找“几乎每篇都出现、且常作为基准行的那个方法”= 公认 baseline。
  2. 记进 10-论文笔记/{方向}_公认baseline.md:方法名 | 出处 | 是否开源 | 代码链接 | 主数据集上的报告指标。通常锁 1 个“经典基准”+ 1 个“当前最强”。
  3. 顺手确认它开源且单卡可跑（D55 你要复现它当资格证）。

3这一步合格的样子

确定 1–2 个公认 baseline（至少 1 个开源可复现），记下代码链接和它在主数据集上的报告分。

4最常踩的坑

  • 把“最新 SOTA”当唯一 baseline：还要有“公认经典 baseline”（大家都比的那个），否则审稿人觉得你回避了经典对比。
