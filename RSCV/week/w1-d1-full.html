前置 1 · 终端（命令行）

它是什么

终端 = 用打字代替点鼠标来操作电脑。 你敲一行字，电脑执行一个动作。

为什么科研必须用它：① 深度学习的工具绝大多数没有图形界面；② 你做的操作要能被记录、被重复——鼠标点击没法写进日志，命令可以；③ 远程服务器上根本没有桌面。

怎么打开

系统 怎么开
Windows 装完 Miniconda 后，开始菜单里搜 Anaconda Prompt，用它（不要用 CMD 或 PowerShell，conda 命令可能不认）
macOS Command + 空格，输入 Terminal，回车
Linux Ctrl + Alt + T

给 Windows 用户的一句真心话：深度学习的绝大多数教程、报错、issue 都是按 Linux 写的。如果你打算认真做两年，现在就装 WSL2（Windows 里的真 Linux 子系统），微软官方支持，一条命令：管理员权限打开 PowerShell，运行 wsl --install，重启即可。今天可以先不装，但 W2 之前一定要装。 这能帮你避开后面几十次“教程里的命令在我这跑不了”。

终端里的三个小坑

  1. 复制粘贴：终端里 Ctrl+V 常常没用。Linux 终端用 Ctrl+Shift+V；Windows 的 Anaconda Prompt 里直接点鼠标右键就是粘贴。
  2. 路径里有空格：cd My Folder 会失败，要写 cd "My Folder"。所以你的项目路径里永远不要有空格和中文——这条会帮你省掉很多莫名其妙的报错。
  3. 命令卡住了：按 Ctrl+C 中断。这是终端的“取消键”。

前置 2 · Markdown（10 分钟学会）

为什么笔记要用 Markdown 而不是 Word

Word Markdown
文件本质 二进制，只能用 Word 打开 纯文本，任何编辑器都能开
十年后还能打开吗 看软件 一定能
能被 grep 全文搜索吗 不能 能
能用 git 做版本管理吗 不能（看不出改了什么） 能
写公式和代码 麻烦 天然支持

一句话：你两年会攒下几百篇笔记，Markdown 保证它们永远属于你，不被任何软件绑架。

全部语法（真的就这些，10 分钟）

---（三个减号 = 分隔线）

  • [ ] 未完成的待办
  • [x] 已完成的待办

conda activate rs 做的事情，就是修改 PATH 环境变量，让你敲 python 时找到的是 envs/rs/bin/python 而不是系统的那个。

理解这一点，你就理解了三件事： 1. 为什么忘了 activate 就装包会“白装”——装到别的目录去了。 2. 为什么删环境只要 conda env remove -n rs——就是删个文件夹，不会污染系统。 3. 怎么确认自己在哪个环境：which python（Windows：where python），看输出路径里有没有 envs/rs。

实操规则（背下来，后面天天用）

一条纪律：每个项目一个环境，环境用完即弃。 环境搞坏了不要修，conda env remove -n rs 删掉重建，五分钟的事。新手最大的时间浪费是修一个坏掉的环境。

为什么用 00- / 10- / 20- 这种数字前缀？（原文没说，但这个设计有讲究）

  1. 强制排序：文件管理器按字典序排，数字前缀让它们永远按你要的逻辑顺序排列，而不是拼音顺序。
  2. 留空隙：用 00/10/20/30 而不是 1/2/3/4，是为了以后能往中间插。比如后面你要加“15-会议投稿”，插进去不用重命名其他所有文件夹。
  3. 这是工程界通用的编号习惯，你以后看开源项目的 configs/ 目录也常见。

① 先垫概念

GPU / 驱动 / CUDA 运行时 / PyTorch —— 四层关系

新手最大的困惑是“我到底要不要单独装 CUDA”。把这四层画清楚就不困惑了：

结论（记住这三条，能省你半天）：

  1. 你不需要单独装 CUDA Toolkit。 带 cu121 的 PyTorch 轮子里已经打包了运行时。
  2. 你需要保证显卡驱动够新。 驱动版本 ≥ 你要用的 CUDA 版本要求即可。
  3. nvidia-smi 右上角显示的 CUDA Version 不是“你装了 CUDA”，它是“你的驱动最高能支持到哪个 CUDA”。显示 12.4 的机器完全可以跑 cu118 的 PyTorch。

这第 3 条是新手劝退率最高的误解。原文一句“以为装了驱动=有 CUDA”点到了，但没说清方向，很多人反而更糊涂了。

为什么 Python 用 3.10（原文说“稳”，这里说为什么）

深度学习生态永远滞后于 Python 官方版本半年到两年。 判断规则：

具体到今天：Python 3.10 / 3.11 都很安全，3.9 也行（老框架兼容性最好）。3.12+ 现在还会遇到某些包没有预编译轮子。 这也是为什么晚上段装 MMRotate 时我建议用 3.9——那套框架更老。

这个判断方法你要学会，因为具体数字每年都在变，方法不变。

技能卡｜深度学习开机四步（升级版） ① conda create -n xxx python=3.10 → ② conda activate xxx，用 which python 确认 → ③ 去 PyTorch 官网按 nvidia-smi 的 CUDA 版本选命令装 → ④ 三行验证：版本带 +cuXXX、is_available() 为 True、矩阵乘测试 1 秒内跑完。 第 ④ 步的矩阵乘测试是原手册没有的，但它能抓出“能看见 GPU 却在用 CPU 跑”这种隐蔽故障。
