怎么用

第 1 步

先垫两块底

零遥感基础的人，先读《遥感基础知识入门》，再读《必备前置知识》。 两篇都是用"和通用 CV 对比"的方式讲的，读完再进 W1。
第 2 步

按周号顺着做

W1 → W104，一周一页，一天三个时段。每个时段固定六块： 先垫概念 → 手把手带做 → 合格样例 → 常踩的坑 → 卡住自救 → 今天学会了什么。
第 3 步

勾掉，别回头

做完一个时段就点一下方框，进度会记在这台浏览器里。 进度地图能一眼看到 728 天走到哪了——进度可慢不可断。

贯穿全程的两条铁律

战略定位

不在"更大基础模型"上硬拼

零遥感基础 + 单张 RTX 4090 + 导师不支持 + 目标空天院，决定了发力点是 下游特化 / 高效适配（LoRA）/ 评测 / 鲁棒性 / 跨域泛化 / 小样本 / SAR 难题 / 通用 CV 嫁接。 单卡 4090 不是短板，写进论文里就是"高效、可复现"的亮点。

两条线

并行推进，绝不混为一谈

博士毕业靠博士论文（原方向），转型求职靠遥感成果。这是两条线， 精力清醒分配。对外连接与运营是"强作品的自然放大"，属副线、要控时，核心永远是研究产出。
