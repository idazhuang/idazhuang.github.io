术语表

上半部分抄自 M0《遥感基础知识入门》第 11 节；下半部分是网站补的——手册正文里频繁出现、但 M0 没单独定义的词，并标出它在计划里第一次用到的周次。

遥感基础（来自 M0）

  • GSD:Ground Sample Distance，空间分辨率（一个像素多少米）。
  • DN:Digital Number，传感器记录的原始数字量（未转物理量）。
  • NDVI：归一化植被指数 =(NIR−Red)/(NIR+Red)，植被越旺越大。
  • band：波段（一个波长区间的成像）。pan：全色；MS：多光谱；HS：高光谱。
  • pan-sharpening：用高分全色图“锐化”低分多光谱图，得到高分彩色图。
  • SAR：合成孔径雷达；SLC:Single Look Complex（SAR 复数数据）；speckle：相干斑噪声；InSAR：干涉 SAR（用相位测高程/形变）；极化:HH/HV/VH/VV。
  • orthorectification：正射（几何）校正；atmospheric correction：大气（辐射）校正。
  • GeoTIFF：带地理坐标的栅格格式；GDAL/rasterio：读写遥感栅格的库。
  • revisit time：重访周期（时间分辨率）。
  • 变化检测/语义分割/旋转检测/场景分类：遥感四类常见 CV 任务。

科研流程

术语说明首次用到
baseline别人已发表、公认可比的基准方法。你先把它原样跑通、拿到和论文接近的数字，才有资格说“我的方法更好”。跑不通的 baseline 不能当对比对象。W1
消融实验 (ablation)把自己方法里的组件一个个拿掉，看指标掉多少，用来证明“这个组件真的有用”。审稿人最爱看，也最容易挑刺——一次只拆一处，别一起改。W2
随机种子 (seed)控制初始化与数据打乱的随机性。同一个方法换个 seed 结果能差零点几个点，所以主结果至少跑 3 个 seed 报 mean±std，单 seed 的提升往往是噪声。W11
SOTAState of the Art，当前最好水平。注意区分“某数据集某设置下的 SOTA”和“领域 SOTA”，论文里要把限定条件写清楚。W5
Gap 分析把一个方向的论文读穿之后，列出“还没有人解决好的口子”。这是从“读者”变成“研究者”的关键一步，也是你所有原创 idea 的来源。W2
Proposal研究计划书：问题是什么、为什么值得做、打算怎么做、怎么验证、预期贡献。写得出 Proposal 才算真正选定了方向。W8
rebuttal / Response Letter对审稿意见的逐条回复。原则是：逐条编号、先答“改了什么”再答“为什么”，能补实验就补实验，不能补就诚实说明并给出证据。W14
mock review投稿前自己或朋友扮演审稿人挑刺。找出的问题越狠，真审稿时越轻松。W11
Cover Letter投稿时给编辑的信：一句话说清论文做了什么、为什么适合这个刊、和作者已有工作的关系。W24
arXiv预印本平台。投稿后挂 arXiv 可以尽早建立时间戳和可见度，但要先确认目标期刊/会议允许。W1
冷邮件给素未谋面的老师写的第一封联系邮件。核心是“让对方 30 秒内看懂你是谁、做过什么、想要什么”，并附可验证的成果链接。W36

模型与指标

术语说明首次用到
backbone / neck / head检测/分割网络的三段式结构：backbone 提特征，neck（如 FPN）融合多尺度，head 出预测。看懂这三段，大部分论文的结构图就能读了。W1
FPN特征金字塔网络，把不同层级的特征融合，让小目标也有足够分辨率的特征。遥感小目标多，FPN 及其变体几乎是标配。W1
anchor预设的候选框。anchor-based 方法先铺一堆框再回归，anchor-free 直接预测。遥感目标尺度跨度大，anchor 设置对结果影响明显。W1
NMS非极大值抑制，去掉重复检测框。旋转框要用 rotated NMS，直接用水平框 NMS 会误删密集排列的目标（如停车场的车、港口的船）。W2
IoU预测框与真值框的交并比，判定“算不算检到”的阈值。旋转框的 IoU 计算比水平框复杂得多，也是很多 bug 的来源。W1
mAP各类别 AP 的平均，检测任务的主指标。注意标注清楚是 VOC07 还是 COCO 口径、IoU 阈值取多少——口径不同数字不可比。W1
mIoU各类别 IoU 的平均，语义分割主指标。类别极不平衡时要同时看每类 IoU，别被平均值骗了。W5
F1 / precision / recall变化检测、少样本场景常用。precision 高 = 报出来的基本是对的；recall 高 = 该找的基本没漏。两者拉扯，F1 是折中。W5
OBB / HBBOriented / Horizontal Bounding Box，旋转框 / 水平框。遥感目标常常是斜的（飞机、船、桥），旋转框才贴得紧，这是遥感检测区别于通用检测的核心之一。W35
ViT / self-attentionVision Transformer 与自注意力。相比 CNN 更擅长建模长距离依赖，但数据量和显存需求更高——单卡场景要特别注意 batch size 和分辨率。W5
预训练 / 微调 (fine-tune)先在大数据上学通用特征，再在目标任务上小步调整。遥感的关键问题是：用 ImageNet 预训练还是遥感自监督预训练，差别可能很大。W2
LoRA低秩适配，只训练一小部分新增参数、冻住原模型。显存和时间成本大幅下降——这是“单张 4090 也能玩大模型”的核心手段，也是本计划的主要发力点之一。W4
MAE / 自监督Masked AutoEncoder，遮住一部分图像让模型重建，从无标注数据里学表征。遥感影像海量但标注稀缺，自监督因此格外重要。W4
小样本 / few-shot每类只有几个标注样本时的学习问题。遥感里新地物、新传感器、新地区的标注都很贵，小样本是真实需求而不是玩具设定。W3
domain gap / 跨域泛化训练数据和实际使用数据分布不一致（不同卫星、不同季节、不同地区、光学 vs SAR）导致性能掉点。遥感里这个问题比通用 CV 严重得多。W9

工程与工具

术语说明首次用到
conda 虚拟环境给每个项目开一间“无菌实验室”，避免不同项目的依赖版本互相污染。每开一个新终端第一件事是 activate。W1
CUDA让代码调用 NVIDIA GPU 的工具链。装 PyTorch 时要选对应 CUDA 版本的轮子，否则 torch.cuda.is_available() 会是 False。W1
MMCV / MMDetection / MMRotateOpenMMLab 的三层依赖：底层算子库 → 通用检测框架 → 旋转框检测库。版本匹配是新手最大的坑，优先用 mim 安装。W1
wandb / TensorBoard训练过程的“飞行记录仪”：记录 loss 曲线、指标、超参、显存。实验一多，没有记录系统就等于没做实验。W7
batch size / learning rate两者要一起调：batch 减半时 lr 通常也要相应下调。单卡显存有限时，靠梯度累积模拟大 batch。W2
AMP 混合精度用半精度算、关键处保留单精度，显存省近一半、速度更快。单卡训练几乎必开。W8
切图 / 滑窗推理 (SAHI)遥感大图（几千甚至上万像素）没法整张进网络，训练时切成小块，推理时滑窗再拼回去。切图重叠率、拼接去重是常见坑。W2
TTA / ensemble测试时增强（翻转、多尺度）与多模型融合，竞赛里的常规涨分手段，论文里要谨慎使用并说明。W9
checkpoint训练过程中保存的模型权重。要定期保存、记录对应的配置和 seed，否则拿到好结果却复现不出来。W2

遥感数据与机构

术语说明首次用到
DOTA最常用的遥感旋转框检测数据集，大图、多类别、目标密集且方向任意。本计划的第一个 baseline 就跑在它上面。W1
DIOR / FAIR1M / HRSC另外几个常用检测基准：DIOR 类别多、FAIR1M 细粒度、HRSC 专做舰船。跨数据集验证时常用组合。W1
LEVIR-CD / iSAID分别是变化检测和实例分割的常用遥感基准。W5
Sentinel-1 / Sentinel-2欧空局的免费卫星数据：S1 是 SAR，S2 是多光谱。数据免费、重访快，是做实验最容易拿到的公开数据源之一。W3
GF 系列（高分）中国高分辨率对地观测系统的卫星系列，国内遥感研究常用数据来源。W4
空天院 / AIR中国科学院空天信息创新研究院，本计划的目标单位。遥感基础模型 RingMo 出自该院孙显组。W2
RingMo空天院孙显组的遥感基础模型工作。理解它有助于判断“哪些方向已经被大团队占住了、哪些下游口子还开着”。W3
多时相同一地区不同时间的影像。变化检测、时序分析的基础，也带来配准、季节差异、云遮挡等一系列特有问题。W5
