2. 深度学习最小概念（看懂训练在干嘛）

① 神经网络是什么：一个带大量可调参数的函数 y = f(x; W)。给它输入 x（图像），它输出预测 y;训练 = 自动调参数 W，让预测越来越准。类比：一个有几百万个旋钮的机器，训练就是自动拧旋钮。

② 张量(tensor)：就是多维数组。一张 RGB 图 = (3, H, W) 的张量；一批(batch)图 = (N, 3, H, W)。PyTorch 里的数据都是张量（和 numpy 数组几乎一样，但能放 GPU、能自动求导）。

③ 训练的核心循环（记住这五步，计划 M1-W3 会让你亲手写）：

  1. 取一批数据(batch)；
  2. 前向:pred = model(x)(算出预测)；
  3. 算 loss:loss = 损失函数(pred, 真值)(预测离真值多远)；
  4. 反向传播:loss.backward()(自动算每个参数该往哪调=梯度)；
  5. 更新参数:optimizer.step()(按梯度拧旋钮)；每步前 optimizer.zero_grad()(清空上一轮梯度)。

④ 几个必懂词：

  • loss（损失）：衡量“预测有多差”，训练就是让 loss 变小。分类常用交叉熵 CrossEntropy。
  • optimizer（优化器）：决定“怎么根据梯度调参数”，常用 SGD / Adam。
  • learning rate（学习率 lr）：每步调多大。太大→震荡/NaN，太小→学不动（最关键的超参）。
  • batch / batch_size：一次喂多少张图。受显存限制(4090 上旋转检测常 bs=2)。
  • epoch：把整个训练集过一遍叫一个 epoch；通常训多个 epoch。
  • 过拟合(overfitting)：在训练集很好、在没见过的数据上差（死记硬背了）。
  • train / val / test 划分：训练集学、验证集调参选模型、测试集只在最后评估——不能用测试集调参（作弊）。

⑤ 一句话记牢：训练 = 反复“前向→算 loss→反向→更新”，目标是 loss 下降且在验证/测试集上也好（不只训练集）。

3. CNN 基础（遥感 CV 的主力网络）

① 卷积(convolution)：用一个小窗口（卷积核）在图上滑动、做加权求和，提取局部特征（边缘、纹理…）。多层卷积叠起来，从低级特征（边）到高级特征（物体部件）。

② 池化 / 下采样(pooling/downsample)：把特征图变小（如尺寸减半），扩大“视野”、减计算。副作用：小目标特征会丢——这正是遥感小目标难检的原因之一（差异表第 2 条）。

③ 特征图(feature map)/ 感受野(receptive field)：卷积输出的中间结果叫特征图；一个输出像素“看得到”的输入区域大小叫感受野（越深越大）。

④ 一个检测/分割网络的三段式（计划 W2 会反复见）：

  • backbone（主干）：负责“从图像提特征”。常用 ResNet（经典 CNN）、Swin Transformer（更强但更重）、ConvNeXt。
  • neck（颈）：融合不同尺度的特征，最常见是 FPN（特征金字塔）——让大目标小目标都能被检到。
  • head（头）：在特征上输出最终结果（框/类别/掩膜）。

⑤ 一句话记牢:图 →[backbone 提特征]→[neck 多尺度融合]→[head 出结果]。换 backbone/neck/head 的某一块来看效果，就是消融实验（计划 W2 起反复做）。

4. CV 三大任务范式（把“做什么”搞清）

任务 输出 关键概念
分类(classification) 一张图一个类别 softmax、交叉熵
目标检测(detection) 每个目标：一个框 + 类别 框、anchor、NMS、IoU
语义分割(segmentation) 每个像素一个类别（掩膜） 逐像素分类、上采样还原细节

检测必懂的几个词：

  • 框(bounding box)：框住目标的矩形。通用 CV 用水平框（左上+右下）；遥感目标斜着，用旋转框（计划 W2 详讲）。
  • anchor（锚框）：预设的一堆候选框，网络在其上微调（两阶段/部分一阶段检测器用）；anchor-free 则不用预设框。
  • 两阶段 vs 一阶段：两阶段（如 Faster/Oriented R-CNN）先选候选区再分类回归，准但慢；一阶段（如 RetinaNet/YOLO 系）直接出框，快。
  • IoU（交并比）：两个框“交集/并集”，衡量预测框和真值框重叠度(0–1)。判断“检测对不对”的尺子。
  • NMS（非极大值抑制）：同一目标常出多个重叠框，NMS 只保留最高分的、删掉其余（计划竞赛周会见到更优的 WBF）。

一句话记牢：分类=整图一个标签；检测=框+类别（看 IoU、用 NMS）；分割=逐像素标签。

5. 评价指标（看懂论文的数字 + 知道何时用哪个）

指标 用于 含义（直觉）
accuracy（准确率） 分类（类别均衡时） 预测对的比例
precision（精确率） 检测/分类 “我说是的里，有多少真是”
recall（召回率） 检测/分类 “真有的里，我找到多少”
F1 类别不平衡（如变化检测） precision 与 recall 的调和平均
mAP 目标检测 各类 AP（平均精度）的平均；越高越好
mIoU 语义分割 各类 IoU 的平均

为什么不同任务用不同指标：类别极不平衡时（如变化检测里“变”的像素很少），光看 accuracy 会骗人（全猜“没变”也高）→ 用 F1。记住对照：检测=mAP，分割=mIoU，变化检测=F1，均衡分类=accuracy。（计划 M2-W5 会让你亲手体会。）

第一层 · 神经网络凭什么能学会

全书把 backbone 解释成“负责从图像提特征”。但从没说过什么叫“特征”。 从这里开始。

1.1 特征（feature）

① 一句话：特征就是从原始像素里提炼出来的、对当前任务有用的数字。

② 打个比方：让你判断一张图里有没有飞机。你不会去看“第 3721 个像素是不是 R=128”，你看的是“有没有细长的机身”“有没有对称的两翼”“尾部有没有分叉”。这些“你实际在看的东西”就是特征。 原始像素是 3×1024×1024 个数字，特征是从中提炼出的、更抽象也更有用的一小把数字。

③ 底层在发生什么：

早期 CV 靠人工设计特征——有人坐下来想“边缘怎么算”“角点怎么定义”，写出 SIFT、HOG 这类算子。问题是人想不全：飞机在遥感图上可以是任意朝向、任意大小、被云挡住一半，手工规则永远漏掉一些情况。

深度学习的做法是让网络自己学出特征。你不告诉它“要看机身”，你只给它几万张“这是飞机 / 这不是飞机”的例子，让它自己调整内部参数，直到能分对。调完之后，网络内部那些中间结果，就是它自己学出来的特征。

特征是分层的，这一点非常重要：

这个分层结构解释了后面很多事：

  • 为什么能用预训练权重：浅层学的边缘和纹理，在自然照片和遥感图上是通用的。所以拿 ImageNet 上训好的 ResNet 当起点，比从随机数开始快得多。这就是 W1-D1 你下载那个 .pth 的意义。
  • 为什么小目标难：深层特征虽然语义强，但分辨率已经被压得很小（见 §1.2）。一辆 16 像素的车，到深层可能只剩不到 1 个像素——信息物理上已经没了。这直接引出 §2.3 的 FPN。

④ 在代码里长什么样：ResNet-50 吃进 (3, 1024, 1024)，吐出四个不同尺度的特征图：

读这四行：往下走，空间尺寸每层减半（分辨率变粗）、通道数每层翻倍（语义变强）。这就是“分辨率换语义”的取舍，是整个 CNN 设计的主线。

⑤ 不懂它会卡在哪：backbone、neck、head、FPN、多尺度 这些词全部建立在“特征”之上。不懂特征，W2 读 Oriented R-CNN 时每一段都在雾里。

1.2 卷积与感受野（全书出现 16 次和 5 次，从未真正解释）

① 一句话：卷积是“用一个小窗口在图上滑动，每滑一步算一次加权和”；感受野是“最终输出里的一个点，实际看到了原图多大一块区域”。

② 打个比方：卷积像用一个 3×3 的小印章在图上一格一格盖过去，每盖一次得到一个数。印章里的 9 个权重不是人定的，是训练学出来的——学到最后，有的印章专门对横边缘敏感，有的对红色块敏感。

③ 底层在发生什么：

一个 3×3 卷积核，输出位置 (i,j) 的值 = 输入上以 (i,j) 为中心的 3×3 区域，和 9 个权重逐个相乘再求和。

关键性质有三个：

  1. 局部性：一次只看一小块，不看全图。符合“图像里相邻像素才相关”的直觉。
  2. 权重共享：同一个印章在整张图上滑，参数量极小。这也意味着它在左上角学会认边缘，右下角自动也会（平移不变）。
  3. 堆叠涨感受野：这是最关键的。

感受野怎么涨：一层 3×3 卷积，输出一个点看到原图 3×3。再叠一层 3×3，这个点看到的是上一层的 3×3，而上一层每个点又看 3×3 —— 等效看到原图 5×5。再叠一层是 7×7。

④ 为什么你必须懂这个：

感受野决定了网络“能不能看见”一个目标。 如果一座桥在图上跨了 800 像素，而你这一层的感受野只有 200 像素，这一层物理上不可能理解“这是一座完整的桥”——它只看得到桥的一小段。

这直接解释了 W2 你会遇到的现象：bridge 这一类的 AP 通常特别低。 桥又细又长，跨越多个 patch，感受野还不够。知道原因之后，“怎么增大有效感受野”就成了一个具体的、你能做的研究方向（空洞卷积、可变形卷积、注意力机制都是冲这个去的）。

⑤ 想深入去哪看：斯坦福 CS231n 的卷积那一讲（课程笔记公开，搜 CS231n convolutional networks notes），配图是全网最好的。看那一讲就够，不用看整门课。

1.3 训练三件套：损失函数 / 梯度下降 / 学习率

全书把 学习率 解释成“每步调多大，太大→震荡/NaN”。对，但没说为什么。 这三个词必须一起讲才通。

① 一句话：损失函数是“打分器”，梯度下降是“改错的方法”，学习率是“每次改多少”。

② 打个比方：你在浓雾里下山，看不见山谷在哪，只能感觉脚下的坡度。

  • 损失函数 = 你现在的海拔（越低越好）
  • 梯度 = 脚下最陡的下坡方向
  • 学习率 = 你每一步迈多大

③ 底层在发生什么：

网络有几千万个参数。训练就是不停重复这四步：

第 ④ 步那个减法就是梯度下降，学习率就是那个乘数。

④ 学习率为什么是最关键的超参（回到那个下山的比方）：

学习率 下山会发生什么 训练日志上长什么样
太大 一步迈过山谷，弹到对面山坡更高处，越走越高 loss 变成 nan 或 inf
略大 在山谷两侧来回横跳，下不去 loss 上下震荡，不收敛
合适 稳步下降 loss 平滑下降 ← 你要的
太小 一步挪一厘米 loss 降得极慢，或卡在半山腰

这张表就是你 W2 判断训练健不健康的全部依据。 现在你知道为什么《W2 实操》里说“盯前 200 个 iter，看到 nan 就把 lr 减半”了。

⑤ 为什么 lr 要跟着 batch 变（线性缩放规则的真正原因）：

梯度是在一个 batch 上算平均得到的。batch 越大，这个平均越稳、噪声越小，你就敢迈更大的步子。batch 翻倍 → 梯度可信度提高 → lr 也翻倍。这就是 W2 那条规则背后的道理，不是玄学。

⑥ warmup 是什么（W2 的 config 里有，原文没解释）：训练最开始参数是随机的，梯度方向极不可靠，这时候迈大步很危险。所以前几百个 iter 用很小的 lr，然后线性升到设定值——这就是 warmup。你在 W2 的日志里看到 lr: 1.978e-03 而 config 写的是 0.005，就是因为还在 warmup 期。

① 一句话：

  • batch：一次喂给网络多少张图
  • iteration：完成一次“前向+反向+更新”，即处理完一个 batch
  • epoch：训练集完整过一遍

集合 干什么 能不能拿它调参

第二层 · 目标检测是怎么工作的

这是全书最大的空白。 W2-D8 直接就让你精读 Oriented R-CNN，但从没讲过检测器长什么样。这一层补齐。

2.1 检测任务本身

① 一句话：分类是回答“这张图是什么”，检测是回答“图里有哪些东西，各自在哪”。

② 输出长什么样：

每个框有三样东西：类别、置信度（0–1，模型有多确定）、位置。

③ 遥感的特殊之处：位置在通用 CV 里是水平框 (x, y, w, h)；遥感因为俯视、目标任意朝向，用旋转框 (x, y, w, h, θ)，多一个角度。这就是 MMRotate 存在的全部理由。

④ GT 是什么（全书 73 次，原文只有 13 个字）：Ground Truth，真值，也就是人工标注的正确答案。W2 评测时“预测框 vs GT 框”算 IoU，就是拿你的答案和标准答案对。DOTA 的 labelTxt/ 里那些 txt 就是 GT。

2.2 检测器的三段式结构：backbone / neck / head

几乎所有现代检测器都是这个结构，认准它，你以后读任何检测论文都能立刻定位作者改了哪一段。

部件 干什么 常见选择 换掉它意味着什么
backbone 从像素提特征（§1.1） ResNet-50/101、Swin、ConvNeXt 换 = 提特征能力变强/变弱。W2-D12 的第一个消融就是把 R50 换成 R101
neck 把不同层的特征融合起来 FPN、PAFPN、BiFPN 换 = 多尺度处理方式变了
head 在特征上输出框 RPN + RoI head（两阶段）；单个卷积头（一阶段） 换 = 检测范式变了

2.3 FPN（全书出现 49 次，从头到尾没有一句解释）

这是全书最离谱的遗漏——FPN 出现了 49 次、写在 W2 每一个 config 里，却从没解释过。

① 一句话：FPN（Feature Pyramid Network，特征金字塔网络）把深层的“语义强但分辨率低”的特征，送回给浅层的“分辨率高但语义弱”的特征，让每一层都既清晰又懂语义。

② 为什么需要它（回到 §1.1 那个矛盾）：

大目标该用深层检测，小目标该用浅层检测。但浅层不认识东西。 这就是死结。

③ FPN 怎么解：自顶向下，把深层特征上采样后加到浅层上。

结果：P2–P5 每一层都既有分辨率又有语义。然后按目标大小分配——小目标交给 P2，大目标交给 P5。

④ 在 config 里长什么样（num_outs=5 是什么意思，原文没说）：

num_outs=5 比输入多一层，多的 P6 是在 P5 上再下采样一次，专门检测超大目标。

⑤ 为什么这对遥感特别重要：遥感的尺度悬殊是核心难题之一（同一张图里有机场和小汽车）。FPN 就是通用 CV 里对付尺度问题的标准答案，而遥感把这个问题放大了十倍。所以“怎么把 FPN 改得更适合遥感的极端尺度分布”，是一个成熟且仍在出论文的方向——BiFPN、PAFPN、各种遥感专用 neck 都在做这件事。这是你 M3 找 Gap 时的一个现成候选。

2.4 anchor、正负样本、标签分配

① anchor 是什么（原文：“预设的一堆候选框，网络在其上微调”——对，但没说为什么）：

直接让网络凭空回归出框的坐标，太难了（坐标可以是 0 到 1024 之间任意数）。所以换个思路：先在图上密密麻麻铺一堆预设框（anchor），让网络只回答两件容易的事：

  1. 这个 anchor 里有没有目标？（分类，二选一）
  2. 如果有，真实框相对这个 anchor 该往哪偏一点？（回归，只需微调）

把“从零画框”变成了“选框 + 微调”，难度大幅下降。 这就是 anchor 的全部意义。

② 铺多密：特征图上每个位置铺 k 个不同尺度、不同长宽比的 anchor。P2 是 256×256，光这一层就有 256×256×k 个 anchor。全部加起来通常十几万个。

十几万个 anchor，绝大多数是背景。训练时必须先决定哪些算“正样本”（该学着预测目标）、哪些算“负样本”（该学着预测背景）。 规则通常是：

④ 为什么这件事在遥感里特别难（★ 这是个真正的选题富矿）：

  • 遥感目标极小，anchor 和小目标的 IoU 天然就低 → 小目标很难被分到正样本 → 学不到 → AP 低。这就是 W2 你会看到 small-vehicle AP 偏低的深层原因之一。

⑤ anchor-free 是什么：干脆不铺预设框，直接让网络预测“这个点到框四条边的距离”。少了一堆超参（anchor 尺度、比例怎么设），但小目标上不一定更好。两条路线现在并存，没有绝对优劣。

③ 控制变量是它的前提：一次只改一处，其他全部保持不变。

W2-D12 让你把 ResNet-50 换成 ResNet-101，这时候你只能改 backbone。如果你顺手把 lr 也调了、epoch 也加了，那最后涨的那 1.2 个点，你永远说不清是谁的功劳——这次实验就废了。
